器件选型贯穿硬件产品的整个生命周期。它不只是比较几个参数，而是同时考虑电气性能、封装、温度、可靠性、供货、成本、软件生态、认证和可替代性。

一个器件“能用”，不等于它适合量产；参数看起来相同，也不代表可以互换。选型做得不充分，往往会在调试、认证、量产或停产阶段集中暴露问题。

这个合集将围绕硬件产品中常见器件，整理一套从需求到验证、从样机到量产的选型方法。

## 器件选型的基本维度

| 维度 | 需要确认的问题 |
| --- | --- |
| 电气性能 | 电压、电流、功率、精度、带宽、漏电和时序 |
| 环境适应 | 工作温度、温漂、湿度和可靠性 |
| 封装工艺 | 引脚间距、焊接、散热和装配 |
| 软件生态 | 驱动、工具链、协议和寄存器兼容 |
| 供货能力 | 生命周期、交期、产能和第二货源 |
| 成本 | 样机成本、量产成本和应用成本 |
| 认证合规 | RoHS、REACH、UL、AEC-Q 和目标市场要求 |
| 可替代性 | 引脚、软件、参数裕量和替代验证成本 |

## 计划形成的文章结构

后续每篇文章会尽量按照以下结构整理：

1. 器件的作用和应用场景；
2. 必须理解的关键参数；
3. 选型时如何比较和取舍；
4. 常见错误和典型风险；
5. 降额、可靠性和验证要求；
6. 供货、成本和国产替代；
7. 选型检查清单。

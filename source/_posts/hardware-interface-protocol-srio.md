## 一、文档目的与适用范围

本文档规定硬件产品中 SRIO（Serial RapidIO，RapidIO 串行接口）的设计要求，覆盖物理层速率与通道、链路拓扑与路由、链路训练与复位、PCB 走线阻抗控制、终端策略、与 PCIe 互操作、可靠性验证，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：采用 RapidIO 总线的 DSP/FPGA 系统、多板卡互连、高性能计算与信号处理平台。RapidIO 并行接口（RIP）设计不在本文档范围内，RapidIO 与 PCIe 互操作（RIOPCIE）另文说明。

## 二、接口概述

SRIO 是 RapidIO 联盟定义的高速串行互连，核心特征如下：

- **物理层**：SRIO 1.0 支持 1.25/2.5/3.125/5.0Gbps，SRIO 2.0 扩展至 8.0/16.0Gbps；每通道（lane）1 对差分信号（TX+/TX-、RX+/RX-）+ 参考时钟。
- **通道数量**：x1、x2、x4、x8 配置，通道间偏斜要求 < 5ps（SRIO 2.0）/ < 50ps（SRIO 1.0）。
- **编码**：SRIO 1.0 采用 8b/10b 编码（BER < 10⁻¹²），SRIO 2.0 采用 128b/130b 编码（与 PCIe 兼容）；CRC 32 校验。
- **链路训练**：SRIO 链路训练遵循 PCI Express Base Spec 物理层规则，包括链路初始化、速率协商、均衡器训练（Tx Rx FOM）；训练完成时间 < 10ms。
- **路由拓扑**：SRIO 支持星型（Switch）、环型（Ring）、树型（Tree）与点对点拓扑；地址路由由设备 ID（SrcID/DestID）决定，支持路由表或地址匹配。
- **背板走线**：SRIO 信号走线阻抗 85Ω（单端）/ 100Ω（差分），走线长度 ≤ 20cm 时可不串接终端；超过 20cm 需评估反射与损耗。
- **参考时钟**：SRIO 1.0 使用 125MHz 差分参考时钟（HCSL），SRIO 2.0 支持 100MHz CDR（与 PCIe 3.0 兼容）；时钟抖动 < 1ps RMS。

## 三、物理层设计

### （一）信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| TXP / TXN | 发送 | 高速差分发送对，85Ω 单端 / 100Ω 差分 |
| RXP / RXN | 接收 | 高速差分接收对，85Ω 单端 / 100Ω 差分 |
| REFCLK_P / REFCLK_N | 参考时钟 | 125MHz HCSL 或 100MHz LVDS，共模 1.2V |
| PERST# | 复位 | 低电平有效，链路复位 |
| PRSNT# | 在位检测 | 检测对端是否插入 |

### （二）阻抗控制

SRIO 信号走线阻抗要求：

- **单端 85Ω**：背板与板卡单端走线（TX/RX）阻抗 85Ω ±10%，TDR 实测。
- **差分 100Ω**：TXP/TXN 与 RXP/RXN 差分阻抗 100Ω ±10%，TDR 实测。
- **等长匹配**：TX 对与 RX 对偏斜 < 5ps（SRIO 2.0），< 50ps（SRIO 1.0）；多 lane 系统各 lane 偏斜 < 5ps。
- **走线长度**：≤ 20cm（FR-4，4 层）无需串接终端；> 20cm 需评估 3dB 带宽与损耗。

### （三）终端策略

SRIO 发送端不串接终端（驱动器内部已含），接收端 100Ω 并接终端（差分对两端各 50Ω 至 GND）；参考时钟 100Ω 并接终端（HCSL 共模 1.2V，各 1kΩ 至 1.2V + 1kΩ 至 GND）。

### （四）参考时钟

SRIO 1.0 参考时钟要求：

- **频率**：125MHz（SRIO 1.0/2.0）或 100MHz（SRIO 2.0 CDR 模式）。
- **抖动**：RMS < 1ps（12~20MHz 带宽），峰峰值 < 5ps（12~20MHz 带宽）。
- **走线**：差分对等长匹配 < 5ps，走线长度 ≤ 10cm，下方完整 GND 铺铜，禁止开窗。
- **共模电压**：HCSL 共模 1.2V，通过 1kΩ 电阻提供；LVDS 共模 1.0V。

## 四、协议层设计

SRIO 链路层与事务层设计要点：

| 层级 | 要点 | 设计要求 |
| --- | --- | --- |
| 物理层 | 8b/10b 或 128b/130b 编码 | 编码/解码器时钟频率匹配，BER < 10⁻¹² |
| 链路层 | 链路训练、速率协商、均衡器 | 训练时间 < 10ms，支持 1.25~16Gbps 自动协商 |
| 事务层 | 读/写请求、响应、路由 | SrcID/DestID 分配，路由表或地址匹配 |
| 管理 | 链路状态、错误计数、热插拔 | 错误计数器上报，热插拔 PWR_OK 控制 |

拓扑设计：

- **星型（Switch）**：多设备通过 SRIO Switch 互联，地址由 Switch 路由表决定；Switch 端口感知各设备 ID。
- **点对点**：两台设备直连，SrcID/DestID 硬编码；最简单，适用于 2 设备系统。
- **环型（Ring）**：设备串成环，数据按环流动；适用于 3~5 设备系统，延迟可控。

## 五、收发操作时序

SRIO 链路训练时序：

1. **上电复位**：PERST# 低电平（≥ 100µs）→ 设备进入 Detect 状态。
2. **链路检测**：检测对端 PRSNT# → 进入 Polling 状态 → 发送 8b/10b K28.5 同步字。
3. **速率协商**：双方协商最高支持速率（1.25/2.5/5.0/8.0/16.0Gbps）→ 进入 Configuration 状态。
4. **均衡器训练**：Tx 端调整 FOM（Figure of Merit），Rx 端反馈 → 均衡收敛（< 5ms）。
5. **链路激活**：均衡收敛 → 进入 L0 状态 → 数据通信开始。
6. **热插拔**：PERST# 高电平（拔出）→ 链路进入 Detect 状态 → 重新插入 → 重新训练。

## 六、硬件设计要点

- **板框**：SRIO 板卡尺寸依系统而定，常见 100mm × 160mm（3U）或 100mm × 233.4mm（6U）。
- **连接器**：推荐 Molex SlimStack 系列（SRIO 专用）或 Samtec 高速连接器，镀层 30µin 镍 + 5µin 金；连接器插损 < 1.5dB @ 8GHz（SRIO 2.0）。
- **背板层叠**：12~16 层，信号层与 GND 层交替；SRIO 信号层阻抗 85Ω（单端）/ 100Ω（差分）；参考时钟走线独立层。
- **接地**：板卡 GND 铺铜与背板 GND 层通过 ≥ 4 pin 桥接；SRIO 差分对下方 GND 过孔密度 ≥ 每 5mm 一个。
- **散热**：SRIO 芯片功耗通常 3~8W，热沉 → 板框 → 导风板散热路径；热通量密度 < 30W/cm²。

## 七、典型应用场景

| 场景 | 配置 | 说明 |
| --- | --- | --- |
| DSP 信号处理 | 4× SRIO DSP 板 + Switch | 星型拓扑，5.0Gbps/lane，BER < 10⁻¹² |
| FPGA 互连 | 8× SRIO FPGA 板 | 环型拓扑，2.5Gbps/lane，低延迟 |
| 多板 HPC | 12× SRIO 计算板 | SRIO 2.0 16Gbps，树型拓扑 |
| 通信基带 | 6× SRIO 基带板 | 点对点，1.25Gbps，可靠互连 |

## 八、可靠性与测试验证

1. **TDR 阻抗测试**：单端 85Ω / 差分 100Ω，TDR 实测偏差 < ±10%；记录背板与板卡各段实测值。
2. **链路训练**：上电后 < 10ms 完成链路训练，速率协商正确（支持 1.25~16Gbps）。
3. **误码率**：SRIO 链路 BER < 10⁻¹²（CRC 32 错误计数，运行 24h）；各速率（1.25/2.5/5.0/8.0/16.0Gbps）均满足。
4. **均衡器收敛**：Tx/Rx 均衡器收敛时间 < 5ms，FOM 值稳定（± 0.1）。
5. **热插拔**：模拟 5000 次插拔，连接器插损变化 < 0.5dB @ 8GHz；链路训练成功率 100%。
6. **参考时钟抖动**：RMS < 1ps（12~20MHz），峰峰值 < 5ps；抖动测试仪器带宽 ≥ 50MHz。
7. **ESD 测试**：IEC 61000-4-2，接触放电 ±4kV（SRIO 连接器），空气放电 ±8kV；链路无复位、无 CRC 错误。
8. **温度循环**：-40°C~+85°C，100 循环，无连接器插损变化、无背板层间脱焊。

## 九、设计检查清单

1. SRIO 连接器型号已确认（Molex/Samtec），插损 < 1.5dB @ 8GHz，镀层规格匹配。
2. 信号走线阻抗：单端 85Ω / 差分 100Ω，TDR 实测偏差 < ±10%。
3. 多 lane 系统各 lane 偏斜 < 5ps（SRIO 2.0），< 50ps（SRIO 1.0），已标注。
4. 接收端 100Ω 并接终端已放置（差分对两端各 50Ω 至 GND）。
5. 参考时钟 125MHz HCSL 走线等长匹配 < 5ps，长度 ≤ 10cm，下方完整 GND 铺铜。
6. PERST# 信号已预留，低电平复位时间 ≥ 100µs。
7. PRSNT# 在位检测已预留，热插拔时 PWR_OK 控制正确。
8. GND 铺铜完整，SRIO 差分对下方 GND 过孔密度 ≥ 每 5mm 一个。
9. 已完成 TDR、链路训练、BER、均衡器、热插拔、ESD 测试，指标满足产品要求。
10. 若与 PCIe 互操作，SRIO 2.0 速率与编码（128b/130b）已确认兼容。

> 注：本文为 SRIO 接口的通用设计说明。具体项目的链路速率、拓扑结构、均衡器参数与可靠性指标最终以所用器件与系统的数据手册为准，关键指标应在样板阶段通过实测确定。

## 一、文档目的与适用范围

本文档规定硬件产品中 SerDes（Serializer/Deserializer）高速串行收发器接口的设计要求，覆盖 8b/10b 与 64b/66b/128b/130b 编码选择、CDR 与 PLL 时钟体系、lane 速率与通道配置、PCB 走线阻抗控制、终端策略、均衡器设计、可靠性验证，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：采用 SerDes 接口的高速信号传输系统，包括光模块互连、板内高速总线、机箱背板互连与无线基站前传。PCIe、SATA、JESD204B 等已有专项文章，本文聚焦通用 SerDes 设计原则。

## 二、接口概述

SerDes 是高速数字信号传输的物理层核心，核心特征如下：

- **编码体系**：8b/10b（经典，带宽开销 20%）、64b/66b（PCIe 3.0+，开销 3.1%）、128b/130b（PCIe 4.0+，开销 1.56%）、NRZ/PAM4（光模块，2 倍波特率）；编码选择决定 lane 速率与 CDR 复杂度。
- **lane 速率**：SerDes 支持 3.125Gbps（6G 光模块）至 112Gbps（PCIe 6.0 x1）；每 lane 1 对差分信号（TXP/TXN、RXP/RXN），多 lane 系统 x4/x8/x16 常见。
- **CDR（时钟数据恢复）**：接收端从数据流恢复时钟，支持自动速率协商；CDR 锁定时间 < 10ms，抖动传递 < 0.1UI。
- **PLL（锁相环）**：发送端 PLL 产生 SerDes 时钟，支持多速率切换（1~112Gbps）；PLL 抖动 RMS < 0.5ps。
- **均衡器**：发送端 Tx FFE（前馈均衡器）+ 接收端 Rx CTLE/DFE（连续时间线性均衡器/判决反馈均衡器），均衡收敛时间 < 5ms；均衡器参数由训练序列自动协商。
- **NRZ vs PAM4**：64Gbps 以下 NRZ 简单可靠；64Gbps 以上 PAM4（4 电平）带宽效率高 2 倍，但 EVM 要求 < -18dB；光模块 100G/400G 主流 PAM4。


## 三、物理层设计

### （一）信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| TXP / TXN | 发送 | SerDes 差分发送对，100Ω 差分 |
| RXP / RXN | 接收 | SerDes 差分接收对，100Ω 差分 |
| REFCLK_P / REFCLK_N | 参考时钟 | 125~312.5MHz，HCSL，共模 1.2V |
| PERST# | 复位 | 低电平有效，SerDes 全局复位 |
| PRSNT# | 在位检测 | 检测对端是否插入 |

### （二）编码与速率配置

SerDes 编码与 lane 速率配置表：

| 编码 | lane 速率 | 波特率 | 适用标准 | 典型应用 |
| --- | --- | --- | --- | --- |
| 8b/10b | 3.125Gbps | 3.125GBd | SGMII / 10GBase-T | 千兆以太网 |
| 8b/10b | 6.25Gbps | 6.25GBd | 6G 光模块 | 10GbE 光模块 |
| 64b/66b | 8.0/16.0Gbps | 8.0/16.0GBd | PCIe 3.0/4.0 | 高速互连 |
| 128b/130b | 16.0/32.0Gbps | 16.0/32.0GBd | PCIe 4.0/5.0 | 高速互连 |
| NRZ | 25.781Gbps | 25.781GBd | 100G 光模块 | 数据中心 |
| PAM4 | 53.125Gbps | 26.5625GBd | 400G/800G 光模块 | 数据中心 |

### （三）CDR 与 PLL 时钟体系

SerDes 时钟设计要求：

- **REFCLK**：外部晶振（125~312.5MHz）→ FPGA/ASIC 全局时钟 → SerDes PLL → 发送时钟；晶振抖动 RMS < 0.5ps（12~20MHz 带宽），峰峰值 < 2ps。
- **CDR**：接收端 CDR 从数据流恢复时钟，支持自动速率协商（1~112Gbps）；CDR 锁定时间 < 10ms，抖动传递 < 0.1UI（64b/66b）/ < 0.25UI（8b/10b）。
- **时钟切换**：多速率系统通过软件配置 SerDes PLL，切换时间 < 10ms；切换期间 CDR 重新锁定。
- **参考时钟分配**：多芯片系统参考时钟通过时钟芯片分配（如 SI5341A），各芯片 REFCLK 偏差 < 50ps。

### （四）PCB 走线阻抗控制

SerDes 信号走线阻抗要求：

- **差分 100Ω**：TXP/TXN 与 RXP/RXN 差分阻抗 100Ω ±10%，TDR 实测；走线长度 ≤ 20cm（FR-4，4 层）无需串接终端；> 20cm 需评估 3dB 带宽与损耗。
- **等长匹配**：TX 对与 RX 对偏斜 < 5ps（64b/66b），< 50ps（8b/10b）；多 lane 系统各 lane 偏斜 < 5ps（PCIe 3.0+）。
- **终端**：接收端 100Ω 并接终端（差分对两端各 50Ω 至 GND）；发送端不串接（SerDes 驱动器内部已含）。
- **过孔回折**：高速差分对走线回折会造成共模噪声，需使用过孔回折（via stub cancellation）或走线绕行；过孔 stub < 5mil。

### （五）均衡器设计

SerDes 均衡器配置：

| 均衡器 | 位置 | 参数 | 设计要求 |
| --- | --- | --- | --- |
| Tx FFE | 发送端 | 3~5 抽头，主抽头 0dB，旁抽头 -12~+6dB | 训练序列自动协商，收敛 < 5ms |
| Rx CTLE | 接收端 | 0~12dB 增益，3dB 带宽 0.5~2GHz | 均衡 3dB 带宽，收敛 < 5ms |
| Rx DFE | 接收端 | 2~4 抽头，主抽头 0dB | 消除 ISI，收敛 < 5ms |

均衡器参数在链路训练阶段自动协商（PCIe 3.0+ 支持），非 PCIe 系统需手动配置；均衡收敛后 BER 改善 > 10dB。


## 四、协议层设计

SerDes 协议层设计要点（以 PCIe 3.0 为例）：

| 层级 | 要点 | 设计要求 |
| --- | --- | --- |
| 物理层 | SerDes lane，64b/66b 编码 | 各 lane 独立训练，BER < 10⁻¹² |
| 链路层 | 链路训练、速率协商、均衡器 | 训练时间 < 10ms，支持 8.0/16.0Gbps |
| 事务层 | TLP 包（读/写/配置） | TLP 大小 4~128 字节，流量控制（FC credit） |

非 PCIe 系统（光模块、自定义互连）协议层设计需明确：

- **帧格式**：帧长、帧头、CRC 校验（CRC 8/16/32）、前导码（8 字节）；帧长 16~128 字节。
- **流控**：背压（credit-based）或丢弃（best-effort）；credit 数量 = 帧长 × 管道深度。
- **QoS**：多队列（4~8 队列），每队列独立 credit；优先级 0~7。


## 五、收发操作时序

SerDes 链路训练时序（以 PCIe 3.0 为例）：

1. **上电复位**：PERST# 低电平（≥ 100µs）→ SerDes 进入 Detect 状态 → 链路无数据。
2. **链路检测**：检测对端 PRSNT# → 进入 Polling 状态 → 发送 64b/66b K28.5 同步字。
3. **速率协商**：双方协商最高支持速率（8.0/16.0/32.0Gbps）→ 进入 Configuration 状态。
4. **均衡器训练**：Tx FFE + Rx CTLE/DFE 自动收敛（< 5ms）→ 均衡收敛。
5. **链路激活**：均衡收敛 → 进入 L0 状态 → 数据通信开始。
6. **热插拔**：PERST# 高电平（拔出）→ 链路进入 Detect 状态 → 重新插入 → 重新训练。


## 六、硬件设计要点

- **板框**：SerDes 板卡尺寸依系统而定，常见 100mm × 160mm（3U）或 100mm × 233.4mm（6U）；SerDes 芯片靠近连接器放置，走线 < 5cm。
- **连接器**：推荐 Molex SlimStack 系列（SerDes 专用）或 Samtec 高速连接器，插损 < 1.5dB @ 16GHz（PCIe 4.0）；镀层 30µin 镍 + 5µin 金。
- **SerDes 芯片选型**：根据 lane 数与速率选择——Xilinx GTH（6~8 lane，3.125~26.5625Gbps）、Intel CDR（1~8 lane，3.125~32.0Gbps）、TI CDR（1~4 lane，6.25~14.2Gbps）；光模块 SerDes 集成在 DSP（如 Marvell Credo）内。
- **背板层叠**：12~16 层，SerDes 信号层阻抗 100Ω（差分）；参考时钟独立层，走线长度 ≤ 10cm。
- **散热**：SerDes 芯片功耗 3~10W，热沉 → 板框 → 导风板散热路径；多 lane 系统散热路径独立。


## 七、典型应用场景

| 场景 | 配置 | 说明 |
| --- | --- | --- |
| 10GbE 光模块 | 4× 6.25Gbps SerDes | 8b/10b 编码，BER < 10⁻¹² |

## 八、可靠性与测试验证

1. **TDR 阻抗测试**：差分 100Ω，TDR 实测偏差 < ±10%；记录背板与板卡各段实测值。
2. **链路训练**：上电后 < 10ms 完成 CDR 锁定与链路训练；各速率（3.125~112Gbps）均满足。
3. **误码率**：SerDes 链路 BER < 10⁻¹²（CRC 32 错误计数，运行 24h）；各速率均满足。
4. **均衡器收敛**：Tx FFE + Rx CTLE/DFE 收敛时间 < 5ms，均衡后 BER 改善 > 10dB。
5. **眼图测试**：6G 光模块眼高 > 25mV，眼宽 > 50UI；100G PAM4 EVM < -18dB；记录各速率眼图实测值。
6. **热插拔**：模拟 5000 次插拔，连接器插损变化 < 0.5dB @ 16GHz；链路训练成功率 100%。
7. **参考时钟抖动**：RMS < 0.5ps（12~20MHz），峰峰值 < 2ps；晶振选型 125~312.5MHz，抖动指标满足。
8. **ESD 测试**：IEC 61000-4-2，接触放电 ±4kV（SerDes 连接器），空气放电 ±8kV；链路无复位、无 CRC 错误。
9. **温度循环**：-40°C~+85°C，100 循环，无连接器插损变化、无背板层间脱焊。


## 九、设计检查清单

1. SerDes 连接器型号已确认（Molex/Samtec），插损 < 1.5dB @ 16GHz，镀层规格匹配。
2. 编码与 lane 速率已确认（8b/10b / 64b/66b / 128b/130b / NRZ / PAM4），匹配系统带宽需求。
3. 信号走线阻抗：差分 100Ω，TDR 实测偏差 < ±10%。
4. 多 lane 系统各 lane 偏斜 < 5ps（64b/66b），< 50ps（8b/10b），已标注。
5. 接收端 100Ω 并接终端已放置（差分对两端各 50Ω 至 GND）。
6. 参考时钟 125~312.5MHz HCSL 走线等长匹配 < 5ps，长度 ≤ 10cm，下方完整 GND 铺铜。
7. SerDes 芯片选型已确认（Xilinx/Intel/TI/Marvell），lane 数与速率匹配系统需求。
8. 均衡器参数已配置（Tx FFE 3~5 抽头，Rx CTLE 0~12dB），收敛时间 < 5ms。
9. GND 铺铜完整，SerDes 差分对下方 GND 过孔密度 ≥ 每 5mm 一个。
10. 已完成 TDR、链路训练、BER、均衡器、眼图、热插拔、ESD 测试，指标满足产品要求。

> 注：本文为 SerDes 接口的通用设计说明。具体项目的编码、lane 数、速率、均衡器参数与可靠性指标最终以所用 SerDes 器件与系统协议的数据手册为准，关键指标应在样板阶段通过实测确定。

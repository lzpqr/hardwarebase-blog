电感是硬件工程师最容易"想当然"的磁性器件。一颗 4.7µH 的功率电感，看着和另一颗同标称值的电感没有区别，但磁芯材料、绕线工艺、屏蔽方式不同，饱和电流、损耗、温升可能相差一大截。选型失败很少是"算错了"，而是"只算了其中一个维度"。

**电感选型的本质**，是在感值 L、饱和电流 I_sat、温升电流 I_rms、直流电阻 DCR、自谐振频率 SRF、尺寸与成本这六个相互拉扯的约束之间，找到满足系统指标的那个平衡点。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。建议先阅读[电阻篇](/posts/component-selection-resistor/)与[电容篇](/posts/component-selection-capacitor/)。

## 1. 先定应用族，再谈参数

不同应用对参数的主次要求差异极大，先明确"用在哪"，再谈"怎么选"。

| 应用族 | 典型电路 | 第一优先参数 | 次要但不可忽略 |
| --- | --- | --- | --- |
| 功率储能 | Buck / Boost / Buck-Boost | 饱和电流 I_sat、温升电流 I_rms | DCR、磁芯损耗、体积 |
| EMI 滤波 | 共模扼流圈、差模电感 | 阻抗-频率特性、共模抑制比 | 漏感、绕组间电容、安规距离 |
| 射频/信号 | LC 匹配、偏置扼流、谐振 | Q 值、SRF、容差 | 寄生电容、温度系数、屏蔽 |
| 通用储能滤波 | π 型滤波、去耦、缓冲 | 感值精度、额定电流 | DCR、封装、可焊性 |

**选型第一原则**：先定义电流波形，再谈感值。电感是电流的"存储器"，所有关键约束（峰值电流、RMS 电流、纹波率）都来自电流波形。波形没算清，后面所有计算都是空中楼阁。

留 20%~30% 降额余量，是工程冗余而非保守。磁芯在接近饱和区时感值急剧下降，温度升高又会进一步降低饱和点，形成正反馈。

## 2. 核心参数逐项拆解

### 2.1 电感量 L

电感量决定纹波电流的大小，是设计的起点而非终点。在 Buck 电路中，感值与纹波电流成反比：

```
L = V_out × (1 − D) / (f_sw × ΔI_L)
```

其中 D = V_out / V_in 为占空比，f_sw 为开关频率，ΔI_L 为期望的峰峰值纹波电流。

工程经验：纹波率 r = ΔI_L / I_out 通常取 0.2 ~ 0.4。r < 0.2 意味着感值过大，体积和 DCR 白白增加；r > 0.4 则峰值电流过高，开关管与输出电容压力陡增，轻载时也更容易进入 DCM 导致环路特性变化。

**关键**：电感量随直流偏置电流上升而下降（DC Bias 特性），标称 4.7µH 的功率电感在满载下可能只剩 2.5µH。选型时必须查看厂商提供的 L-I 曲线，而不是只看标称值。

### 2.2 饱和电流 I_sat 与温升电流 I_rms

这是功率电感选型中最关键、也最容易混淆的一对参数。

| 参数 | 定义 | 工程意义与选取准则 |
| --- | --- | --- |
| I_sat | 磁芯开始显著饱和、电感量跌落到标称值的某一比例（常见 −10% 或 −20% 定义）时的直流电流 | 决定抗瞬态能力。建议 I_peak ≤ 70%~80% × I_sat(−10% 定义值) |
| I_rms | 使电感温升达到规定值（常见 40K）的 RMS 电流 | 决定发热能力。建议 I_rms(实际) ≤ 70%~80% × I_rms(额定) |
| I_DC | 使电感量跌落 30% 时的直流偏置电流 | 部分厂商采用此定义，数值比 −10% 定义更大。跨厂商对比时必须核对定义口径 |

**跨厂商对比的头号陷阱**：同样是"4.7µH / 10A"的两颗电感，A 厂的 10A 按 −10% 定义，B 厂按 −30% 定义，实际抗饱和能力可能相差 40% 以上。务必拉取两颗料完整的 L-I 曲线，在同一跌落比例下（例如都看 −20%）比较电流值，才能得出正确结论。

### 2.3 直流电阻 DCR

DCR 直接决定铜损，是效率与温升的主要贡献者：

```
P_cu = I_rms² × DCR
```

注意 I_rms 是考虑纹波后的总有效值，而非单纯的输出直流电流。

DCR 的负向影响不止于功耗：它会产生直流压降（I_out × DCR），在低压大电流输出（如 0.8V / 30A）场景下可能吃掉可观的电压裕量，直接影响负载调整率。同时 DCR 还是电流采样（DCR 检测）方案的采样元件，此时需关注其精度与温度漂移（铜的电阻温度系数约 +3900 ppm/°C）。

**选型建议**：在满足饱和电流与体积约束的前提下优先选低 DCR 型号；但低 DCR 往往意味着更粗的线径或更大的磁芯，会推高成本与体积，需要权衡。

### 2.4 自谐振频率 SRF

实际电感并非理想元件，其等效模型为 L 与寄生电容 C_p 并联（再串联 DCR 与交流电阻）。频率升高到某一值时，L 与 C_p 发生并联谐振，阻抗达到最大值；超过该频率后电感呈现容性，滤波能力急剧下降。

```
SRF = 1 / (2π √(L × C_p))
```

**选取准则**：工作频率（含主要谐波频段）应低于 SRF 的 1/3 ~ 1/5。对于高频 DC-DC（1MHz 以上）和 EMI 滤波应用，SRF 是硬约束，必须逐颗核对。

### 2.5 品质因数 Q 值

Q 值反映电感储能与耗能之比，在射频与谐振电路中是核心指标：

```
Q = ωL / R_ac = 2πfL / R_ac
```

R_ac 为工作频率下的等效交流电阻，包含 DCR、趋肤效应与邻近效应带来的损耗。射频电感的 Q 值通常在其 SRF 之前某处达到峰值，工作点应选在 Q 值较高、且远低于 SRF 的频段。

## 2.6 其他不可忽视的参数

| 参数 | 说明 |
| --- | --- |
| 磁芯材料类型 | 铁氧体（高频低损耗、易饱和）、合金粉芯（软饱和、高 I_sat）、铁粉芯（低成本、损耗大）。材料决定损耗-饱和-成本的三角关系 |
| 磁屏蔽形式 | 屏蔽式（漏磁小、EMI 友好）、半屏蔽、非屏蔽（成本低但漏磁大，不适用于高密度布局） |
| 容差 | 功率电感常见 ±20%；射频电感需要 ±2% 或 ±5% 以保证谐振点精度 |
| 温度系数 | 感值随温度漂移，谐振与滤波类应用需关注 |
| 额定温度与温升 | 确认工作环境温度 + 自身温升后仍在材料限制内，注意磁芯居里温度 |
| 封装尺寸与焊盘 | 需与 PCB 封装、回流焊工艺、爬电距离匹配；大电流型号注意焊盘载流能力 |
| 安规认证 | EMI 滤波与市电侧应用需满足爬电距离、绝缘耐压、阻燃等级要求 |

**Boost / Buck-Boost 特别提示**：Boost 电路的电感电流等于输入电流，且纹波相对值更大；平均电流 I_L = I_out / (1 − D)，在最恶劣条件下可能显著高于输出电流，务必按此计算饱和裕量。

## 3. DC-DC 电源电感选型

### 3.1 选型流程（七步法）

1. 确定拓扑与工作条件：拓扑、V_in 范围、V_out、I_out(max)、开关频率 f_sw
2. 计算占空比与纹波电流：按最恶劣工况（最低 V_in、满载）计算 D 与 ΔI_L
3. 初选感值：由纹波率 r = 0.2~0.4 反推 L，得到感值区间
4. 计算电流应力：I_peak = I_out + ΔI_L/2；I_rms 按三角波有效值公式计算
5. 按电流应力筛选：要求 I_peak ≤ 80% I_sat，I_rms(实际) ≤ 80% I_rms(额定)
6. 核算损耗与温升：铜损 + 磁芯损耗，叠加环境温度后确认温升在允许范围内
7. 验证 SRF 与瞬态：确认工作频段低于 SRF/3，并做负载瞬态仿真或测试验证环路稳定性

### 3.2 关键计算公式（Buck 电路，CCM）

```
D      = V_out / V_in
ΔI_L   = (V_out × (1 − D)) / (f_sw × L)
L      = (V_out × (1 − D)) / (f_sw × ΔI_L)
I_peak = I_out + ΔI_L / 2
I_rms  = √(I_out² + ΔI_L² / 12)
```

I_peak 用于饱和判定，I_rms 用于铜损与温升判定。

### 3.3 降额与余量建议

| 项目 | 建议余量 | 说明 |
| --- | --- | --- |
| 峰值电流 vs I_sat | ≤ 80% | 考虑感值跌落、批次差异与最恶劣工况；关键电源建议 70% |
| RMS 电流 vs I_rms 额定 | ≤ 80% | 留出环境温度已偏高的余量 |
| 感值精度 | ±20% 起 | 对纹波敏感的应用选 ±10%，注意偏置导致的感值下降 |
| 工作频率 vs SRF | ≤ 1/3 | 谐波频段也需考虑，高频电源建议 1/5 |
| 温升 | ≤ 40K | 叠加最高环境温度后仍在磁芯与绝缘等级允许范围内 |
| DCR 引起的压降 | ≤ 输出 2%~3% | 低压大电流输出时尤其重要 |

### 3.4 五个高频踩坑点

1. 只看标称感值，忽略 DC Bias 特性——满载下感值可能腰斩，纹波远超设计值
2. 混淆 I_sat 与 I_rms 的定义口径——跨厂商直接比大小是最常见的错误
3. 用 DCR 直接乘输出电流算铜损——必须用含纹波的 RMS 电流
4. 忽略磁芯损耗——高频下磁芯损耗可能超过铜损，尤其大纹波、高 f_sw 场合
5. 只看电性能不看热与工艺——温升裕量、焊接可靠性、屏蔽方式同样决定方案成败

## 4. EMI/EMC 滤波电感选型

### 4.1 共模电感与差模电感

| 类型 | 作用与原理 | 选型关键点 |
| --- | --- | --- |
| 共模电感 | 两组绕组同向绕制，共模电流磁通叠加形成高阻抗；差模电流磁通相互抵消 | 共模阻抗-频率曲线、额定电流下的感值保持率、漏感（可兼职差模抑制）、绕组间耐压与爬电距离 |
| 差模电感 | 单个绕组，对差模噪声呈现高阻抗 | 饱和电流（差模电流即工作电流，容易饱和）、DCR、阻抗峰值频率与实际噪声频段是否重合 |

### 4.2 选型要点

- **先定位噪声频段，再选器件**。共模/差模噪声峰值频率不同（共模多在高频，差模多在中低频）。用近场探头或频谱仪确定主噪声频段后，选择在该频段阻抗最高的电感，而不是盲目堆感值。
- **关注额定电流下的感值保持率**。共模电感在通过工作电流后，磁芯偏置会降低有效感值。必须查厂商的阻抗-偏置电流曲线。
- **利用漏感做差模抑制**。共模电感的漏感通常在 0.5%~2%，可提供一定的差模抑制，设计时可将此纳入整体滤波网络考虑，减少一级滤波。
- **注意绕组间寄生电容**。它为高频共模噪声提供旁路通道，使高频段抑制效果大打折扣。分段绕制可降低寄生电容。
- **安规不可妥协**。市电侧应用需满足爬电距离、电气间隙、绝缘耐压与阻燃等级要求，需选用有安规认证的型号。

### 4.3 滤波结构与阻抗匹配

单个电感很少能解决问题，EMI 滤波器通常是 π 型或 T 型网络。设计要点：

- 滤波器的插入损耗取决于源阻抗与负载阻抗的失配程度，一味增大感值不如合理配置电容与磁珠分区。
- 对高频噪声，磁珠（本质是高频损耗型元件）+ 电容的组合往往比大感值电感更有效，可参考[磁珠/变压器篇](/posts/component-selection-bead-transformer/)。
- 注意滤波器自身的谐振点，避免在噪声频段内形成谐振放大而非衰减。

## 5. 射频/信号链路电感选型

射频电感关注的是"在特定频率上的阻抗特性与损耗"，而非储能能力，其选型逻辑与功率电感几乎相反。

| 维度 | 功率电感 | 射频电感 |
| --- | --- | --- |
| 首要指标 | I_sat、I_rms、DCR | Q 值、SRF、容差 |
| 损耗关注 | 铜损为主 | 交流电阻、介质损耗、辐射损耗 |
| 感值范围 | µH ~ mH | nH ~ 数百 nH |
| 容差要求 | ±20% 常见 | ±2% ~ ±5%（谐振点敏感） |
| 屏蔽要求 | 降低 EMI 泄漏 | 防止与邻近电路耦合、稳定 Q 值 |
| 仿真需求 | 通常不需要 | 强烈建议建立含寄生的等效模型并仿真 |

### 5.1 三大类型对比

| 类型 | Q 值 | 尺寸/一致性 | 适用场景 |
| --- | --- | --- | --- |
| 绕线式（Wire-wound） | 高（60~100+） | 尺寸大、一致性一般 | 对 Q 值要求极高的窄带匹配、低噪放偏置 |
| 薄膜式（Thin-film） | 很高（可达 100+） | 尺寸小、精度高 | 高频/毫米波链路、高精度匹配网络，成本较高 |
| 多层陶瓷（Multilayer） | 中（30~60） | 尺寸最小、一致性好 | 高密度集成、成本敏感、对 Q 值要求不极端的场合 |

### 5.2 选型要点

- **Q 值必须在工作频率上核对**。规格书给出的 Q 值通常标在特定频率（如 100MHz 或 1GHz），需查曲线确认工作频点的实际 Q 值。
- **工作频率应远低于 SRF**。经验值工作频率 ≤ SRF/3，窄带谐振电路建议 ≤ SRF/5，并留出容差与温漂余量。
- **容差影响谐振点**。LC 谐振频率与 √(LC) 成反比，感值 5% 的偏差会引起约 2.5% 的谐振频率偏移，窄带系统必须核算。
- **寄生模型不可忽略**。高频段封装的引线电感、焊盘电容都会显著影响性能，建议使用厂商提供的 S 参数或等效模型进行仿真。
- **留意直流偏置与温漂**。偏置扼流圈（Bias Tee）通过直流电流，需确认直流下感值下降是否可接受。

## 6. 通用选型检查清单

物料定板前逐项核对，可拦截绝大多数选型问题。

**电性能核对**

| # | 检查项 | 判定标准 |
| --- | --- | --- |
| 1 | 感值是否满足纹波/谐振要求 | 按最恶劣工况计算，考虑容差与 DC Bias 下降 |
| 2 | 峰值电流是否低于 I_sat | I_peak ≤ 80% I_sat（注意定义口径一致） |
| 3 | RMS 电流是否低于额定 I_rms | I_rms(实际) ≤ 80% I_rms(额定) |
| 4 | DCR 是否可接受 | 铜损与直流压降均在预算内 |
| 5 | 工作频率是否低于 SRF 的 1/3 | 含谐波频段一并核算 |
| 6 | 损耗与温升是否合规 | 铜损 + 磁芯损耗，叠加环境温度后余量充足 |
| 7 | Q 值/阻抗在目标频段是否达标 | 射频与 EMI 应用按实际频点核对曲线 |

**机械与工艺核对**

| # | 检查项 | 判定标准 |
| --- | --- | --- |
| 1 | 封装与 PCB 焊盘是否匹配 | 尺寸、引脚间距、焊盘载流能力 |
| 2 | 引脚与焊盘是否满足回流焊工艺 | 有无虚焊/立碑风险，钢网与焊盘设计合理 |
| 3 | 屏蔽形式是否满足 EMC 布局要求 | 高密度布局优先屏蔽式，降低相互耦合 |
| 4 | 安规距离是否满足 | 市电侧应用核对爬电距离、电气间隙、绝缘耐压 |
| 5 | 高度与结构是否受限于外壳 | 确认与机壳、散热器的间隙 |

**供应链与可制造性核对**

| # | 检查项 | 判定标准 |
| --- | --- | --- |
| 1 | 是否有多货源（Second Source） | 关键物料建议至少两家可替代，避免单一供应商风险 |
| 2 | 供货周期与生命周期 | 确认非停产料（NRND/EOL），长周期物料提前备货 |
| 3 | 成本与目标 BOM 是否匹配 | 在满足性能的前提下评估降本空间 |
| 4 | 是否有样片与仿真模型 | 射频与高频应用优先选提供 S 参数模型的厂商 |
| 5 | 温度等级与可靠性 | 工业级/车规级要求需核对认证与工作温度范围 |

**定板前的最后三问**

1. 最恶劣工况下，感值还够用吗？（最低 V_in、最高温度、最大负载）
2. 最恶劣工况下，电流还安全吗？（峰值 vs I_sat，RMS vs 额定）
3. 最恶劣工况下，温度还合规吗？（自身温升 + 环境温度 ≤ 材料限值）

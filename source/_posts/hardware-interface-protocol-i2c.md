## 一、文档目的与适用范围

本文档规定硬件产品中 I2C（Inter-Integrated Circuit）接口的电气设计、总线拓扑、上拉与负载计算、PCB 布局、可靠性设计及测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：单板内主控制器与外围器件（传感器、EEPROM、PMIC、RTC、IO 扩展、codec 等）之间的 I2C 互连设计。跨板长距离传输不在本文档范围内，应改用差分总线或中继缓冲方案。

## 二、接口概述

I2C 是由 Philips（现 NXP）定义的双线制同步串行总线，核心特征如下：

- **两线制**：串行数据线 SDA、串行时钟线 SCL，均为双向。
- **半双工同步**：同一时刻只有一个方向的数据流，时钟由主机提供。
- **开漏输出**：所有器件的 SDA/SCL 引脚必须为开漏（Open-Drain）或开集（Open-Collector）输出，配合外部上拉电阻实现"线与"逻辑。
- **多主多从**：支持总线仲裁与时钟同步，任一时刻只能有一个主设备占用总线。
- **地址寻址**：每个从设备有唯一地址，标准模式为 7 位地址，扩展支持 10 位地址。
- **速率等级**：标准 100kbps、快速 400kbps、快速增强 1Mbps、高速 3.4Mbps、超快 5Mbps。

I2C 的优势在于引脚占用极少、支持多设备挂接；代价是速率较低、通信距离短、总线电容受限。

## 三、物理层设计

物理层设计直接决定总线的电气可靠性，主要包括总线结构、速率等级选择、上拉电阻与总线电容计算，以及多电压域共存时的电平转换处理。

### （一）总线结构与引脚

总线由 SDA、SCL 两条信号线加一根共地 GND 构成。所有器件的 SDA 并联到 SDA 总线，SCL 并联到 SCL 总线。开漏结构决定了总线只能被拉低，无法主动拉高，因此必须为每条线配置上拉电阻。

### （二）速率模式与电气参数

| 模式 | 速率 | 备注 |
| --- | --- | --- |
| 标准模式 Standard | 100 kbps | 兼容性最好 |
| 快速模式 Fast | 400 kbps | 最常用 |
| 快速增强 Fast-mode Plus | 1 Mbps | 要求更强的下拉驱动 |
| 高速模式 Hs | 3.4 Mbps | 需额外的高速主设备代码 |
| 超快模式 UFm | 5 Mbps | 单向、推挽，极少用 |

逻辑电平门限（以 3.3V 系统为例）：输入低电平上限约 0.3×VDD，输入高电平下限约 0.7×VDD。设计时应以器件数据手册的 VIH/VIL 实测值为准。

### （三）总线电容与上拉电阻计算

规范限定总线总电容不超过 400 pF（快速模式）。总电容由各器件引脚电容、PCB 走线寄生电容与连接器电容累加而成，应在器件选型阶段即完成估算。

上拉电阻 Rp 的设计受两个边界约束：

- **最小值（由灌电流决定）**：保证输出低电平时，器件能可靠拉低到 VOL 以下。
- **最大值（由上升时间决定）**：保证上升沿在规定时间内完成。

```text
Rp(min) = ( VDD − VOL(max) ) / IOL
Rp(max) = tr / ( 0.8473 × Cb )
```

工程常用取值：400kbps、总线电容约 100~200pF 时，3.3V 系统典型上拉为 2.2kΩ~4.7kΩ；100kbps 场合可放宽到 4.7kΩ~10kΩ。速率越高、总线电容越大，上拉电阻应越小。

### （四）电平转换设计

当总线上存在不同电压域（如 1.8V 与 3.3V 器件混挂）时，应使用专用双向电平转换器件或由 NMOS 管构成的双向电平移位电路，禁止通过电阻分压简单处理。上拉电阻应分别接到各自电压域对应的电源。

## 四、协议层设计

协议层定义了总线的帧结构与传输规则，是保证多设备共存、数据正确性与异常可恢复的基础，设计时必须完整落实以下各项机制。

- **起始与停止条件**：起始 S 为 SCL 高电平期间 SDA 由高变低；停止 P 为 SCL 高电平期间 SDA 由低变高。二者均由主机产生，总线在起止之间处于"忙"状态。
- **数据有效性**：SDA 上的数据必须在 SCL 高电平期间保持稳定，仅允许在 SCL 低电平期间改变。每个时钟脉冲传输一位，高位（MSB）先行。
- **寻址格式**：7 位地址模式下首字节为 7 位从机地址 + 1 位读写方向位（0 写 / 1 读），共 128 个地址，其中若干为保留地址；10 位地址以特定前缀字节扩展，支持 1024 个地址，用于地址资源紧张的场景。
- **应答机制**：每传输完一个字节（8 位），接收方必须在第 9 个时钟周期拉低 SDA 作为应答（ACK）；保持高电平则为非应答（NACK）。主机读操作读取最后一个字节后应返回 NACK，通知从机结束传输。
- **重复起始条件**：主机在不发送停止条件的情况下再次发送起始条件，用于在不释放总线的情况下切换读写方向或切换目标从机。典型应用于"写寄存器地址 → 读寄存器数据"的组合操作。
- **时钟同步与仲裁**：多个主设备同时驱动 SCL 时，总线表现为所有时钟的"与"，由最长的低电平决定实际时钟；多主竞争时各主机在发送数据的同时监测 SDA，发送高电平却检测到总线为低时立即退出竞争并转为从机接收模式，仲裁失败方不丢失数据完整性。
- **时钟延展**：从设备若需要更多处理时间，可在接收完字节后将 SCL 拉低保持，迫使主机进入等待状态，直到从机释放 SCL。主机软件或 I2C 控制器必须支持该特性，否则与慢速器件通信会失败。

## 五、读写操作时序

绝大多数传感器与存储类器件采用"寄存器地址 + 数据"的访问模型，需通过重复起始条件完成先写后读的切换。

**写操作**：起始条件 → 发送从机地址（写）→ 等待 ACK → 发送寄存器地址 → 等待 ACK → 连续发送数据字节 → 每字节等待 ACK → 停止条件。

**读操作**：对 EEPROM、传感器等带寄存器地址映射的器件，标准流程为：起始条件 → 写器件地址 → 写寄存器地址 → 重复起始条件 → 读器件地址 → 连续读取数据字节 → 最后字节返回 NACK → 停止条件。

**页写限制与写周期等待**：EEPROM 类器件存在页写边界（典型 8~64 字节）与内部写周期（典型 5~10ms）。跨页写入会发生地址回卷，写周期内器件不应答，须采用轮询应答方式确认写完成。

## 六、硬件设计要点

- **上拉电阻配置**：每条总线仅需一组上拉（SDA、SCL 各一个），禁止在每个器件上重复放置上拉，避免并联导致等效阻值过小、灌电流超标。
- **总线扩展**：挂载器件过多导致电容超标时，应使用 I2C 缓冲器/中继器（如 PCA9515 类）分段隔离，或选用 I2C 多路复用器（如 PCA9548 类）分时复用。
- **总线隔离与热插拔**：支持热插拔的接口应使用带总线缓冲的隔离器件，避免插拔瞬间锁定总线。
- **ESD 防护**：对外引出的 I2C 需配置 ESD 保护器件，选型时注意保护器件的结电容不得使总线电容超标。
- **PCB 布局**：SDA 与 SCL 应平行走线、长度尽量一致并避免跨分割；远离高频、大电流与开关电源节点；走线尽可能短以控制寄生电容；必要时加包地保护。
- **串联保护电阻**：在从机 SDA/SCL 引脚处可串联小阻值电阻（典型 10~100Ω），抑制振铃并限制插拔浪涌，但需评估对上升时间的影响。
- **电源与地址去耦**：每个从机就近放置去耦电容；多器件同地址时，优先通过地址引脚配置区分，避免依赖软件分时。

## 七、典型应用场景

| 应用对象 | 典型器件 | 设计关注点 |
| --- | --- | --- |
| 参数存储 | EEPROM（24Cxx 系列） | 写周期等待、页写边界、WP 写保护引脚 |
| 环境感知 | 温湿度 / 加速度 / 陀螺仪 | 采样率与转换时间的等待策略、中断引脚配合 |
| 电源管理 | PMIC / 充电管理 IC | 电压域匹配、上电时序、电流检测精度 |
| 实时时钟 | RTC | 备份电源切换、32.768kHz 晶振布局 |
| IO 扩展 | GPIO 扩展芯片 | 中断输出聚合、端口驱动能力 |
| 人机接口 | 触摸 IC、背光驱动 | 中断线走线、刷新率对总线占用率的计算 |

## 八、可靠性与测试验证

I2C 的工程问题大多集中在电气裕量不足与总线锁定两类，应在设计阶段建立典型故障模式清单，并在调试与测试阶段逐条验证。

**常见故障模式**：

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 通信完全无响应 | 地址错误、上拉缺失、器件未上电 | 核对器件地址与读写位；确认上拉电阻已焊接；测量器件供电 |
| 偶发通信失败 | 上拉过大、总线电容超标、时序裕量不足 | 减小上拉阻值；分段加缓冲器；降低通信速率验证 |
| 总线死锁（SDA 常低） | 从机异常拉住总线、上电时序异常 | 主机发送 9 个以上时钟脉冲尝试释放；复位从机；必要时硬件复位从机电源 |
| 多器件互相干扰 | 地址冲突、NACK 处理不当 | 核对地址表；修正软件对 NACK 的处理逻辑 |
| 高速下波形畸变 | 上升沿过缓、反射、走线过长 | 观测上升时间是否满足规范；缩短走线、优化上拉 |

**测试要点**：

- 电气参数测量：使用示波器测量 SCL 频率、SDA/SCL 上升下降时间、低电平 VOL，确认全部满足所选速率模式的规范要求。
- 总线空闲电平：空闲时 SDA、SCL 均应稳定为高电平。
- 时序裕量：在高低温、极限电压条件下重复测量，确认建立保持时间与上升时间的裕量充足。
- 压力测试：连续读写循环应覆盖写周期等待、跨页写、重复起始等关键路径，统计误码与重试次数。
- 异常恢复：人为制造总线锁定，验证主机的总线恢复机制（时钟脉冲恢复或从机电源复位）是否有效。

## 九、设计检查清单

1. 已确认总线上所有器件均支持目标速率模式。
2. 已完成总线电容估算并确认不超过 400pF，余量充足。
3. 已按公式计算并确认上拉电阻落在 Rp(min) 与 Rp(max) 之间。
4. 全总线仅一组上拉电阻，无重复上拉。
5. 已核对全部从机地址无冲突，地址引脚配置已固化。
6. 存在电平转换需求时已采用专用电平转换器件。
7. SDA/SCL 走线短、平行、远离干扰源，未跨分割。
8. 对外引出接口已配置 ESD 防护且结电容合格。
9. 主机侧软件支持时钟延展与 NACK 处理。
10. 已定义总线锁定场景的恢复策略。
11. 已完成高低温与极限电压下的时序裕量验证。

> 注：本文为 I2C 接口的通用设计说明，具体项目的电气参数最终以所用主控制器与从器件的数据手册为准，上拉电阻应在样板阶段通过实测微调确定。

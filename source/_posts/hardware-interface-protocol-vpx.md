## 一、文档目的与适用范围

本文档规定硬件产品中 VPX（VMEbus Performance eXtension）背板/插卡接口的设计要求，覆盖插座槽位与引脚定义、12V 电源分配、高速信号（GTH/GENICAM 时钟、PCIe、USB 3.x）完整性、VPX Star 与 VPX 75Ω 变体识别、板框与连接器选型、背板走线、ESD/EMC 验证，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：采用 VPX 或 VME 总线插槽的板卡系统、嵌入式机箱与机箱内背板。标准 VME 总线接口设计不在本文档范围内，VXI、PICMG 1.0/3.0 等其他机箱总线另文规定。

## 二、接口概述

VPX 由 SEABORG（System Engineering And Board Optimization Group）定义，是 VME 总线的电气扩展，核心特征如下：

- **槽位与引脚**：VPX 插座分 A 侧（短信号）与 B 侧（长信号），共 12 排 × 24 列（288 引脚）；A 侧 15 mm、B 侧 16.5 mm，比 VME 短，减少 EMI 漏出。
- **12V 电源**：VPX 将 VME 的 5V 主电源扩展为 12V，配合板内 DC-DC 降压，降低背板 I²R 损耗，是 VPX 相对 VME 最重要的电气改进。
- **高速信号区**：A 侧 1~8 排保留 VME 总线定义（地址、数据、中断、状态），B 侧 9~12 排预留给高速差分对（PCIe、USB、以太网、GENICAM 等），需按 VPX Star 或 VPX 75Ω 走线。
- **VPX Star**：SEABORG 提出的增强版，在 A/B 侧增加 PWR、SIGNAL、GND 引脚重新分配，改善电源分配与信号隔离。
- **VPX 75Ω 变体**：背板高速信号阻抗标称 75Ω（单端）或 100Ω（差分），需与连接器厂商确认实际值，与 50Ω 系统兼容但走线规则不同。
- **背板层数**：VPX 背板常见 12~16 层，高速信号层需满足阻抗控制（50Ω 单端 / 100Ω 差分），层间隔离与电源分配网格是关键。

## 三、物理层设计

### （一）插座与引脚定义

| 排号 | A 侧 | B 侧 | 说明 |
| --- | --- | --- | --- |
| 1~4 | VME 地址/数据 | VME 地址/数据 | 32-bit 总线，5V 兼容 |
| 5~6 | VME 状态/中断 | VME 状态/中断 | 中断向量、DRQ/SRQ |
| 7~8 | 12V 电源 + 信号 | 12V 电源 + 信号 | VPX 新增 12V PWR1/PWR2 |
| 9~12 | 高速差分区 | 高速差分区 | PCIe / USB / 以太网 |

A 侧与 B 侧的接地引脚在 12V 电源分配上交替排列，板卡插入时 A 侧先接触（短盲插保护），B 侧后接触（信号先通），顺序不可颠倒。

### （二）12V 电源分配

VPX 12V 电源由背板直接分配至各插槽，板内 DC-DC 降压至 3.3V/1.8V/1.2V 等。背板走线规则：

- 12V 走线宽度按 3A/槽位、0.5mm 线宽计算（约 40mΩ/slot），多槽位系统需在背板增加 12V 铜皮扩展。
- PWR 引脚每槽独立，禁止跨槽并联；若系统功耗超标需评估背板 12V 总线容量。
- 板内 DC-DC 输入电容：≥ 10µF（陶瓷）+ 100µF（电解），去耦电容就近放置，ESR < 25mΩ @ 100kHz。

### （三）高速信号完整性

B 侧 9~12 排高速差分对设计要求：

- **阻抗**：单端 50Ω（VPX 标准）或 75Ω（VPX 75Ω 变体），差分 100Ω；背板与板卡阻抗偏差 < ±10%。
- **等长匹配**：PCIe 各 lane 间偏斜 < 5ps，USB 3.x D+/D- 偏斜 < 1ps；在连接器焊盘处预留等长蛇形余量。
- **回折避免**：高速差分对走线回折会造成共模噪声，需使用过孔回折（via stub cancellation）或走线绕行。
- **串接终端**：PCIe/USB 信号在发送端串接 20~50Ω 电阻，接收端不串接；100Ω 差分对在两端各 50Ω 并接终端。
- **GND 铺铜**：高速信号层下方必须铺完整 GND 层，禁止开窗；背板与板卡 GND 铺铜区域对齐。

### （四）ESD 与 EMC

- 背板对外接口（A 侧 1~4 排）预留 ESD 保护：TVS 阵列（双向，Vcl 3.3V，Cj < 0.5pF），每信号独立保护。
- 板卡 EMI 缝隙：VPX 插座与背板配合面加导电衬垫（conductive gasket），缝隙 < 0.5mm；整机屏蔽覆盖率 ≥ 90%。
- 背板走线远离机箱金属框架，避免形成天线；高速信号层与电源层之间加 1mm 以上空气间隔。

## 四、协议层设计

VPX 信号层协议随背板系统而异，常见组合：

| 应用场景 | 信号类型 | 速率 | 协议层要求 |
| --- | --- | --- | --- |
| 嵌入式图像处理 | GENICAM / 以太网 | 1~10 Gbps | 100Ω 差分，背板走线 ≤ 30cm |
| 多 GPU 互联 | PCIe 3.0/4.0 | 8~16 GT/s | 等长 ± 5ps，背板走线 ≤ 15cm |
| 高速数据采集 | LVDS / 自定义 | 100Mbps~1Gbps | 50Ω 单端，串接终端 |
| 机箱管理 | I2C / 1-Wire | 100kHz | 背板公共总线，上拉 10kΩ 至 3.3V |

协议层设计需在原理图阶段完成：信号方向、差分/单端、终端策略、时钟频率、背板与板卡阻抗匹配表。

## 五、收发操作时序

VPX 插拔时序与 VME 兼容，但 12V 电源区有额外约束：

1. **插入顺序**：A 侧（短）先接触 → B 侧（长）后接触；12V 电源在 A 侧 7~8 排，先于信号区通电。
2. **盲插保护**：连接器导向柱（pilot）先于信号 pin 接触，导向柱材料硬度 > 信号 pin，防止插拔磨损。
3. **上电时序**：12V PWR 先建立 → 板内 DC-DC 输出 → 高速信号使能（CE/RESET 脉冲）→ 总线通信。
4. **热插拔**：VPX 不原生支持热插拔；若系统要求热插拔，需在背板增加电流检测与过流保护（每槽 3A 保险丝）。

## 六、硬件设计要点

- **板框**：VPX 板卡板框尺寸 160mm × 233.4mm（3U）或 160mm × 297mm（6U），公差 ±0.1mm；板框角部加导电衬垫，与机箱屏蔽框接触电阻 < 10mΩ。
- **连接器**：推荐 Molex 105214 系列（VPX 专用）或 Samtec TSW 系列，镀层 30µin 镍 + 5µin 金；避免使用普通 VME 连接器替代 VPX，引脚间距不同。
- **背板层叠**：12~16 层，信号层与 GND 层交替；12V 电源层独立，厚度 ≥ 1oz 铜；高速信号层阻抗 50Ω/100Ω 控制。
- **接地**：板卡 GND 铺铜与背板 GND 层通过多 pin 桥接（≥ 4 pin），接触电阻 < 10mΩ；避免单点接地。
- **散热**：VPX 板卡散热路径：芯片 → 热沉 → 板框 → 机箱导风板；热沉与板框之间加导热垫（≥ 1W/mK），导风板风速 ≥ 2m/s。

## 七、典型应用场景

| 场景 | 配置 | 说明 |
| --- | --- | --- |
| 多板图像处理系统 | 4× VPX 图像处理板 + 1× 管理板 | GENICAM 10GbE 互联，背板 16 层 |
| 雷达信号处理 | 8× VPX DSP 板 | PCIe 3.0 x16 互联，背板走线 ≤ 10cm |
| 军事/航空机载 | 3U VPX 机箱 | 符合 VITA 46/48，宽温 -40~+85°C |
| 测试测量 | 10 槽 VPX 机箱 | LXI / USB 互联，支持热插拔 |

## 八、可靠性与测试验证

1. **阻抗测试**：TDR 测量背板与板卡高速信号阻抗，偏差 < ±10%；记录 50Ω 单端与 100Ω 差分实测值。
2. **回波损耗**：S11 在 0~2.5GHz（PCIe 3.0）内 < -15dB；在 0~8GHz（PCIe 4.0）内 < -15dB。
3. **误码率**：PCIe 链路 BER < 10⁻¹²（误码计数器，运行 24h）；GENICAM 以太网 CRC 错误率 < 10⁻⁹。
4. **热插拔应力**：模拟 5000 次插拔，连接器接触电阻变化 < 5mΩ；导向柱磨损 < 0.05mm。
5. **ESD 测试**：IEC 61000-4-2，接触放电 ±4kV（A 侧），空气放电 ±8kV；系统无复位、无数据丢失。
6. **EMC 辐射**：IEC 61000-6-3，30MHz~1GHz 辐射 < 30dBµV/m（3m）；屏蔽覆盖率 ≥ 90%。
7. **12V 电源波动**：满载时背板 12V 跌落 < 5%；板内 DC-DC 输出纹波 < 50mVpp。
8. **温度循环**：-40°C~+85°C，100 循环，无连接器引脚松动、无背板层间脱焊。

## 九、设计检查清单

1. 板框尺寸 160mm × 233.4mm（3U）或 297mm（6U），公差 ±0.1mm，已确认。
2. VPX 连接器型号已确认（Molex/Samtec），镀层规格匹配，盲插导向柱已预留。
3. A 侧 7~8 排 12V PWR 引脚已分配，板内 DC-DC 输入电容 ≥ 10µF + 100µF 已放置。
4. 高速信号层阻抗控制：单端 50Ω / 差分 100Ω，TDR 实测偏差 < ±10%。
5. PCIe lane 等长匹配 < 5ps，USB D+/D- 偏斜 < 1ps，已标注。
6. 高速差分对走线回折已消除，过孔回折或走线绕行已完成。
7. 串接终端：发送端 20~50Ω，接收端不串接；100Ω 差分两端各 50Ω 并接，已确认。
8. GND 铺铜完整，高速信号层下方无开窗；背板与板卡 GND 桥接 ≥ 4 pin。
9. ESD 保护：A 侧对外接口 TVS 阵列已放置，Vcl 3.3V，Cj < 0.5pF。
10. 板框导电衬垫已加，缝隙 < 0.5mm；屏蔽覆盖率 ≥ 90%。
11. 散热路径：芯片 → 热沉 → 板框 → 导风板，导热垫 ≥ 1W/mK，风速 ≥ 2m/s。
12. 已完成 TDR、S11、BER、ESD、EMC 测试，指标满足产品要求。

> 注：本文为 VPX 接口的通用设计说明。具体项目的槽位数量、背板层叠、高速信号规格与可靠性指标最终以所用连接器与机箱系统的数据手册为准，关键指标应在样板阶段通过实测确定。

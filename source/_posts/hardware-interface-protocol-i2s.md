## 一、文档目的与适用范围

本文档规定硬件产品中 I2S（Inter-IC Sound）数字音频接口的电气设计、时钟体系与主从配置、帧格式与对齐方式、多通道 TDM 扩展、PCB 布局、音质可靠性设计及测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：单板内主控制器与音频器件（Codec、ADC/DAC、数字功放、音频模组、DSP）之间的立体声或多通道 PCM 音频数据传输。麦克风前端的模拟放大滤波与 Class-D 功率输出级不在本文档范围内；采用 PDM 调制的数字麦克风不属于 I2S 接口，其设计要求另行规定。

## 二、接口概述

I2S 由 Philips（现 NXP）于 1986 年定义，是专为数字音频设计的三线制串行接口，核心特征如下：

- **三线制基本信号**：BCLK 或 SCK（位时钟）、WS 或 LRCK（字选择/左右声道时钟）、SD（串行数据），加一根共地 GND；多数场合还需要额外的 MCLK（主时钟）。
- **单向数据流**：一条 SD 线只承载一个方向的数据，因此 I2S 是单工接口。实现录音与播放同时进行需要两条 SD 线（SDOUT 与 SDIN），或改用 TDM 复用。
- **同步串行**：数据与位时钟、字时钟严格同步，接收端无需像异步串口那样判断速率。
- **数据与时钟分离**：音频时钟的质量直接决定重放音质，时钟抖动会劣化信噪比与失真指标，这是 I2S 与普通数字接口在设计上最大的不同。
- **MSB 先行**：每个声道的采样数据高位先发，字长常见 16、20、24、32 位。
- **采样率族**：常见 8k、16k、44.1k、48k、96k、192kHz，其中 44.1kHz 系列与 48kHz 系列需要各自对应的主时钟频率族。
- **无寻址、无应答**：I2S 只负责音频流的搬运，Codec 内部的工作模式与增益等寄存器通常另行通过 I2C 或 SPI 总线配置。

I2S 的优势是结构简单、器件支持广泛、把音频数据与时分解耦；代价是单向传输需要扩线、对时钟质量要求高，且衍生出多种对齐格式，容易出现兼容性问题。

## 三、物理层设计

物理层设计的核心是"时钟体系"：谁来提供时钟、各时钟之间是什么整数倍关系，以及在怎样的走线与拓扑下边沿仍然干净。

### （一）信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| BCLK / SCK | 由时钟主提供 | 位时钟，每一位数据对应一个 BCLK 周期 |
| WS / LRCK / FSYNC | 由时钟主提供 | 字时钟，低电平通常表示左声道，高电平表示右声道 |
| SD / SDATA / SDOUT / SDIN | 按数据方向 | 串行音频数据，MSB 先行 |
| MCLK / XCLK | 由系统提供 | 主时钟，Codec 内部 PLL 与调制的基准，典型 256×fs 或 384×fs |
| GND | — | 必需共地，音频系统的地处理直接影响底噪 |

### （二）电气特性与时钟频率关系

I2S 采用 CMOS/TTL 推挽电平（常见 1.8V 或 3.3V），无需上拉。各时钟之间的推导关系如下：

```text
BCLK = 采样率 fs × 量化位宽 × 声道数（每声道时隙内的位数）
```

以常见的 48kHz 采样率、16 位字长、立体声为例：

```text
BCLK   = 48k × 16 × 2    = 1.536 MHz
MCLK(256×fs)  = 48k × 256 = 12.288 MHz
MCLK(384×fs)  = 48k × 384 = 18.432 MHz
```

44.1kHz 系列对应的主时钟为 11.2896MHz（256×fs）或 16.9344MHz（384×fs）。这两组时钟无法由同一个晶振同时整除得到，是设计中必须提前处理的经典问题。

### （三）主从模式与时钟供给

I2S 有且只能有一个时钟主（Master），负责提供 BCLK 与 WS，其余器件设为从（Slave）。四种常见的时钟供给方式如下：

- **主控制器作主**：由 MCU/SoC 的音频 PLL 分频产生 BCLK 与 WS，Codec 作从。软件控制灵活，但 SoC 内部 PLL 的抖动通常较大，需评估是否满足音质要求。
- **Codec 作主**：由 Codec 内部 PLL 从外部 MCLK 合成 BCLK 与 WS，主控制器作从。时钟质量最好，是音质优先方案的首选。
- **独立音频时钟发生器**：由专用时钟芯片同时向主控制器与 Codec 提供 MCLK。适用于多采样率、高音质场合。
- **外部晶振直接作 MCLK**：成本最低，但只能支持单一采样率族。

必须注意：两端同时配置为 Master 会造成 BCLK 与 WS 驱动冲突；两端同时配置为 Slave 则没有时钟源，两种情况都不会有正常数据。

### （四）拓扑形式

- **点对点单向**：最简形式，一条 SD 单向传输，用于纯播放或纯录音。
- **双 SD 全双工**：SDOUT 与 SDIN 各一条，共享 BCLK 与 WS，是最常见的立体声全双工接法（同时录音与播放）。
- **多器件共享时钟**：多个 Codec 或 DAC 并联同一组 BCLK/WS，各自使用独立的 SD 线。可并行工作，但不可共用 SD。
- **TDM 多通道**：在一帧内划分多个时隙，单条 SD 线上依次传输多通道数据，用于麦克风阵列与多声道音频系统。
- **级联**：少数器件支持数据级联，但 I2S 原生不支持，工程上不推荐采用。

### （五）电平转换设计

跨电平域（如 1.8V SoC 与 3.3V Codec）时需使用电平转换器件。I2S 的特殊之处在于 MCLK 频率可达十几至二十几兆赫兹，转换器的传播延迟必须远小于位周期，且各通道间延迟一致性要好，否则会引入附加抖动并破坏声道间的相位关系。实践中更推荐让整个音频子系统统一采用同一 IO 电平，从源头消除转换需求。

### （六）端接与阻容处理

驱动侧可串联 22~33Ω 电阻抑制反射与振铃；MCLK 走线尤其要短并做好包地处理。不建议在音频时钟线上并联电容滤波，这会劣化边沿、增加抖动，反而损害音质。

## 四、协议层设计

I2S 在多年使用中衍生出多种对齐格式，不同厂商的默认配置常常不一致，这是应用中的主要困惑点。这一层的核心工作就是把时序、对齐方式、位宽三项在收发两端对齐。

### （一）标准 I2S 帧结构

标准 Philips I2S 的关键约定有四条：

1. WS 低电平表示左声道，高电平表示右声道。
2. 数据的最高位 MSB 在 WS 跳变后的第二个 BCLK 上升沿出现，即存在一个位时钟的延迟，这是标准 I2S 与其他对齐格式的本质区别。
3. 数据在 BCLK 下降沿更新，接收端在上升沿采样。
4. WS 在 BCLK 下降沿跳变，从而与数据的最高位错开一个完整位周期。

标准 I2S 的另一个重要特性是可以发送超过实际字长的位数：接收端若处理不了多余的位会将其丢弃；反过来，长字长的数据也可以被短位宽器件截尾接收，这使不同位宽的器件之间具备一定的互操作能力。

### （二）四种常见对齐格式

| 格式 | 帧同步信号 | MSB 位置 | 特点与应用 |
| --- | --- | --- | --- |
| 标准 I2S（Philips） | WS 占空比 50%，低电平为左声道 | WS 跳变后延迟 1 个 BCLK | 最通用，多数 Codec 默认采用 |
| 左对齐 Left-justified / MSB-justified | WS 占空比 50% | WS 跳变后立即开始，无延迟 | 部分 DAC 与 DSP 采用 |
| 右对齐 Right-justified / LSB-justified | WS 占空比 50% | 数据靠帧末尾对齐 | 日系器件常见，使用时必须指定字长 |
| DSP / PCM 模式 | FSYNC 为 1 个 BCLK 宽的脉冲 | 脉冲之后立即开始 | 语音、PCM 编解码与 DSP 接口常用 |

配置时必须让收发双方使用同一种对齐格式。若格式错配，典型表现是音量减半、声音失真、左右声道偏移一个采样，或者直接变成噪声。

### （三）主从模式的时延要求

主机发送时 SD 相对 BCLK 存在固有的输出延迟，从机接收时需要在 BCLK 的指定边沿采样。数据手册通常给出下列时序参数，设计时应逐一核对：

- 数据传输延时：BCLK 边沿到 SD 上数据有效的最大延时。
- 建立与保持时间：SD 相对采样边沿的最小建立时间与最小保持时间。
- WS 建立与保持时间：WS 相对 BCLK 边沿的建立与保持要求。

这些参数在十几兆赫兹的位时钟下往往只有几纳秒量级的裕量，因此硬件上必须控制走线长度差，软件上要正确配置采样边沿。

### （四）字长与时隙长度

多数量化器件支持 16、20、24、32 位四种字长。需要注意"字长"与"时隙长度（slot length）"是两个不同概念：当只使用 16 位数据却以 32 位时隙传输时，低位补零；反之亦然。收发双方的时隙长度必须一致，否则一帧内的数据总数不同，会直接导致串位。

### （五）TDM 多通道扩展

TDM（Time Division Multiplexing）在每一帧内划分 N 个时隙，每个时隙承载一个声道的数据：

- 单帧总位数 = 时隙数 N × 每时隙位数。
- BCLK = fs × N × 每时隙位数，因此多通道时位时钟频率会成倍上升。
- 帧同步可以是占空比 50% 的 WS，也可以是宽度为一个 BCLK 的脉冲，后者常见于 8 通道以上的设备。

典型应用为 4 或 8 通道的麦克风阵列与车载多声道音频系统。

## 五、收发操作时序

I2S 的数据搬运几乎总是配合 DMA 完成，因为它对连续性要求极高：任何一次数据欠载都会造成可听见的爆音。

**播放（发送）流程**：音频数据从内存经 DMA 送入发送寄存器，再由移位寄存器逐位串行输出。推荐采用双缓冲或循环 DMA 方式：CPU 在半传输完成与全传输完成两个中断点回填已播放的那一半缓冲区，使数据流不出现断点。

**录音（接收）流程**：接收端在 WS 边沿切换声道，在 BCLK 的指定边沿逐位采样并拼装成采样值，由 DMA 自动写入接收缓冲区。同样推荐使用双缓冲，CPU 在半区中断时取走已填满的数据，避免溢出。

**全双工同时进行**：播放与录音共用 BCLK 与 WS，但各有独立的 SD 线与 DMA 通道。两者的缓冲区相互独立，但中断优先级需要平衡，避免一边长期抢占 DMA 带宽导致另一边欠载。

**音频通路的完整启动顺序**：实际的音频 Codec 需要 I2S 与 I2C 两条总线配合工作，典型的启动流程为：

1. 完成上电与复位释放，确认各路电源（AVDD、DVDD、IOVDD）均已稳定。
2. 通过 I2C 配置 Codec 内部寄存器：时钟来源、PLL 系数、采样率、字长、对齐格式、主从模式。
3. 等待 PLL 锁定（部分器件提供锁定标志，或需要毫秒级延时）。
4. 配置主控制器侧的 I2S 外设与 DMA，参数必须与第二步完全一致。
5. 使能输出通道，软件上先保持静音一小段时间再解除，规避上电爆音。

**欠载、溢出与爆音容忍**：音频流不可容忍断点：缓冲区读空会造成欠载，写入未来得及取走会造成溢出，两者都表现为爆音或断续。设计上应保证足够深的缓冲区与合适的中断优先级，并在发生异常时播放静音数据而不是重发残留数据。

## 六、硬件设计要点

音频接口的硬件设计目标不同于一般数字接口——不只是"能通"，还要"通得干净"，因此重心落在时钟质量、地平面分区与供电纯净度上。

- **MCLK 质量优先**：主时钟抖动直接劣化信噪比与失真指标。应使用专用晶体或有源晶振，负载电容按手册精确选取，走线尽量短并做好包地，远离开关电源、DDR 与射频区域。
- **时钟源统一**：优先让整个音频子系统使用同一个时钟源，避免多个时钟域带来异步重采样与杂散。
- **同组走线与等长**：BCLK、WS、SD 应同组平行走线，长度偏差应远小于一个位周期对应的传播延迟，必要时用蛇形走线补偿。
- **完整地平面与分区**：音频器件下方须有连续的地平面。模拟区、数字区与开关电源区应分区布局，模拟地与数字地采用单点连接，避免大电流回流路径穿过音频地。
- **严禁跨分割**：所有 I2S 信号不得跨地平面分割走线，否则回流路径中断会造成严重的辐射与串扰。
- **串联阻尼电阻**：驱动侧串联 22~33Ω 抑制反射；不得在时钟线上并联电容滤波。
- **禁止双主**：原理图上应明确标注主从关系，两端不可同时配置为 Master。
- **采样率族与 MCLK 表**：设计阶段列出产品支持的全部采样率及其对应的 MCLK 频率，确认时钟源或 PLL 能够生成。44.1kHz 与 48kHz 系列需用不同 PLL 配置或双时钟源。
- **电源与参考去耦**：Codec 的 AVDD 应单独采用 LC 或 RC 滤波；VREF、MICBIAS 引脚的对地电容必须按手册选取并保证精度，这直接影响底噪与失真指标。
- **上下电使能时序**：上电与掉电过程中应保持功放处于静音态，待 Codec 的参考电压建立完成后再解除静音，规避上电爆音。
- **与噪声源隔离**：I2S 走线应远离 Class-D 功放的 PWM 输出、DC-DC 电感、射频天线馈点与高速并行总线，必要时加屏蔽地过孔墙。
- **测试点预留**：应在 BCLK、WS、SD、MCLK 及对应地线上留出测试点，方便用逻辑分析仪解码波形，这对初期调试极为关键。

## 七、典型应用场景

I2S 广泛应用于各类需要传输 PCM 音频的场合，不同应用的设计重心并不相同：

| 应用对象 | 典型器件 | 设计关注点 |
| --- | --- | --- |
| 音频 Codec | 立体声编解码器、Codec 与 DAC 二合一 | I2S 传数据、I2C 配寄存器的双总线配合；PLL 与采样率族配置 |
| Hi-Fi 播放器 | 独立 DAC、耳机放大器 | MCLK 质量与抖动控制、模拟地处理、格式兼容性 |
| 数字功放 | 带 I2S 输入的 Class-D | 从模式接收、PWM 输出对 I2S 走线的辐射隔离、静音时序 |
| 无线音频模组 | Wi-Fi、蓝牙音频模组 | 模组侧 I2S 的主从约定、采样率自适应与缓冲 |
| 麦克风阵列 | 多路 ADC、多通道 Codec | TDM 时隙数与时隙宽度、各通道一致性与相位对齐 |
| 语音交互设备 | 语音前端 DSP、Codec | 低延迟链路设计、缓冲区深度与时延的平衡 |
| 嵌入式视频终端 | SoC 直出 I2S | SoC 内部音频 PLL 的分数分频误差、DMA 配置 |

需要特别区分：PDM（脉冲密度调制）数字麦克风使用时钟与数据两线，属于 1 位调制接口，不是 I2S，不可直接接到 I2S 引脚，需经抽取滤波器转换后才能得到 PCM 数据。

## 八、可靠性与测试验证

音频接口的容错窗口比普通数字接口严格得多：普通接口偶发丢几个字节也许毫无察觉，音频接口丢一次 DMA 就会产生可听见的爆音。因此验证重点在于量化指标与长时间稳定性。

**常见故障模式**：

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 完全无声 | MCLK 未供给、Codec 未配置或处于复位、功放未使能 | 测量 MCLK/BCLK/WS 是否有波形；确认 I2C 配置成功；检查复位与使能脚电平 |
| 全是噪声或杂音 | 对齐格式不匹配、字长与时隙长度不一致、MSB/LSB 设置错误 | 逐项核对 I2S 格式配置；用逻辑分析仪解码确认数据位排列 |
| 声音变快或变慢 | 实际采样率与配置不符、MCLK 或 PLL 系数错误 | 测量 WS 频率反推实际采样率；核对 PLL 分频系数 |
| 左右声道反了 | WS 极性定义与器件相反、数据线接反 | 核对 WS 极性配置；检查 SDIN 与 SDOUT 是否接反 |
| 只有一个声道有声 | 通道未使能、缓冲区只填了单声道数据、时隙数配置错误 | 检查声道使能与缓冲区填充方式；核对 TDM 时隙数 |
| 断续爆音 | DMA 欠载或溢出、中断延迟过长、缓冲区过浅 | 加大缓冲区；提高 DMA 中断优先级；统计欠载次数定位 |
| 上电或掉电时爆音 | 未使用静音控制、参考电压未建立即解除静音 | 增加上电延时与静音保持；确认解除静音发生在参考建立之后 |
| 高频杂散或底噪大 | MCLK 抖动、地分割不合理、电源纹波串入 | 优化时钟源与地平面；加强 AVDD 滤波；检查 VREF 电容取值 |
| 特定采样率异常 | 该采样率对应的 MCLK 无法产生或 PLL 配置未同步切换 | 核对 MCLK 频率表；切换采样率时同步重配 PLL |
| 48kHz 正常而 44.1kHz 异常 | 同一时钟源无法同时整除两个采样率族 | 增加独立音频时钟，或按采样率切换 PLL 配置 |
| 多通道互相串音 | TDM 时隙错位、帧同步宽度或极性配置错误 | 核对帧同步极性与宽度；逐时隙抓取数据验证 |

**测试要点**：

- 时钟关系核查：用示波器测量 MCLK、BCLK、WS 的频率，验证 BCLK 等于采样率乘以位宽再乘以声道数（TDM 时为时隙数），并确认与主时钟的整倍数关系成立。
- 帧同步信号核查：测量 WS 的频率（应等于采样率）、占空比与极性。
- 波形解码：用逻辑分析仪按对应的对齐格式整帧解码，确认每个采样值、声道顺序与位排列跟预期一致。
- 音频指标测试：使用音频分析仪输入标准正弦信号（典型 1kHz、-1dBFS），测量 THD+N、信噪比、动态范围与频率响应；多通道系统还应测量通道间串扰与相位一致性。
- 抖动测量：条件允许时应测量 MCLK 与 BCLK 的抖动，确认满足所选器件的指标要求。
- 长时间稳定性：连续播放或录音数小时，DMA 欠载与溢出计数必须为 0，无爆音、无断续。
- 切换与上下电：反复切换采样率、反复上电掉电，确认无爆音且能稳定恢复。
- EMC 验证：在射频干扰环境下（如靠近天线或手机通话状态）检查音频是否出现可闻干扰。
- 极限条件：在高低温与极限电压下重复关键指标测试，确认 Codec 的 PLL 在全温范围内稳定锁定。

## 九、设计检查清单

1. 已明确主从关系，全链路有且仅有一个时钟主。
2. 已列出产品支持的全部采样率及对应的 MCLK 频率，并确认时钟源或 PLL 可生成。
3. 44.1kHz 与 48kHz 两个采样率族的处理方案已确定（双时钟或切换 PLL）。
4. 对齐格式（标准 I2S / 左对齐 / 右对齐 / DSP 模式）两端配置完全一致。
5. 字长与时隙长度两端配置一致，补零规则已明确。
6. BCLK、WS、SD 已同组走线并控制长度偏差，未跨地平面分割。
7. MCLK 走线短、已做包地处理，远离开关电源、DDR 与射频区域。
8. 音频模拟区已完成分区，模拟地与数字地采用单点连接。
9. 驱动侧已串联 22~33Ω 阻尼电阻，时钟线上未并联滤波电容。
10. Codec 的 AVDD 已单独滤波，VREF 与 MICBIAS 电容按手册选取且精度满足要求。
11. 用于配置寄存器的 I2C/SPI 总线已确认可用，配置流程在软件中已完整实现。
12. 上电、掉电与采样率切换三处均已加入静音保持，规避爆音。
13. DMA 采用双缓冲或循环缓冲，缓冲区深度满足最坏中断延迟要求。
14. 欠载与溢出异常已有计数上报，异常处理时播放静音而非残留数据。
15. I2S 走线已远离 Class-D 的 PWM 输出、电感与射频馈点。
16. BCLK、WS、SD、MCLK 及对应地均已预留测试点。
17. 已完成 THD+N、信噪比、动态范围与串扰实测，指标满足产品要求。
18. 已完成连续数小时的播放与录音稳定性测试，欠载与溢出计数为 0。
19. 已保留样板阶段的实测波形与谐波指标，作为后续量产比对基线。

> 注：本文为 I2S 接口的通用设计说明。具体项目的时序参数、PLL 配置、寄存器定义与音频指标最终以所用主控制器与音频器件的数据手册为准，关键指标应在样板阶段通过实测确定。

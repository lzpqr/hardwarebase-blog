三极管（BJT，双极型晶体管）是中小电流驱动与信号放大里最常见的开关/放大器件。拿到选型任务，第一步不是看参数，而是确定电路功能——开关和放大关注的重点完全不同，会直接决定筛选数据手册的切入点。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。功率开关场合的对比见[MOS管篇](/posts/component-selection-mosfet/)。

## 1. 先想清楚：开关还是放大

| 功能 | 关注点 |
| --- | --- |
| 开关（Switch / Driver） | 只看两个状态：截止（断开）与饱和（闭合）；关注 VCE(sat) 越低越好（导通损耗小）、IC、PD、SOA、开关时间；hFE 仅用于算基极电流，需"过驱动" |
| 放大（Amplifier） | 工作在放大区（线性区），集电极电流受基极线性控制；关注 hFE 的线性度与一致性、fT、噪声系数 NF、Cob；功率放大还需关注 SOA、热稳定、二次击穿 |

**一句话总结**：开关看"压降和扛流"，放大看"增益和频率"。选型方向错了，后面所有计算都白做。

## 2. 七大核心参数

| 参数 | 含义 | 选型判据 |
| --- | --- | --- |
| VCEO | 集电极-发射极击穿电压（基极开路） | 必须大于电路最大 VCE，且留 1.5~2 倍余量；感性负载需额外考虑关断尖峰 |
| IC / ICM | 连续 / 峰值集电极电流 | 连续电流留 1.5 倍以上余量，注意浪涌与堵转电流；脉冲电流不可当直流用 |
| PD | 最大耗散功率（@TC=25℃） | 实际 P=VCE×IC 必须小于耗散能力，并按环境温度降额 |
| hFE | 直流电流增益 = IC/IB | 永远用最小值设计，不能用典型值；随 IC、温度变化 |
| VCE(sat) | 饱和压降 | 开关应用关键参数，越低发热越小；达林顿管高达 1~2V，需注意 |
| fT | 特征频率（增益降至 1 的频率） | 射频选 fT ≥ 5~10× 工作频率；音频取 ≥150MHz 足够 |
| RθJA / RθJC | 热阻（结到环境 / 结到壳） | 用于计算结温 TJ = TA + P×RθJA，功率管必看 |

**关键提醒**：hFE 不是常数。同一型号不同批次可能相差数倍，且在小电流、大电流、低温下都会明显跌落。数据手册给出的通常是范围（如 100~300），设计时必须取最小档。

## 3. NPN / PNP 与拓扑选择

| 拓扑 | 类型 | 负载位置 | 驱动条件 | 典型场景 |
| --- | --- | --- | --- | --- |
| 低边开关 | NPN | 负载在电源与集电极之间，发射极接地 | 基极加高电平导通，饱和压降低、速度快 | 继电器、LED、电机低边驱动（最常用） |
| 高边开关 | PNP | 发射极接电源，集电极接负载 | 基极电压需比电源低 0.7V 以上才导通 | 负载需共地、多负载共地场景 |
| 互补输出级 | NPN+PNP | 配对推挽 | 两管交替导通 | 音频功放、推挽驱动 |

**电平匹配坑**：用 MCU（3.3V/5V）驱动 PNP 做高边开关时，基极需被拉到"电源电压 − 0.7V"以上才能可靠关断，高电平可能不够。此时常加一级 NPN 反相驱动，或改用 P 沟道 MOSFET / 高边驱动芯片。

## 4. 开关电路选型计算流程（五步法）

以最常见的 NPN 低边开关为例，把选型变成可复现的计算流程。

**步骤 1 · 确定负载电流 IC**

```
IC ≈ (VCC − VCE(sat)) / Rload    // 近似 IC ≈ VCC / Rload
```

按此电流选管，要求 IC(max) ≥ 1.5 × IC。

**步骤 2 · 查最小增益 hFE(min)**：在数据手册中找到对应 IC 与工作温度下的最小 hFE（不要用典型值）。

**步骤 3 · 计算临界基极电流 + 过驱动**

```
IB,sat    = IC / hFE(min)
IB,design = IB,sat × K    // 过驱动系数 K = 2~10（强制 β = 10~20）
```

深度饱和要求 IC/IB ≤ 10~20，确保任何批次、任何温度都可靠饱和。

**步骤 4 · 计算基极电阻 Rb**

```
Rb = (VGPIO − VBE(sat)) / IB,design
// 硅管 VBE(sat) ≈ 0.7V；达林顿 ≈ 1.5~2.5V
```

取标准电阻值时就近取小（如算得 650Ω，取 560Ω 或 680Ω 需权衡；取小则基极电流略大、饱和更可靠）。

**步骤 5 · 校核功耗与热**

```
Psat ≈ VCE(sat) × IC
TJ = TA + P × RθJA    // 要求 TJ < 125~150℃
```

### 4.1 实例 A · MMBT3904 驱动 3.3V / 330µA 负载

已知：VCC=3.3V，Rload=10kΩ → IC≈0.33mA；hFE(min)≈65；VGPIO=3.3V；过驱动系数 K=2。

```
IB,sat    = 0.33mA / 65  ≈ 5.1µA
IB,design = 5.1µA × 2    ≈ 10µA
Rb        = (3.3 − 0.7)V / 10µA = 260kΩ  → 取标准值 220kΩ
```

取 220kΩ 后基极电流略大于设计值，饱和更彻底，且远小于 MCU 引脚驱动能力，安全。

### 4.2 实例 B · S8050 驱动 12V / 98mA 继电器

已知：IC≈98mA，hFE(min)≈50（IC=100mA 时），VGPIO=3.3V，K=2。

```
IB,sat    = 98mA / 50  ≈ 2mA
IB,design = 2mA × 2     = 4mA
Rb        = (3.3 − 0.7)V / 4mA = 650Ω  → 取 680Ω 或 1kΩ
```

**必须加续流二极管！** 继电器线圈是电感，关断瞬间产生的反向电动势可达几十到上百伏，会直接击穿三极管。在线圈两端反向并联二极管（如 1N4148 / 1N4007），阴极接电源正极，阳极接集电极。

两个实用技巧：① 在基极与发射极之间并联 10kΩ 泄放电阻，确保 GPIO 高阻态（上电复位期间）时基极电荷有释放路径，防止意外导通；② 高速开关时在基极电阻上并联小电容（加速电容），加快进入/退出饱和，减小存储延迟。

## 5. 热设计与 SOA 降额

### 5.1 结温计算与散热片

功率管需要散热片时，按此式反推所需散热器热阻 RθSA。涂导热硅脂或加导热垫可显著降低 RθCS；强制风冷可把散热器热阻降低 2~5 倍。

```
TJ = TA + PD × (RθJC + RθCS + RθSA)
// RθJC 结到壳｜RθCS 壳到散热器｜RθSA 散热器到环境
```

### 5.2 SOA 安全工作区：为什么"算过功耗"还会炸管

很多工程师只算了稳态功耗 P=VCE×IC，结果上电瞬间管子还是烧了。原因是瞬态工况（浪涌、短路、感性负载反冲、电机堵转、关断尖峰）覆盖不到稳态计算，必须查 SOA 曲线。

做法：把实际负载线叠加到 SOA 图上，确认包括开/关瞬态在内的所有工作点都落在边界内。脉冲越窄，SOA 越宽；DC 工况最严格。

| SOA 边界 | 限制机理 | 注意事项 |
| --- | --- | --- |
| 最大 IC（垂直线） | 金属布线电迁移、键合线熔断 | 脉冲电流 ICP 需满足脉宽与占空比约束，不可当直流用 |
| 最大 VCEO（垂直线） | 雪崩击穿 | 任何时刻 VCE 都不能超过 VCEO；感性负载加钳位 |
| 等功率线（斜线） | 热限制 | 与 TC 相关，温度越高越收紧 |
| 二次击穿线（更陡斜线） | 电流集中 → 局部热点 → 热失控 | 高压大电流同时出现时最危险，BJT 独有失效模式 |

**热失控（Thermal Runaway）**：BJT 在固定 VBE 下，集电极电流随温度升高而增大，形成"越热→电流越大→越热"的正反馈。防范：发射极串联负反馈电阻、温度补偿偏置（偏置管/二极管贴装在同一散热片上）、热敏电阻补偿、有源限流。

## 6. 封装与命名规则

### 6.1 常见封装

| 封装 | 类型 | 功耗能力 | 典型型号 |
| --- | --- | --- | --- |
| TO-92 | 插件小功率 | ~0.3–0.6W | 2N3904、S8050 |
| SOT-23 | 贴片小信号 | ~0.35W | MMBT3904 |
| SOT-89 / 223 | 贴片中功率 | 0.5–1.5W | — |
| TO-126 | 中功率 | — | BD135 / BD136 |
| TO-220 / TO-247 | 功率 | 数十~上百 W（带散热） | TIP41、2N3055 |
| DPAK (TO-252) | 贴片功率 | 2W+（依赖铜箔） | — |

### 6.2 命名体系

| 体系 | 说明 | 示例 |
| --- | --- | --- |
| 2N（JEDEC） | 美系通用 | 2N2222、2N3904、2N3055 |
| BC / BD / BF | 欧系：C 小功率 / D 功率 / F 高频 | BC547、BD139、BFR92 |
| 2SA / 2SB / 2SC / 2SD | 日系：A/B = PNP，C/D = NPN | 2SC1815、2SA1015 |
| TIP | 功率管 / 达林顿 | TIP31、TIP120 |
| MMBT | 2N 的贴片版本 | MMBT3904 = SOT-23 版 2N3904 |

**引脚顺序！** 替换型号时，务必核对手册中的 E-B-C 引脚排列与 PCB 封装兼容性。同一封装不同厂商/型号的引脚顺序可能不同（尤其 TO-92）。

## 7. 常见选型陷阱（避坑清单）

| 陷阱 | 后果 | 正确做法 |
| --- | --- | --- |
| 用典型 hFE 而非最小值设计 | 部分批次不饱和，VCE 升高、发热烧毁 | 取 hFE(min)，并过驱动 K=2~10 |
| 忘记基极电阻 | 基极电流过大，烧管或烧 MCU 引脚 | 必须串联 Rb 并计算 |
| 感性负载不加续流二极管 | 关断尖峰击穿 C-E 结 | 反向并联 1N4007 / 1N4148 |
| 电压/电流余量不足 | 浪涌或反冲瞬间击穿 / 熔断 | VCEO、IC 各留 1.5~2 倍余量 |
| 忽视 SOA 与二次击穿 | "算过功耗"仍炸管 | 叠加负载线查 SOA，含瞬态 |
| 达林顿用在小电压场合 | VCE(sat)=1~2V，损耗大 | 低压场景用单管或 MOSFET |
| 忽略反向 VEBO | 负压关断时击穿 B-E 结（小信号管仅 5~6V） | 加钳位或改用合适驱动 |
| 忽略引脚顺序 | 替换料直接冒烟 / 不工作 | 核对 E-B-C 与封装 |
| 采购到假货 / 翻新料 | hFE、VCE(sat) 超差 | 正规渠道，抽检参数，留存批次溯源 |

## 8. 选型核对清单 & 常用型号

### 8.1 上料前 10 问

1. 电路功能是开关还是放大？
2. 需要 NPN 还是 PNP（低边 / 高边）？
3. VCEO 是否 ≥ 2× 最大 VCE（含瞬态）？
4. IC(max) 是否 ≥ 1.5× 实际（含浪涌）？
5. 是否查了对应 IC 下的 hFE(min) 并过驱动？
6. VCE(sat) 是否满足低压 / 低损耗要求？
7. 功耗 P=VCE·IC 是否在 PD 降额后范围内？结温 OK？
8. SOA 负荷线是否全落在安全区？
9. 是否加了基极电阻、续流二极管、泄放电阻？
10. 封装 / 引脚顺序与 PCB 兼容？

| 型号 | 类型 | VCEO | IC | fT | 特点 / 典型用途 |
| --- | --- | --- | --- | --- | --- |
| 2N3904 | NPN | 40V | 200mA | ~300MHz | 通用小信号、开关 |
| 2N2222 | NPN | 40V | 800mA | ~250MHz | 通用开关，饱和压降低 |
| MMBT3904 | NPN | 40V | 200mA | ~300MHz | 2N3904 的贴片版 |
| S8050 | NPN | 25V | 1.5A | ~150MHz | 继电器 / 小电机驱动 |
| S8550 | PNP | 25V | 1.5A | ~100MHz | 与 S8050 互补 |
| 2SC1815 / 2SA1015 | NPN / PNP | 50V | 150mA | ~80MHz | 音频前置、互补对 |
| 9014 | NPN | 50V | 100mA | ~150MHz | 低噪声音频放大 |

**BJT 还是 MOSFET？** BJT 电流驱动、简单可靠、饱和压降低，适合中小电流与线性场合；MOSFET 电压驱动、开关损耗低、导通电阻小，适合大电流高频开关。若在开关电源中反复烧 BJT，考虑迁移到 MOSFET / IGBT 从根本上解决，详见[MOS管篇](/posts/component-selection-mosfet/)。

> 本文档为技术参考速查，具体设计以器件官方数据手册为准。涉及高压、大电流、安全性应用时，请进行实际测试与热验证。

## 一、文档目的与适用范围

本文档规定硬件产品中 USB（Universal Serial Bus）接口的信号定义、速率与版本选择、Type-C 连接器与供电协商、协议与枚举流程、PCB 布局、防护设计与测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：产品对外或板内的 USB 2.0、USB 3.x（含 Type-C）接口，以及基于 USB 供电与 USB PD 协商的供电设计。USB4 与 Thunderbolt 的具体隧道协议、USB PD 固件的完整策略实现不在本文档范围内；具体器件与连接器的电气参数以对应数据手册与 USB-IF 规范为准。

## 二、接口概述

USB 是应用最广的通用串行总线，设计者需要同时面对三件事：数据速率、连接器形态、供电能力。它的核心特征如下：

- **严格的主从架构**：通信只能由主机发起，设备不能主动上报，轮询机制决定了它天然不适合极低时延的中断型场合。
- **分层清晰**：物理层负责信号与供电，链路与协议层负责包、事务与传输调度，功能层负责具体类协议。各层解耦，同一物理口可承载多种设备类。
- **版本与命名复杂**：USB 3.0/3.1/3.2 的多次改名造成了大量混淆，工程沟通中应直接用速率（5Gbps、10Gbps）而不是"Gen1/Gen2"或版本号。
- **总线供电**：从最初的 5V/500mA 演进到 USB PD 3.1 的最高 240W，供电能力已成为 USB 设计中与数据同等重要的一半。
- **支持热插拔**：连接检测、上电时序与 ESD 防护必须按热插拔场景设计。
- **Type-C 统一形态**：正反可插、支持角色切换与交替模式，但同时引入了 CC 逻辑、E-Marker 与复用器，硬件复杂度显著上升。
- **向后兼容**：高速口向下兼容低速设备，但兼容链路上的线缆、Hub 与转换器是兼容性问题的高发区。

USB 的优势是生态完整、供电与数据合一、即插即用；代价是协议栈复杂、主从架构带来时延、Type-C 时代的硬件与认证成本较高。

## 三、物理层设计

物理层的核心是三件事：用哪组差分对、用哪种连接器、能供多少电。

### （一）信号定义

| 信号 | 适用 | 说明 |
| --- | --- | --- |
| VBUS | 全部 | 总线电源，默认 5V，PD 协商后可升至 9V/15V/20V 等 |
| D+ / D− | 全部 | USB 2.0 差分数据对，所有 USB 口都必须保留，用于枚举与兼容 |
| GND | 全部 | 电源回流与信号参考，需保证足够引脚数与载流能力 |
| SSTX+ / SSTX− | USB 3.x | 超高速发送差分对，主机与设备方向相反 |
| SSRX+ / SSRX− | USB 3.x | 超高速接收差分对 |
| CC1 / CC2 | Type-C | 配置通道，用于连接检测、方向识别、角色协商与 PD 通信 |
| SBU1 / SBU2 | Type-C | 边带信号，交替模式下用作低速辅助通道 |
| ID | Micro-AB | OTG 角色识别，Type-C 时代由 CC 取代 |

需要特别注意：USB 3.x 口在物理上同时存在 USB 2.0 的 D+/D− 与超高速差分对，两套数据通路并行工作。设计时不能因为速率高就省略 D+/D−，否则设备在高速协商失败时将无法回落到可用状态。

### （二）速率与版本对照

| 速率等级 | 标称速率 | 常用叫法 | 编码方式 |
| --- | --- | --- | --- |
| 低速 | 1.5 Mbps | USB 1.0/1.1 低速 | NRZI |
| 全速 | 12 Mbps | USB 1.1 全速 | NRZI |
| 高速 | 480 Mbps | USB 2.0 | NRZI |
| 超高速 | 5 Gbps | USB 3.2 Gen1（原 USB 3.0） | 8b/10b |
| 超高速+ | 10 Gbps | USB 3.2 Gen2（原 USB 3.1 Gen2） | 128b/132b |
| 超高速 20G | 20 Gbps | USB 3.2 Gen2×2 | 128b/132b，双通道 |
| USB4 | 20 / 40 Gbps | USB4 Gen2×2 / Gen3×2 | 隧道封装 |

实际可用吞吐量约为标称速率的 70%~90%，取决于编码开销、协议开销与调度效率。选型时应按有效吞吐而不是标称速率核算需求。

### （三）Type-C 连接器与 CC 逻辑

Type-C 的连接与角色全部由 CC 引脚决定，这是它与传统 USB 最大的不同：

- **连接检测与方向识别**：主机侧在 CC1/CC2 上提供上拉电阻，设备侧提供下拉电阻。哪一根 CC 线被拉低即决定插入方向，随之切换高速差分对的映射。
- **角色协商**：供电方与受电方、主机与设备的角色都通过 CC 上的电阻与后续 PD 消息确定，支持动态切换。
- **双角色端口**：同时具备主机与设备能力的端口在 CC 上周期性切换上拉与下拉，等待对端接入后确定角色，适用于笔记本、平板与移动电源。
- **线缆识别**：带电子标签（E-Marker）的线缆通过 CC 上报自身能力（电流等级、速率等级、是否支持交替模式），主机据此决定可用的供电与速率。
- **交替模式**：通过 CC 协商后可把高速差分对复用于显示或其他协议，此时需配套的高速复用器。

硬件上 CC 引脚的电阻取值、走线与防护必须严格按规范设计；CC 引脚处理不当是"插上不识别""只能单向插入"这类故障的首要原因。

### （四）供电能力与 PD 协商

| 供电方式 | 电压 | 最大电流 | 最大功率 |
| --- | --- | --- | --- |
| USB 2.0 默认 | 5V | 500 mA | 2.5 W |
| USB 3.x 默认 | 5V | 900 mA | 4.5 W |
| 电池充电规范 | 5V | 1.5 A | 7.5 W |
| Type-C 默认电流 | 5V | 1.5 A / 3 A | 15 W |
| PD 标准功率范围 | 5~20V | 3 A / 5 A | 100 W |
| PD 扩展功率范围 | 最高 48V | 5 A | 240 W |

超过 5V 或 3A 的供电必须通过 PD 协商获得，协商在 CC 线上完成。设计要点有三：一是供电端须按协商结果逐步升压并记录当前契约，二是受电端须在请求前确认自身能承受的电压，三是超过 3A 的电流必须使用带电子标签的线缆，否则应主动限制电流。

### （五）拓扑结构

- **星型分层**：主机为根，通过集线器逐级扩展，最多支持 5 级集线器级联，最多 127 个设备地址。
- **点对点直连**：一个主机口接一个设备，是最简单也是最可靠的形态。
- **复合设备**：一个物理设备内含集线器与多个功能，占用多个地址。
- **Type-C 交替模式**：同一物理口在同一时刻只能工作在一种模式下，切换需重新协商。

### （六）端接与电平要求

- **差分阻抗**：USB 2.0 与 USB 3.x 的差分对均要求 90Ω 标称差分阻抗，需按板厚与叠层计算线宽线距并让板厂确认。
- **设备识别上拉**：设备在 D+（全速）或 D−（低速）上提供 1.5kΩ 上拉至 3.3V，主机据此判断设备存在与速率等级。
- **交流耦合电容**：超高速差分对在发送端串联耦合电容，取值需按器件手册选取并靠近发送端放置。
- **禁止分支**：超高速差分对不允许任何形式的分支或分叉，测试点也应做成极小焊盘而非引出长线。

## 四、协议层设计

USB 协议栈的分层比前面几篇的接口都要厚，但硬件设计真正需要掌握的只有两块：四种传输类型的差异，以及枚举与调度的基本机制。

### （一）四种传输类型

| 传输类型 | 特点 | 带宽保证 | 典型应用 |
| --- | --- | --- | --- |
| 控制传输 | 双向、小包、必配 | 保留带宽 | 枚举、配置、状态查询 |
| 中断传输 | 周期性轮询、低时延 | 保证最大等待时间 | 键盘、鼠标、触摸 |
| 批量传输 | 尽最大努力、可重试 | 不保证，占用剩余带宽 | 存储、打印机、固件升级 |
| 等时传输 | 周期性、无重传 | 保证带宽与时延 | 音频、视频采集 |

等时传输不重传错误数据，这是它保证实时性的代价，音视频类设备必须能容忍偶发的数据错误；批量传输则相反，宁可慢也不出错。

### （二）包结构与事务

USB 2.0 的包由同步字段、包标识、地址与端点、数据、校验与包结束字段组成，一次完整的事务通常由令牌包、数据包与握手包三段构成。USB 3.x 在保留事务概念的同时，改用独立的超高速链路，增加了链路训练、电源管理与流控机制，包头结构也与 2.0 不同。

### （三）端点与管道

- **端点**：设备侧可寻址的数据缓冲区，每个端点有编号与方向，端点 0 固定为控制端点。
- **管道**：主机与端点之间的逻辑通道，配置完成后才建立。
- **端点类型**：控制、中断、批量、等时四种，与传输类型对应，在端点描述符中声明。

### （四）设备类与描述符

描述符是设备向主机自我说明的数据结构，层次为设备描述符 → 配置描述符 → 接口描述符 → 端点描述符，另有字符串描述符与类专用描述符。常见的设备类包括大容量存储、人机接口设备（HID）、通信设备类（CDC，虚拟串口）、视频类（UVC）、音频类（UAC）与厂商自定义类。硬件设计者需要知道：描述符内容决定了主机的驱动匹配方式，端点数与缓冲大小决定了可实现的最大吞吐。

### （五）USB 3.x 链路与电源管理

- **双总线并行**：USB 2.0 与超高速总线同时存在，超高速链路训练失败时设备仍应能在 2.0 下工作。
- **链路训练**：通过低频周期信号发起，依次完成检测、轮询与配置，最终进入正常工作状态。
- **链路状态**：从全速工作状态到多级省电状态（U1/U2 等），空闲时自动降功耗，有数据时快速唤醒。
- **双通道聚合**：部分型号支持两条通道同时工作以获得翻倍速率，要求线缆与两端均支持。

### （六）Type-C 交替模式

交替模式把 Type-C 的高速差分对借给其他协议（如显示信号）使用。硬件上的关键是高速复用器的选型与走线：复用器必须满足所承载速率的带宽与插损要求，并且从连接器到复用器、再到协议控制器的整条路径都要按高速差分规则处理。是否支持交替模式、支持哪些模式，必须在产品定义阶段确定，因为它直接影响原理图与叠层设计。

## 五、枚举与传输操作流程

枚举是 USB 最核心的过程：设备接入后被识别、分配地址、加载驱动并进入可用状态。理解它，才能判断"插上没反应"到底卡在哪一步。

### （一）枚举流程

1. **连接检测**：主机通过 D+/D− 的上拉或 CC 引脚的电平变化检测到设备接入。
2. **去抖与等待**：等待电源与信号稳定，通常为百毫秒量级。
3. **端口复位**：主机发出复位信号，设备进入默认状态并使用默认地址 0。
4. **读取描述符**：主机先读设备描述符的前若干字节获取端点 0 的最大包长，再读完整描述符。
5. **分配地址**：主机为设备分配唯一地址，设备此后响应该地址。
6. **读取全部配置**：读取配置、接口与端点描述符，完成驱动匹配。
7. **选择配置**：主机选定一个配置，设备进入工作状态，端点开始传输数据。

### （二）调度与帧结构

主机按固定周期调度所有传输：USB 2.0 的帧周期为 1ms，超高速的微帧周期为 125μs。每个周期内优先安排等时与中断传输，剩余带宽分配给批量与控制传输。这一机制决定了：即便总带宽充足，若周期性传输占用过多，批量传输的实际速率也会明显下降。

### （三）挂起与唤醒

总线空闲超过规定时间后设备进入挂起状态，电流降至挂起限值（通常 2.5mA）以下。设备可通过信号（远程唤醒）唤醒主机，主机也可广播唤醒。设计时需要注意：挂起电流是很多产品认证失败的原因，尤其是带有独立供电或大容量去耦电容的设备。

### （四）供电协商流程（USB PD）

1. 连接建立后，供电端（Source）在 CC 上广播自身可提供的电源能力（Power Data Object）清单。
2. 受电端（Sink）从中选择一项并发出请求，可请求固定电压或可编程电压。
3. 供电端接受请求后调整输出电压，待电压稳定后发出就绪通知。
4. 双方按新契约（Contract）工作；任一方需要变更时重新发起协商（PSR / PDO 更新）。

协商过程中电压切换前后必须留足稳定时间，受电端的过压保护与放电回路设计要能覆盖协商失败或异常断电的情况。

### （五）吞吐核算

设计摄像头、存储或采集类设备时，应先做带宽核算：先由分辨率、帧率与像素位宽算出原始码率，再除以编码与协议效率（通常取 0.7~0.85），得到所需标称速率，据此选择 USB 2.0、5Gbps 还是 10Gbps。留出 20% 以上余量是必要的，因为 Hub 共享、CPU 占用与调度抖动都会吃掉带宽。

## 六、硬件设计要点

USB 的硬件风险集中在差分信号完整性、热插拔防护、供电能力三个方面。以下 12 条按此展开：

1. **差分阻抗控制**：所有差分对按 90Ω 设计，线宽线距按实际叠层计算，在制板说明中明确阻抗要求并让板厂出具阻抗报告。
2. **等长与对称**：差分对的两根线长度应尽量相等，过孔数量对称，避免不必要的换层。
3. **禁止跨分割**：差分对下方必须有完整的参考平面，不得跨地平面或电源平面分割走线。
4. **耦合电容放置**：超高速发送端的交流耦合电容靠近发送引脚放置，两端接地过孔就近打孔。
5. **ESD 防护**：对外接口必须放置低结电容（<0.5pF 级）的浪涌与静电防护器件，结电容过大会直接劣化高速眼图。
6. **CC 引脚处理**：按规范配置上拉（Rp：5.1k/10k/22kΩ 对应 1.5A/3A/5A）或下拉电阻，走线短且远离噪声源，必要时加防护器件。
7. **电源载流与保护**：VBUS 走线宽度按最大输出电流设计并留余量；对外供电口必须配置过流保护与限流器件。
8. **大电容的浪涌限制**：设备侧 VBUS 上的总电容应控制在规范限值内（通常 <50μF），否则插入瞬间的浪涌电流会造成主机端口保护动作。
9. **连接器屏蔽与接地**：连接器金属外壳应通过低阻抗路径接到机壳或系统地，屏蔽层处理方式需按整机接地策略统一。
10. **共模抑制**：对外口可按需串接共模电感以改善辐射，但需评估其对高速眼图的影响。
11. **远离干扰源**：USB 差分对应远离开关电源电感、射频天线与时钟源；高速 USB 本身也是强辐射源，需评估对无线灵敏度的影响。
12. **测试点预留**：在差分对上预留极小尺寸的测试焊盘，便于眼图与一致性测试，但不得引出长分支。

## 七、典型应用场景

| 应用对象 | 典型形态 | 设计关注点 |
| --- | --- | --- |
| 调试与固件升级口 | USB 2.0 设备口 | 枚举稳定性、DFU 模式进入方式、挂起电流 |
| 虚拟串口 | 通信设备类（CDC） | 描述符与驱动匹配、端点缓冲、数据丢失处理 |
| 大容量存储 | U 盘、移动硬盘 | 批量传输吞吐优化、供电能力、掉电保护 |
| 摄像头与采集卡 | 视频类（UVC） | 带宽核算、等时传输配置、线缆质量与长度 |
| 音频设备 | 音频类（UAC） | 等时传输与时钟同步、异步反馈端点、底噪 |
| 对外供电与充电口 | Type-C PD | PD 协商策略、线缆识别、过流与过压保护 |
| 扩展坞与转接 | Type-C 交替模式 | 高速复用器选型、多协议共存、整链路插损预算 |

## 八、可靠性与测试验证

USB 是产品上最容易被用户直接接触的接口，故障暴露率极高。验证重点放在兼容性、热插拔与长期稳定性上。

### （一）常见故障模式

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 插入无任何反应 | VBUS 未供上、CC 电阻配置错误、D+/D− 上拉缺失 | 测量连接器各引脚电压；核对 CC 上下拉与设备侧上拉电阻 |
| 只能 2.0 速率不能到 3.x | 超高速差分对走线问题、线缆不支持、耦合电容缺失 | 换已知良好的线缆；检查焊接与走线；用协议分析仪看协商过程 |
| 时断时续 | 连接器接触不良、虚焊、阻抗不连续、ESD 器件结电容过大 | 检查连接器焊点；测眼图；尝试移除防护器件对比 |
| 枚举超时失败 | 描述符错误、端点配置错误、固件未响应 | 抓取枚举过程定位卡在哪一步；核对描述符内容 |
| 传输速率远低于预期 | 批量传输被周期传输挤占、Hub 共享、驱动或固件效率低 | 核算带宽占用；排查 Hub 级联；优化端点缓冲与 DMA |
| 大电流设备插上后主机断电 | 浪涌电流超限、过流保护误动作 | 限制 VBUS 总电容；加入缓启动电路；核对限流阈值 |
| PD 协商失败或反复重启 | CC 走线受扰、供电能力不足、策略固件问题 | 抓取 CC 上的协商报文；核对外设功率需求与供电能力 |
| Type-C 只能单向识别 | 两根 CC 中有一路未连接或电阻缺失 | 逐脚测量 CC1 与 CC2；核对连接器引脚定义 |
| 设备发热或连接器发烫 | VBUS 走线载流不足、接触电阻过大 | 核算走线载流；更换连接器规格；实测温升 |
| 辐射或传导超标 | 高速差分对辐射、屏蔽接地不当 | 检查屏蔽层接地；优化走线与包地；按需加共模电感 |
| ESD 测试后损坏 | 防护器件选型或布局不当、放电路径穿过芯片 | 防护器件靠近连接器放置；保证低阻抗泄放路径 |

### （二）测试要点

- **信号质量**：用高速示波器或专用一致性测试夹具测量眼图、抖动与上升下降时间，确认满足对应速率等级的模板要求。
- **阻抗验证**：核对板厂阻抗报告，必要时用时域反射法（TDR）实测差分阻抗。
- **兼容性矩阵**：在不同品牌主机、不同线缆、不同集线器组合下逐一测试枚举与传输，形成兼容性矩阵。
- **热插拔**：反复插拔数百次以上，确认每次都能正常枚举且无死机，统计失败次数。
- **长时间传输**：持续大流量读写数小时，确认无掉速、无断连、无误码。
- **供电测试**：测试各电压档位下的带载能力、纹波与转换效率；验证过流、过压与短路保护动作正确。
- **挂起电流**：测量挂起状态下的电流，确认满足规范要求。
- **极限与异常**：测试欠压、过压、插拔瞬断、线缆断开等异常场景，确认能自动恢复且不损坏。
- **ESD 与浪涌**：按产品等级（IEC 61000-4 系列）对接口做接触与空气放电测试，确认功能不中断或不损坏。
- **高低温**：在极限温度下重复关键测试，确认速率与供电能力不降级。

## 九、设计检查清单

1. 已明确所需速率等级，并按实际吞吐需求核算带宽且留有裕量。
2. USB 3.x 设计中已保留 USB 2.0 的 D+/D− 通路。
3. 设备侧上拉电阻已按速率等级正确配置在 D+ 或 D−。
4. 连接器型号、方向、引脚定义已核对，具备可靠的机械固定与屏蔽接地。
5. Type-C 的 CC1/CC2 上拉或下拉电阻已按角色与规范配置。
6. 所有差分对已按 90Ω 设计，制板说明中已注明阻抗要求。
7. 差分对未跨平面分割，换层次数与过孔数量已受控，两侧对称。
8. 超高速发送端的交流耦合电容已靠近发送端放置，取值符合手册。
9. 对外接口已配置低结电容的 ESD 与浪涌防护器件，且靠近连接器。
10. VBUS 走线载流满足最大电流要求，对外供电口已配置过流保护。
11. 设备侧 VBUS 总电容已核算，插入浪涌电流不超限。
12. 需要 PD 的产品已确定供电与受电策略，线缆识别与限流逻辑已实现。
13. 使用交替模式的产品已完成高速复用器选型与整链路插损核算。
14. 连接器屏蔽层的接地方式已按整机接地策略确定。
15. 已完成眼图与一致性测试，指标满足对应速率等级要求。
16. 已完成跨主机、跨线缆、跨集线器的兼容性矩阵测试。
17. 已完成数百次热插拔循环测试，失败率为零。
18. 已完成长时间大流量传输测试，无掉速与断连。
19. 挂起电流与异常恢复能力已验证。
20. 已通过 ESD 与浪涌测试，防护器件布局合理。

> 注：本文为 USB 接口的通用设计说明。具体速率等级、供电能力、连接器与线缆要求，最终以 USB-IF 相关规范、所用主控与连接器的数据手册为准；产品若需使用 USB 标识与认证，应在设计阶段同步规划一致性测试。

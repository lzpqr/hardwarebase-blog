LDO（Low Dropout Regulator，低压差线性稳压器）工作在晶体管线性区，通过负反馈环路调节调整管的等效导通阻抗，使输出电压稳定在设定值。相比 DC-DC 开关电源，它**无开关噪声、输出纹波极低、外围元件少、设计简单**，广泛用于对电源质量敏感的模拟前端、射频、时钟、音频与传感器等供电轨。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。大压差、大电流主供电见[DC/DC篇](/posts/component-selection-dc-dc/)，MOS 调整管方案见[MOS管篇](/posts/component-selection-mosfet/)。

LDO 的代价是效率近似 **η ≈ VOUT / VIN**，压差越大损耗越大，多余能量全部以热的形式在调整管上耗散。因此 LDO 选型的本质是在**噪声 / PSRR、静态功耗、压差、电流能力、散热与成本**之间做工程权衡。

## 1. LDO vs 开关电源：何时选 LDO

| 对比维度 | LDO | DC-DC 开关电源 |
| --- | --- | --- |
| 输出噪声 | 极低，几十 µVrms（低噪声型） | 较高，存在开关纹波与谐波 |
| 效率 | ≈ VOUT/VIN，压差大时低 | 高，可达 85%~95% |
| 外围元件 | 少（IC + 输入/输出电容） | 多（电感、反馈网络、补偿等） |
| PCB 面积 | 小（约 20~30 mm²） | 大（约 80~150 mm²） |
| EMI | 几乎无 | 需专门抑制，传导/辐射风险 |
| 适用场景 | 模拟/RF/ADC/时钟/音频供电轨 | 大压差、大电流、电池主供电 |

**工程上最常见的架构是级联（Cascade）**：前级 DC-DC 完成大压差降压保证效率，后级 LDO 做后级稳压（Post-regulation），用于清理开关噪声。此组合通常能在 100 kHz~2 MHz 区间额外获得约 15~35 dB 的噪声抑制。

## 2. 核心参数详解

**压差电压（Dropout）**：维持稳压所需的最小输入-输出电压差，即 VIN ≥ VOUT + Vdropout。现代 CMOS LDO 压差可低至 100 mV 级。当输入接近压差区时 PSRR、环路增益、瞬态响应会全面劣化，须留足裕量（建议 ≥ 200~300 mV）。电池直接供电时，超低压差器件可多榨取约 10%~15% 电池容量。

**静态电流 Iq 与关断电流**：LDO 自身在空载/轻载时消耗的电流（流经地引脚），直接决定待机续航。η = Io·Vo / [(Io + Iq)·Vi]。

| Iq 水平 | CR2032（220mAh）理论续航 | 典型适用场景 |
| --- | --- | --- |
| 1 µA | 约 25 年 | 极低功耗传感器节点 |
| 10 µA | 约 2.5 年 | 多数 IoT 设备 |
| 100 µA | 约 3 个月 | 基本不推荐用于电池常供电轨 |

低 Iq 与环路带宽天然矛盾：Iq 越低响应越慢。现代纳安级器件（如 TPS7A02 的 25 nA）已能兼顾低功耗与较快的瞬态响应。

**PSRR**：衡量将输入端纹波压制到输出端的能力，单位 dB。关键陷阱——PSRR 是频率相关的：低频（100~120 Hz）通常 60~80 dB，但随频率升高急剧下降，切勿只看 1 kHz 典型值。若前级为几百 kHz 的 DC-DC，必须查 PSRR-频率曲线。

| 器件类型 | 1 MHz 处 PSRR | 说明 |
| --- | --- | --- |
| 普通 LDO | 约 20~30 dB | 高频抑制能力弱 |
| 高性能 LDO | 40~60 dB | 如 LT3045 约 60 dB @1 MHz |
| 带 BYPASS/NR 引脚 | 可进一步提升 | 外接 10 nF~1 µF 降噪电容 |

**输出噪声**：主要来自内部基准源与误差放大器，通常几十到几百 µVRMS。对数字电路无关紧要，但对 24 位 ADC、PLL/VCO、射频前端、高保真音频是硬伤。单位陷阱：手册有时标 RMS、有时给峰峰值，高斯噪声下两者约差 6~6.6 倍，对比前务必统一单位与测试带宽。低噪声型可低至 0.8 µV(RMS)（LT3045）、4 µV(RMS)（TPS7A47）。

**瞬态响应**：负载电流从微安跳到几百毫安时，输出电容先顶上，环路随后补上。最大跌落近似：

    ΔVtr,max = [Io,max / (Cout + Cbyp)]·Δt₁ + ΔV_ESR

给射频功放、时钟电路供电时，瞬间跌落可能导致信号失真或频率偏移。

**调整率**：线性调整率（ΔVout/ΔVin，约 0.1~0.5 %/V）与负载调整率（ΔVout/ΔIout，几 mV 量级）均为稳态参数，与 PSRR 的动态频率响应互补。高精度设计建议做开尔文（Kelvin）远端采样，取样点尽量靠近负载。

**输出电容与环路稳定性**：LDO 是反馈环路，输出电容与其输出阻抗构成极点，直接影响相位裕度。

- **陶瓷电容陷阱**：老式（尤其双极型）LDO 依赖 ESR 提供稳定零点；直接用低 ESR 陶瓷电容替换钽电容可能引起振荡。优选明确标注 "Stable with Ceramic Capacitors" 且零 ESR 稳定的器件。
- **直流偏压降容**：陶瓷电容实际容值随直流电压与温度显著下降，须核对工作点下的有效容值而非标称值。
- **最小负载要求**：部分老器件需最小负载电流（如 5 mA）才能稳定，轻载易振荡，应避免。

## 3. 六步选型流程

| 步骤 | 工作内容 | 关键判断 |
| --- | --- | --- |
| 1 | 确定 VIN / VOUT / IOUT | 输入范围覆盖电池/前级，输出精度满足负载 |
| 2 | 计算压差裕量 | VIN,min − VOUT 大于最大负载下 Vdropout，并留 200~300 mV |
| 3 | 按噪声 / PSRR 选型 | 查 PSRR-频率曲线与输出噪声 RMS，对照后端敏感度 |
| 4 | 平衡 Iq 与瞬态 | 电池常供电轨优先低 Iq；动态负载优先高带宽/快瞬态 |
| 5 | 核算散热 | P = (VIN,max − VOUT)·IOUT，ΔT = P·θJA，校核结温 |
| 6 | 确定封装 / 电容 / 成本 | 匹配 PCB 面积与散热，确认输出电容类型与容值 |

**散热核算示例**：输入 4.2 V、输出 3.3 V、负载 0.5 A、SOT-223（θJA ≈ 80 °C/W）：

    P = (4.2 − 3.3) × 0.5 = 0.45 W
    ΔT = 0.45 × 80 = 36 °C
    环境 25 °C 时结温 ≈ 61 °C，满足降额要求。

若功耗 > 1 W，应改用 DFN / SOT-223 等带裸露焊盘的封装并加铺散热铜皮；必要时改用 DC-DC 或 LDO 控制器 + 外部调整管方案。

## 4. 典型应用场景

| 应用场景 | 关注重点 | 选型建议 |
| --- | --- | --- |
| IoT / 可穿戴节点 | Iq、关断电流、封装尺寸 | 纳安~微安级 Iq，小封装（X2SON/WLCSP） |
| 射频 / 时钟 / PLL | 高频 PSRR、低噪声 | 1 MHz PSRR ≥ 20~30 dB，噪声 < 10~20 µVrms，NR 脚接 10~100 nF |
| 精密 ADC / AFE | 噪声、调整率 | 超低噪声，模拟/数字轨分离，开尔文采样 |
| 高保真音频 | 1/f 噪声、宽带噪声 | 最低 1/f 噪声，可加 Cff 前馈电容改善高频 |
| CMOS 图像传感器 | 纹波、串扰 | 独立供电轨，Kelvin 采样，低纹波 |
| 工业 / 汽车高噪声 | 高频 PSRR、抗扰、认证 | 全陶瓷稳定、裸露焊盘封装，AEC-Q100 认证 |

## 5. 降噪与 PCB 布局

**降噪三要素**：

- NR/SS 引脚接 10 nF~1 µF 到地，滤除内部带隙基准噪声；容值越大噪声越低，但启动时间越长。
- 输出电容选低 ESR 陶瓷（1~10 µF），改善瞬态响应与高频 PSRR。
- 前馈电容 Cff：跨接于输出与反馈节点，可在中高频段提升环路增益与 PSRR。

**布局建议**：输入、输出电容贴近对应引脚，缩短高频回路；地回路要短，模拟地与功率地合理分割后单点连接；裸露焊盘可靠接地并铺铜散热；高精度场合用开尔文远端采样，取样点靠近负载。

## 6. 选型快速检查清单

- VIN 范围覆盖最坏情况（含电池满电/欠压、前级上电冲击）。
- 压差裕量在最大负载、最低温度下仍满足，并留 ≥ 200~300 mV。
- 已查看 PSRR-频率曲线，而非只看 1 kHz 典型值。
- 输出噪声统一了 RMS/峰峰值单位与测试带宽。
- 瞬态跌落满足后端芯片的绝对 mV 容限。
- Iq 与待机续航预算匹配，关断电流满足货架寿命要求。
- 输出电容类型/容值/ESR 落在数据手册稳定区间内，并校核直流偏压降容。
- 热核算通过，结温满足降额要求（一般留 > 20 °C 裕量）。
- 封装满足 PCB 面积与散热需求，必要时选裸露焊盘封装。
- 确认无最小负载限制，或设计中已保证最小负载。

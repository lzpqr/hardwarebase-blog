原理图在硬件开发中经常被看作一项“画图工作”：把器件摆上去，把网络连起来，把封装对上，似乎就完成了。但真正决定产品成败的问题，往往在原理图阶段就已经埋下。

电源树是否合理，接口保护是否到位，时序是否可控，测试点是否留够，关键器件是否可持续供货，以及方案是否真的满足需求和成本目标，都会在原理图中留下痕迹。

原理图是硬件产品的第一份完整技术契约。它向上承接需求、方案和成本约束，向下决定 PCB 布局、BOM 成本、生产测试、认证风险和售后维护难度。

一张合格的原理图，不仅要“能工作”，还要做到可读、可查、可测、可制造、可维护。

> 本文是硬件开发流程系列的第四篇。建议先阅读 [方案设计篇](/posts/hardware-development-solution-design/) 和 [需求分析篇](/posts/hardware-development-requirements-analysis/)。

## 原理图设计的目标与边界

### 原理图要回答的五个问题

1. 信号从哪里来、到哪里去？
2. 电从哪里来、经过什么路径？
3. 器件为什么这样选？
4. 异常时会发生什么？
5. 这张图如何被验证？

如果一张原理图无法回答这些问题，说明它只是完成了连线，还没有完成设计。

### 原理图设计的三层目标

| 层次 | 目标 | 典型表现 |
| --- | --- | --- |
| 功能正确 | 电路能实现预期功能 | 上电可用、接口能通、指标达标 |
| 工程可靠 | 在真实环境和全生命周期内稳定 | 通过 EMC、高低温、振动和寿命测试 |
| 产品可交付 | 能高效、低成本地生产维护 | BOM 可控、测试高效、问题可定位 |

很多团队只关注第一层，结果样机阶段“能跑”，量产阶段问题集中爆发。原理图评审必须同时覆盖后两层。

### 明确设计边界

动手画图之前，需要先明确哪些内容属于本板，哪些属于外部系统：

- 本板负责哪些功能；
- 板间接口的电气定义和连接器引脚；
- 供电边界和上电、掉电时序；
- 单板地、机壳地、模拟地和数字地的连接关系；
- 哪些引脚由软件配置，哪些状态需要软件读取；
- 哪些参数在单板测试，哪些在整机测试。

建议用一页系统边界图，把这些问题固化在原理图首页。

## 1. 设计输入：动手之前必须确认的内容

### 需求和规格

原理图设计输入至少应包含：

- 功能需求：模块、优先级和资源需求；
- 性能指标：精度、速率、功耗、响应时间和输出功率；
- 环境条件：温度、湿度、振动、防护等级和海拔；
- 电气条件：输入范围、额定电流、浪涌和绝缘耐压；
- 接口定义：连接器、协议、电平和引脚定义；
- 认证要求：CE、FCC、CCC、UL、RoHS 和 REACH；
- 成本目标：整机 BOM、关键器件成本上限和替代方案；
- 生命周期与供货：预计产量、生命周期和器件供应风险。

### 关键约束确认

| 类别 | 需要确认的问题 |
| --- | --- |
| 电源 | 输入范围、最大电流、效率、待机功耗和上电时序 |
| 时钟 | 精度、抖动、温漂和外部同步需求 |
| 复位 | 阈值、时间、手动复位和看门狗 |
| 接口 | 电平、速率、隔离、保护等级和线缆长度 |
| 存储 | 容量、接口、读写寿命和掉电保护 |
| 散热 | 主要热源、允许温升和导热路径 |
| 结构 | 板尺寸、安装孔、连接器位置和限高 |
| 测试 | 产线测试、测试点、烧录和校准接口 |

### 方案选型和预研

正式绘制前，建议确认：

- 核心芯片是否有成熟参考设计；
- 关键器件是否量产，是否有第二货源；
- 电源方案的效率、纹波和热设计是否明确；
- 高速接口是否需要阻抗控制和信号完整性分析；
- 无线模块、天线和传感器是否有布局约束；
- 软件资源是否能够满足需求。

预研结论应形成书面记录，作为原理图设计输入的一部分。

## 2. 图纸规范：让原理图可读、可查、可维护

### 图幅和页码

- 使用统一的图框模板；
- 标注产品名、单板名、版本、日期、设计者和审核者；
- 多页原理图建立清晰的页码和目录；
- 首页放系统框图和目录；
- 使用跨页连接符或层次化端口，避免长线连接。

### 网络命名

网络命名直接影响图纸可读性：

- 功能明确，例如 `UART1_TX` 优于 `TX1`；
- 方向明确，例如使用 `_IN`、`_OUT`、`_REQ` 和 `_ACK`；
- 极性明确，低有效信号统一使用 `_N` 或 `#`；
- 跨电压域信号包含电压信息，例如 `SPI_CS_1V8`；
- 差分对成对命名，例如 `USB_DP/USB_DM`；
- 避免大量自动生成的匿名网络；
- 电源、地、时钟、复位和模拟信号采用统一前缀。

### 器件位号和属性

- 位号按器件类型统一编号；
- 位号在整板范围内唯一；
- 器件属性包含型号、封装、容差、耐压、功率、温度等级和精度；
- 关键器件标注选型依据；
- 不使用的引脚、预留器件和可选器件明确标注。

### 图形和连线

- 连线尽量横平竖直；
- 同一网络优先使用网络标签；
- 电源和地使用标准符号；
- 重要信号标注阻抗、频率、电流和上升时间；
- 模块之间使用框线和分区；
- 每个模块保留简短说明，解释设计意图和注意事项。

### 版本和变更管理

- 原理图必须纳入版本管理；
- 变更记录包含内容、原因、影响、验证结果、责任人和日期；
- 关键变更同步更新 BOM、PCB、软件配置和测试文档；
- 已发布版本未经评审不得直接修改。

## 3. 器件选型与 BOM 前移

### 选型维度

| 维度 | 关注点 |
| --- | --- |
| 电气参数 | 电压、电流、功率、精度、带宽和漏电流 |
| 封装工艺 | 封装尺寸、引脚间距、焊接和散热 |
| 温度等级 | 商业级、工业级、汽车级和高温漂移 |
| 稳定性 | 初始误差、温漂、时漂和长期稳定性 |
| 供货成本 | 生命周期、交期、价格和第二货源 |
| 认证合规 | RoHS、REACH、UL 和 AEC-Q |
| 生态支持 | 参考设计、仿真模型和驱动支持 |
| 可替代性 | 引脚兼容、软件兼容和替代验证成本 |

### 降额设计

原理图阶段应完成关键器件的降额核算：

- 电容工作电压不超过额定值的 50%～80%；
- 电阻实际功率通常不超过额定功率的 50%；
- 二极管、电感、连接器和 MOSFET 留出电压、电流和温度裕量；
- 降额计算写入设计记录，不能只凭经验估计。

### BOM 前移

- 所有器件都有明确型号、封装和位号；
- 关键器件标注生命周期和预估用量；
- 长交期、单货源和停产物料提前准备替代方案；
- 区分必贴、选贴和不贴器件；
- 核对封装与实物一致性。

## 4. 电源设计

### 电源树

电源树应说明：

- 输入来源、范围和最大电流；
- 每一级转换的输入输出、效率和负载能力；
- 各电压域负载和峰值电流；
- 上电、掉电时序；
- 电源监测、复位和故障保护。

电源树应该放在原理图首页，并与实际电路一一对应。

### 输入保护

- 反接保护；
- 过压保护；
- 过流保护；
- 浪涌保护；
- 输入滤波和去耦；
- 热插拔浪涌限制。

保护器件必须与工作电压、故障电流和认证要求匹配。

### DC-DC 和 LDO

DC-DC 重点关注输入输出范围、开关频率、电感参数、电容类型、反馈网络、环路稳定性和开关节点布局。

LDO 重点关注压差、静态电流、调整率、功耗、结温、输出电容和 PSRR。

功耗计算公式：

```text
P = (Vin - Vout) × Iout
```

### 去耦和上下电时序

- 每个电源引脚配置去耦电容；
- 大容量储能电容与高频去耦电容配合；
- 模拟、数字和接口电源分别滤波；
- 明确上电顺序、时间间隔和单调性；
- 保证所有电源稳定后再释放复位；
- 掉电时保证关键数据能够正确保存。

## 5. 时钟、复位与最小系统

### 时钟源

根据精度、抖动和功耗选择晶体、晶振、硅振荡器或外部时钟。确认负载电容、串联电阻和驱动能力，并预留测试点。

### 复位电路

- 复位阈值覆盖电源波动范围；
- 复位脉冲宽度满足器件手册要求；
- 复位信号远离高噪声区域；
- 明确上电复位、手动复位、看门狗和软件复位的优先级；
- 多器件系统注意复位释放顺序。

### 最小系统

最小系统通常包括电源、去耦、时钟、复位、启动配置、存储介质、调试接口、上下拉和状态指示。

启动配置引脚必须明确默认电平，避免悬空导致异常启动。

## 6. 接口电路设计

### I²C

- 根据总线电容和速率选择上拉电阻；
- 检查多主多从地址冲突；
- 长距离总线考虑缓冲和隔离；
- 预留测试点。

### SPI

- 确认时钟极性、相位、最高速率和片选逻辑；
- 多从机系统注意片选和上拉；
- 长距离传输考虑串联端接和缓冲。

### UART、GPIO

UART 需要交叉 TX/RX，确认 TTL、RS-232 或 RS-485 电平，预留调试串口。

GPIO 需要明确方向、默认状态、上下拉和驱动能力；未使用引脚按手册处理。

### 高速接口

USB、以太网、PCIe、MIPI、HDMI 等接口需要关注：

- 差分阻抗和长度匹配；
- 交流耦合和终端电阻；
- 时钟架构和复位时序；
- ESD 和浪涌保护；
- PCB 布局约束在原理图上明确标注。

### 调试和烧录

预留 SWD/JTAG、UART、USB 或专用烧录接口，并考虑产线夹具、ESD 和误插保护。

## 7. 模拟与混合信号设计

### 基准源

基准源的初始误差、温漂、噪声和长期稳定性必须满足精度要求，并远离数字噪声和开关电源。

### ADC 和 DAC

- 模拟输入范围与 ADC 匹配；
- 必要时增加缓冲、滤波和抗混叠电路；
- 控制采样时钟抖动和电源噪声；
- 数字接口与模拟部分隔离。

### 运放和滤波器

根据带宽、压摆率、失调、噪声和功耗选择运放，并准确计算反馈网络和补偿电容，避免自激振荡。

### 接地与屏蔽

模拟地、数字地和功率地在原理图阶段就要规划单点连接或分区策略，避免地环路。## 8. 保护、可靠性与安规

### ESD 和浪涌保护

- 所有对外接口都需要考虑 ESD 保护；
- 保护器件尽量靠近连接器；
- 根据信号速率选择钳位电压、结电容和响应时间；
- 为电源、信号和地分别设计低阻抗泄放路径；
- 明确接触放电、空气放电和浪涌测试等级。

### 过压、过流与反接保护

- 输入端配置过压、过流、反接和浪涌保护；
- 输出端配置短路保护、限流和热关断；
- 感性负载增加续流和钳位电路；
- 电池产品考虑过充、过放、过温和电池保护 IC。

### 隔离与安规

- 根据标准确定爬电距离、电气间隙和绝缘等级；
- 强弱电之间使用隔离电源、隔离器或光耦；
- 隔离器件的耐压和认证等级满足目标标准；
- 地系统、Y 电容和屏蔽连接符合安规与 EMC 要求。

### 热设计

- 估算主要器件的功耗和温升；
- 评估散热焊盘、导热路径和风道；
- 温度敏感器件远离热源；
- 预留温度传感器和热保护电路。

## 9. EMC 与信号完整性

很多人认为 EMC 和信号完整性是 PCB 阶段的问题，实际上大量问题在原理图阶段已经决定。

### 原理图阶段可以完成的 EMC 工作

- 选择接口保护和滤波方案；
- 规划电源、地和回流路径；
- 为高速信号标注阻抗、长度和参考平面要求；
- 配置端接、共模电感和磁珠；
- 标注时钟、开关电源和高速接口的布局约束；
- 预留 EMC 调试用的元件位置。

### 常见 EMC 风险

| 风险点 | 原理图层面的对策 |
| --- | --- |
| 开关电源噪声 | 选择合适开关频率、输入输出滤波和回流路径 |
| 时钟谐波辐射 | 降低驱动能力、串联端接、包地和屏蔽 |
| 接口线缆辐射 | 共模电感、滤波、屏蔽和 ESD 保护 |
| 地弹和共阻抗 | 合理分区、单点连接、降低地阻抗 |
| 电源纹波耦合 | 去耦、滤波、独立电源和磁珠隔离 |
| 高速信号反射 | 端接匹配、阻抗控制和拓扑优化 |

### 信号完整性关键参数

- 上升时间、带宽和信号频率；
- 传输线阻抗和端接方式；
- 走线长度、延迟匹配和过孔数量；
- 参考平面连续性和回流路径；
- 串扰、损耗和抖动预算。

这些参数应在原理图上标注，作为 PCB 设计输入。

## 10. 低功耗设计

### 功耗预算

建立功耗预算表，记录：

- 各模块工作、待机和峰值电流；
- 不同工作模式下的功耗和占空比；
- 电源转换效率产生的额外损耗；
- 电池容量、续航时间和自放电；
- 温度对功耗和电池性能的影响。

### 低功耗设计要点

- 选择低静态电流的电源芯片和器件；
- 支持分区供电和动态关断；
- 合理使用休眠、停机和唤醒机制；
- 关注上拉电阻、指示灯和分压电路的静态功耗；
- 避免关断状态下的漏电通路和反向供电；
- 预留电流测量点和功耗调试手段。

## 11. 可测试性、可制造性与可服务性

### 可测试性（DFT）

- 关键电源、时钟、复位和总线预留测试点；
- 测试点尺寸、间距和位置便于探针或夹具接触；
- 预留产线烧录、校准和功能测试接口；
- 不可直接测量的信号增加测试缓冲或监测电路；
- 关键电路支持隔离和旁路，方便故障定位。

### 可制造性（DFM）

- 器件封装与生产工艺匹配；
- 极性器件、连接器和按键方向标注清晰；
- 避免器件布局冲突和组装干涉；
- 为手工焊接或返修器件留出空间；
- 评估工艺边、拼板和分板方式的影响。

### 可服务性

- 关键器件可更换、可维修；
- 预留故障指示和自诊断能力；
- 现场升级和维护有明确接口；
- 记录关键设计参数和校准数据。

## 12. 原理图评审

### 评审流程

建议采用分层评审：

1. 自检；
2. 交叉评审；
3. 专业评审；
4. 发布评审。

所有问题闭环后，才能正式发布原理图版本。

### 评审角色

| 角色 | 关注重点 |
| --- | --- |
| 硬件设计者 | 功能、参数、连接和封装 |
| 硬件评审人 | 规范、可读性和常见错误 |
| 电源工程师 | 电源树、效率、纹波、时序和热 |
| 模拟/射频工程师 | 噪声、匹配、接地和屏蔽 |
| EMC 工程师 | 滤波、保护、接地和接口 |
| 软件工程师 | 引脚分配、电平、启动和调试接口 |
| 结构工程师 | 板尺寸、连接器、限高和散热 |
| 测试工程师 | 测试点、夹具、烧录和产线测试 |
| 采购/供应链 | 生命周期、交期、成本和替代料 |

### 评审要点

- 功能是否完整；
- 电源树是否闭合，降额是否满足；
- 接口电平和保护是否合理；
- 时钟、复位和启动配置是否正确；
- 高速信号约束是否标注；
- 测试点和调试接口是否预留；
- BOM 和替代料是否可行；
- 是否满足安规、EMC 和环保要求；
- 版本和变更记录是否一致。

## 13. 常见错误

### 电源类错误

- 缺少电压域；
- 去耦电容不足；
- DC-DC 反馈电阻计算错误；
- 上电时序不满足；
- 未考虑峰值电流；
- LDO 功耗超标。

### 接口类错误

- TX/RX 未交叉；
- 电平域不匹配；
- I²C 上拉缺失或阻值不当；
- 差分对极性接反；
- 未使用引脚悬空；
- 连接器引脚定义不一致。

### 时钟和复位类错误

- 晶体负载电容计算错误；
- 复位释放时间不足；
- 启动配置引脚电平错误；
- 复位信号受到干扰。

### 可制造性错误

- 封装与实物不一致；
- 极性器件方向标注不清；
- 器件间距过小；
- BOM 中存在停产或长交期器件。

这些问题通常来自三个根源：设计输入不完整、评审不充分、变更不受控。

## 14. 从原理图到 PCB 的交接

原理图评审通过后，需要向 PCB 设计传递完整约束：

- 板框、安装孔、连接器位置和限高；
- 叠层、阻抗和参考平面；
- 电源分配、电流路径和散热要求；
- 高速信号拓扑、长度匹配和差分规则；
- 模拟与数字分区、接地和屏蔽要求；
- 关键器件布局约束；
- 测试点、调试接口和制造要求。

交接应以书面形式完成，并在 PCB 设计过程中保持沟通。

## 15. 原理图设计的四个层次

原理图设计能力可以分为四个层次：

1. 会画：能正确连接电路，完成基本功能；
2. 会算：能进行参数计算、降额核算和功耗预算；
3. 会防：能预见异常工况，设计保护、冗余和容错；
4. 会交付：能兼顾成本、可制造、可测试和可维护。

从“会画”到“会交付”，靠的不是更多技巧，而是系统化设计、严谨评审和持续的问题闭环。

一份好的原理图，是硬件产品可靠性的起点，也是团队工程能力的直接体现。

## 附录 A：原理图评审检查清单

### 文档与规范

- 图框信息完整；
- 页码、分区和目录清晰；
- 网络命名规范；
- 器件位号唯一；
- 版本记录与 BOM、PCB 一致。

### 电源

- 电源树完整；
- 输入保护齐全；
- 效率和热设计满足要求；
- 去耦电容数量和位置合理；
- 上下电时序满足要求；
- 电源监测和故障保护完善。

### 时钟与复位

- 时钟频率和精度满足要求；
- 晶体负载电容匹配；
- 复位阈值、宽度和释放顺序正确；
- 启动配置引脚正确；
- 预留时钟和复位测试点。

### 接口

- 电平和协议匹配；
- 上拉、下拉和端接正确；
- 差分对极性和阻抗明确；
- ESD 和浪涌保护到位；
- 未使用引脚按手册处理；
- 调试和烧录接口预留。

### 模拟与混合信号

- 基准源精度、温漂和噪声满足要求；
- ADC/DAC 输入输出匹配；
- 滤波器参数正确；
- 模拟地与数字地策略明确；
- 敏感信号有屏蔽或隔离。

### 可靠性与可制造性

- 关键器件降额满足规范；
- 安规和隔离要求满足；
- BOM 和封装一致；
- 测试点、烧录和校准接口齐全；
- 极性器件方向标注清晰；
- 可维修性和故障隔离考虑充分。

### 软件协同

- 引脚分配与软件配置一致；
- 中断、使能和状态信号定义清晰；
- 启动模式、复位和调试接口满足软件需求；
- 与外部系统的接口边界和时序明确。

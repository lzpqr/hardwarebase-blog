传感器与射频是硬件系统里"参数最容易被当成装饰性指标"的两类器件。电阻电容选型看的是精度和降额，传感器选型的本质是**把系统的测量需求翻译成一组器件指标**；射频选型则是**把链路预算分解到每一级**。两类器件的共性是：指标不是越"好"越贵越好，而是**够用、可标定、可量产**才好。这篇把传感器的精度-噪声-标定链路和射频的增益-噪声-匹配链路各拉一条主线，给出可复用的选型判据。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。传感器前端常接 ADC，参考[ADC篇](/posts/component-selection-adc/)；射频参考源涉及时钟，参考[晶振篇](/posts/component-selection-crystal/)。

## 1. 核心观点

传感器与射频器件选型不是"选个精度高的"，而是回答三个问题——

1. **系统到底要测什么、到什么精度**（需求 → 指标翻译）；
2. **信号链上每一级够不够用**（器件 → 链路分解）；
3. **能否稳定标定与量产**（一致性 → 供货）。

一条铁律：**器件指标是"单件"指标，系统指标是"整链"指标。** 传感器 0.1% 精度配个 1% 温漂的参考源，整链精度就是 1%；射频 LNA 噪声系数 1 dB，但天线失配损耗 3 dB，系统灵敏度照样掉 3 dB。

## 2. 传感器选型：先把需求翻译成指标

### 2.1 需求 → 指标的翻译

传感器选型的第一步永远不是翻规格书，而是回答：测什么物理量、量程多少、精度上限、采样率、工作温区、供电、接口（模拟/数字）、寿命与标定周期。把这七项写清楚，候选器件会立刻收敛。

| 需求项 | 决定什么 | 常见误区 |
| --- | --- | --- |
| 物理量与量程 | 器件类型与规格档 | 量程留太满，精度被拉低 |
| 精度上限 | 分辨率、噪声、线性度、温漂的组合 | 只看分辨率（位数）不看噪声 |
| 采样率 | 响应时间、带宽、数字接口速率 | 响应时间≠带宽，两者都要校 |
| 工作温区 | 温漂系数、材料、封装 | 常温指标当全温区指标用 |
| 供电 | 静态功耗、单端/差分、电源噪声敏感度 | 电池设备漏看静态电流 |
| 接口 | 模拟需配运放+ADC，数字看总线 | 模拟输出没算前端 ADC 匹配 |
| 寿命与标定 | 重复性、长期漂移、标定周期 | 没留标定与补偿余量 |

### 2.2 六个必须分清的核心参数

- **分辨率（Resolution）**：ADC 位数决定的最小可分辨步长，是"能报出多少位"，**不等于能测多准**。
- **噪声（Noise，RMS / µV）**：无输入时的输出波动，决定"能测多小"。8 位 ADC 但噪声 3 LSB 的场景，有效位远不足 8。
- **灵敏度 / 满量程（FS）**：物理量变化对应输出变化，选型要确认线性范围内 FS 与目标量程匹配。
- **线性度（Linearity）**：输出与输入的理想直线偏离度。大范围量程下线性度常被噪声淹没。
- **迟滞（Hysteresis）**：正向与反向扫描输出的差值，机械量（位移、压力、重量）场景必查。
- **温漂（Temperature Coefficient / TCR）**：灵敏度与零点随温度的变化。全温区精度 = 常温精度 + 温漂项叠加。
- **响应时间 / 带宽**：动态信号看带宽，阶跃跟踪看响应时间（通常 1/带宽量级），两者不可互相替代。

**精度预算口诀**：有效精度 ≈ 量程 / 噪声（RMS）× 线性度修正 × 温漂修正。任何一个环节超标，全链精度就塌到那个环节。

### 2.3 前端匹配（模拟输出传感器）

模拟输出传感器几乎总需要运放调理 + ADC 量化，选型时要一起看：

- **信号幅度与 ADC 满量程匹配**：传感器 FS 输出应对到 ADC 的 80%~95% 量程，留削峰余量又不过分压缩分辨率。
- **噪声链**：传感器噪声 + 运放噪声 + ADC 量化噪声 + 参考源噪声，逐级折算到输入端再平方和根（RSS）。
- **参考源温漂**：VREF 的温漂直接乘到所有读数上，高精度场景参考源要选低 TCR（如 ppm/℃ 级）并与传感器同温区。
- **共模与接地**：远端传感器（长走线）看共模范围、驱动能力，必要时用隔离或仪表放大器。

数字接口传感器（I2C/SPI/SENT）则要确认**采样率、内部 ADC 位数、接口速率上限、是否自带标定**。

## 3. 射频器件选型：按链路预算分解

射频器件的选型是"链路预算"驱动：先定系统灵敏度/最大可接收功率，再把增益、噪声、线性、匹配分配到每一级。

### 3.1 各级器件与第一约束

| 器件 | 第一约束 | 关键参数 | 常见误区 |
| --- | --- | --- | --- |
| 天线 | 效率 / 匹配 | 增益、阻抗(50Ω)、VSWR、极化、方向图 | 只看 dBi 增益不看失配损耗 |
| LNA | 噪声系数 NF | NF、增益、OIP3、功耗 | 增益拉满导致后级过载 |
| 滤波器 | 带外抑制 | 通带插损、阻带抑制、带边陡峭度 | 通带插损没计入链路预算 |
| 混频器 / VCO | 无杂散 / 相噪 | 变频损耗、本相噪、无杂散区(NFT) | 本振相噪抬升系统相噪 |
| PA | 效率 / 线性 | P1dB、PAE、OIP3、负载/源匹配 | 只看 P1dB 不看 PAE（电池设备） |
| 参考源 | 相噪 / 稳定度 | 参考频率、相噪、温漂、牵引 | 参考相噪污染整个发射频谱 |
| 射频前端模组 | 集成度 | 频段、MIMO 通道数、协议 | 集成度高但灵活性/成本要评估 |

### 3.2 三个贯穿性的量

- **噪声系数 / 相噪**：接收灵敏度由前级噪声系数主导，LNA 的 NF 与天线失配损耗、滤波器插损都要折算进去；发射频谱由参考源相噪与 PA 的非线性主导。
- **线性度（OIP3 / P1dB）**：多通道、高动态场景看 IIP3/OIP3，决定了能压多少带外阻塞信号。PA 的 P1dB 决定最大输出功率，PAE 决定效率与发热。
- **阻抗匹配（VSWR / 插入损耗）**：每个射频接口都要 50 Ω（少数视频 75 Ω）匹配，失配损耗直接吃链路预算，且随温度、装配、走线变化。

**选型判断**：低噪声接收 → 优先 NF 与匹配；高功率发射 → 优先 P1dB/PAE/散热；多协议窄带 → 优先滤波器带边与 PA 线性；电池设备 → PAE 与静态功耗是生死线。

### 3.3 封装与布局

- **射频封装寄生**：射频器件（尤其 PA、LNA）的封装寄生电感/电容直接影响匹配，SMA/DFN/QFN 的匹配网络要在实际封装上仿真，不能只看理想模型。
- **走线阻抗与参考平面**：50 Ω（或 75 Ω）微带/同轴走线，参考平面完整、过孔残桩控制好；射频走线短、等长对称。
- **隔离与屏蔽**：收放之间、LNA 与 PA 之间要隔离，必要时加屏蔽壳/隔离墙，防止自激与互调。
- **热**：PA 散热面积、热阻要与功耗匹配，大功率场景预留散热路径。

## 4. 六步选型流程（传感器与射频通用）

1. **定系统指标**：测量范围/精度 或 收发灵敏度/最大功率/频段/协议。
2. **分解到器件**：把系统指标拆成器件参数（噪声/线性/增益/匹配/带宽）。
3. **初筛候选**：按类型、频段、接口、封装筛出 2~3 家。
4. **链路核算**：噪声系数链 / 增益链 / 匹配损耗 / 线性度逐项算通。
5. **标定与一致性**：明确标定方法、温区、寿命末漂移、批次分散性。
6. **验证与供货**：S 参数/实机灵敏度测试、生命周期与二供。

### 选型决策检查清单（逐项打勾，任何一项不能确认都应重新评估）

| # | 检查项 | 确认标准 |
| --- | --- | --- |
| 1 | 系统指标已翻译成器件指标 | 精度/灵敏度/频段明确 |
| 2 | 量程/增益匹配且留余量 | FS 用到 80%~95% 量程 |
| 3 | 噪声/相噪链核算通过 | 折算到系统仍达标 |
| 4 | 线性度/迟滞满足精度 | 全温区叠加后达标 |
| 5 | 温漂计入寿命末期 | 最恶劣温度+老化后仍达标 |
| 6 | 前端匹配/参考源确认 | VREF、LNA 匹配、50 Ω |
| 7 | 响应时间/带宽确认 | 动态信号不失真 |
| 8 | 封装寄生与布局落地 | S 参数/仿真验证 |
| 9 | 标定方案与周期 | 可量产、可追溯 |
| 10 | 供货与二供 | 生命周期、一致性、Pin-to-Pin |

## 5. 常见问题与避坑

**只看出厂精度，不看温区与寿命末期**：规格书首页精度多为 25℃ 标称值，全温区与 3~5 年后的精度要按温漂+老化叠加，工业/车规尤其要校最恶劣工况。

**分辨率当精度**：16 位 ADC ≠ 能测到 16 位精度，噪声和参考源温漂决定有效位。先算有效精度再定器件。

**射频只看增益不看噪声与失配**：LNA 增益拉满若后级过载、天线失配 3 dB 没算，系统灵敏度照样掉。链路预算必须全链折算。

**PA 只看 P1dB 不看 PAE**：电池设备里 20% PAE 与 60% PAE 的功耗差数倍，发热差数倍，直接决定散热方案。

**参考源相噪被忽略**：参考源相噪污染整个发射频谱，高速率通信（Wi-Fi/5G）尤其敏感，参考源选型要单独核算相噪。

**封装寄生没在实封装上仿真**：射频匹配网络必须用实际封装的 S 参数仿真，理想模型算出的匹配上板就会偏。

**标定缺失**：传感器批次分散性是量产一致性隐患，量产前做批次标定曲线，预留软件校准余量，关键量做周期复标。

**避坑要点**

- 精度按"全温区 + 寿命末期"叠加预算，不用常温标称值。
- 射频链路逐级算噪声、增益、失配、线性，不用规格书首页典型值。
- PA 同时看 P1dB 与 PAE，接收链同时看 NF 与匹配损耗。
- 批次分散性与标定方案写进量产导入条件。

**评审建议**：设计评审阶段引入本清单逐项确认；样品阶段完成全温区、全频段实机测试（灵敏度、EVM、VSWR、噪声链）；量产前完成批次一致性与长期漂移验证，关键参数留足裕度。

> 本文档为技术参考速查，具体设计以器件官方数据手册与实测链路预算为准。高精度与射频应用需以实机链路测试为准。

光电耦合器（Optocoupler，光耦）是隔离设计里最常见、也最容易"用对了参数、用错了场景"的器件。它的本质是 **LED → 光 → 光敏接收器** 的单向能量转换：输入端电流驱动 LED 发光，输出端光敏器件接收光后转换成电信号，输入输出之间没有电气连接，仅通过光耦合。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。功率开关的隔离栅极驱动场景可结合[MOS管篇](/posts/component-selection-mosfet/)理解，高速多通道替代方案可对比数字隔离器。

## 1. 先想清楚：光耦的三条固有特性

这三个特性是所有选型矛盾的源头：

1. **单向传输**：只能从输入传到输出，天然适合同步信号隔离，不适合双向总线（除非用双光耦背靠背）。
2. **存在老化机制**：LED 光输出功率随累计通电时间和结温单调衰减，这是不可逆的物理过程，CTR 衰减是光耦寿命的头号杀手。
3. **速度受限于载流子与结电容**：光敏三极管型带宽通常只有几十 kHz 到几百 kHz，高速场景必须换光电二极管 + 逻辑门或光电 IC 型。

**选型最常见的错误**：把"能导通"当成"能用"。记住一句话——光耦选型的核心不是"能不能用"，而是"用久了还行不行"。

## 2. 按应用方向定关注点（先缩小范围）

| 应用方向 | 首选关注参数 |
| --- | --- |
| 数字信号 / 通用隔离 | CTR、传输速率、CMTI |
| 模拟信号传输 | CTR 线性度与温漂（必须选线性光耦） |
| 功率 MOS / IGBT 栅极驱动 | 专用栅极驱动光耦，CMTI、峰值电流、UVLO |
| 高压安全隔离（医疗 / 电网 / 充电桩） | 隔离电压、爬电距离、安规认证等级 |

## 3. 关键参数逐项解读

### 3.1 电流传输比 CTR（最重要的直流参数）

CTR = (I_C / I_F) × 100%。设计公式（共射极输出、上拉电阻 R_L）：

    R_L(max) = V_OL_max / I_C(min)
    I_C(min) = CTR_min × I_F

**设计要点**：

- CTR 是范围不是定值，数据手册给 CTR_min ~ CTR_max（如 50%~600%），常按 rank 分档供货，设计必须按 CTR_min 做最坏情况。
- CTR 随时间衰减：主动向厂家索取 CTR 退化曲线，或按保守值设计。
- **降额准则**：按寿命末期（EOL）CTR 的 50%~70% 留设计裕量；长期高温工况（结温 > 85℃）建议留到 50%。

### 3.2 隔离电压（三个指标不能混用）

| 指标 | 符号 | 含义 | 选型意义 |
| --- | --- | --- | --- |
| 瞬时隔离电压 | V_ISO | 1 秒/1 分钟耐压测试值 | 反映介质耐压能力 |
| 工作隔离电压 | V_IORM | 连续工作下允许的最高隔离电压 | **安规设计用这个** |
| 浪涌隔离电压 | V_IOSM | 脉冲条件下的峰值承受能力 | 反映抗瞬态能力 |

**要点**：隔离电压与封装强相关（DIP-4 常规约 3.75~5 kVrms，宽体 SMD 可达 7.5 kVrms 以上）。医疗、电网、充电桩产品应直接按安规标准（UL 1577、IEC 60747-5-5、VDE 0884-10/11、CQC）的 V_IORM 与爬电距离/电气间隙选型，而非看厂家宣传耐压值。

### 3.3 传输速率分档

| 类型 | 典型带宽 / 速率 | 典型器件形态 |
| --- | --- | --- |
| 通用型（光敏三极管） | DC ~ 几十 kHz | 4 脚 DIP/SOP |
| 高速型（光电二极管 + 逻辑输出） | 1 ~ 50 Mbps | 6/8 脚，带使能、图腾柱输出 |
| 超高速 / 数字隔离器替代 | 50 Mbps ~ 150 Mbps | 电容/磁耦合数字隔离器 |

关键延时参数：t_PLH / t_PHL（传播延时）、PWD = |t_PLH − t_PHL|（脉宽失真，对 PWM 尤为关键）、t_r / t_f。选型准则：信号周期应 ≥ 5~10 倍传播延时，并保证 PWD 最坏情况不破坏时序。

### 3.4 共模瞬态抗扰度 CMTI（高 dv/dt 场景头号参数）

CMTI 表示输入输出间存在快速共模电压跳变时输出不误翻转的能力，单位 kV/µs。

- 普通光耦 CMTI 可能只有 5~10 kV/µs，专用栅极驱动光耦可达 25~50 kV/µs 以上。
- CMTI 与隔离电容 C_ISO 强相关：C_ISO 越小，共模电流 I_cm = C_ISO × dv/dt 越小，抗扰越强。
- **测试条件必须核对**：不同厂家标注的 V_CM 幅值、温度、电源电压条件不同，横向比较前必须统一条件。
- 电机驱动、逆变器场景按实测 dv/dt 的 2 倍以上作为 CMTI 需求（SiC/GaN 器件 dv/dt 更高，要求更严）。

### 3.5 输入侧参数

- I_F 推荐工作点 5~20 mA，不要顶到最大值。
- V_F 典型 1.1~1.4 V（红外 LED），随温度负漂。
- 反向耐压 V_R 通常仅 3~6 V，必须加防反二极管或串联防反。
- **实践提醒**：驱动 LED 时恒流优于限流电阻——限流电阻会让 I_F 随 V_F 温漂大幅波动，直接放大 CTR 分散性。

### 3.6 输出侧参数

输出类型决定一切：光敏三极管（模拟/低速）、达林顿（高 CTR 低速）、光电二极管 + 逻辑门（高速）、光电 IC（高速 + 可控）。I_O 与 V_CE(sat) 决定能驱动多大负载；低功耗设计关注 I_CEO 漏电流。

### 3.7 环境与可靠性参数

| 参数 | 关注点 |
| --- | --- |
| 工作温度 | 工业级 −40~+105℃，车规 −40~+125℃ |
| MSL | 影响生产前烘烤与开封管理 |
| 认证 | UL / VDE / CQC / AEC-Q102（车规光耦） |
| 焊接耐温 | 无铅回流焊 260℃ |

## 4. 封装与隔离能力对照

| 封装 | 脚距 / 尺寸 | 隔离电压（典型） | 适用场景 |
| --- | --- | --- | --- |
| DIP-4 | 2.54 mm | 3.75~5 kVrms | 通用信号隔离、低成本 |
| SOP-4 / SSOP-4 | 1.27 mm | 2.5~3.75 kVrms | 高密度板、消费类 |
| DIP-6 / SOP-5 | 2.54 / 1.27 mm | 3.75~5 kVrms | 高速光耦、带使能 |
| 宽体 SOP（Wide-body） | ≥ 8 mm 爬电 | 5~7.5 kVrms | 工业、安规要求高 |
| 大爬电 DIP（加长型） | > 8 mm | 7.5~10 kVrms | 医疗、电网、充电桩 |

**封装三原则**：隔离等级决定封装下限（安规爬电距离直接排除一批封装）；板上空间决定封装上限（高密度板只能在 SOP 级选）；散热与工艺决定中间选择。

## 5. 典型应用场景选型

| 场景 | 要点 | 常见方向（举例） |
| --- | --- | --- |
| 数字信号隔离（通信、GPIO） | 低速通用型即可；高速选逻辑输出型，核算时序与 PWD | PC817/EL817；6N137/HCPL-2601 |
| 模拟信号传输 | 必须用线性光耦（伺服反馈双光敏管），核心看线性度与增益温漂 | HCNR200/201 |
| 功率开关驱动 | 达林顿输出或带缓冲器件，核算 P_C = V_CE(sat)×I_C 与散热 | 达林顿光耦系列 |
| IGBT/SiC/MOS 栅极驱动 | 专用光耦栅极驱动器：峰值输出 2~5A、CMTI ≥25 kV/µs、UVLO、负压关断 | HCPL-3160、TLP250/350 |
| 高压安全隔离 | 对照 IEC 60601-1（医疗）、IEC 61800-5-1（调速）、IEC 62109（光伏）算隔离等级，评估增强隔离与单点失效 | 宽体/大爬电安规系列 |

**替代趋势**：1 Mbps 以上、多通道、低功耗场景，电容/磁耦合数字隔离器已在很多应用中取代高速光耦。需要 LED 老化可视性、极端高压安规、超长供货周期的场景，光耦仍有不可替代性。

## 6. 七步选型流程

| 步骤 | 动作 | 输出 |
| --- | --- | --- |
| Step 1 | 明确隔离需求 | 隔离电压等级、安规标准、爬电距离 |
| Step 2 | 确定信号类型 | 数字 / 模拟 / 驱动；速率或精度 |
| Step 3 | 制定关键参数门槛 | CTR_min、速率/延时、CMTI、功耗、温区 |
| Step 4 | 筛选封装 | 隔离等级 + 板面积 + 工艺 → 候选封装集 |
| Step 5 | 最坏情况计算 | EOL CTR 降额、温度极限、电源与负载容差 |
| Step 6 | 可靠性核对 | CTR 退化曲线、MTBF、认证证书 |
| Step 7 | 成本与供货核对 | 单价、生命周期、第二供应商 |

## 7. 十大常见坑

1. 只按标称 CTR 设计——忽略分散性与老化衰减，量产后批次不良率高。必须按 CTR_min 并在寿命末期留 ≥ 50% 余量。
2. 用隔离电压宣传值代替安规计算——安规看 V_IORM 与爬电距离，不可替换。
3. 忽略 CMTI 测试条件——横向比较前必须统一 V_CM、温度与供电条件。
4. LED 反向不设保护——反向耐压常仅 3~6 V，供电瞬态即可击穿，务必加防反二极管。
5. 用限流电阻代替恒流驱动——V_F 温漂放大 I_F 波动与 CTR 分散性。
6. 忽视 PWD——PWM 应用中占空比失真比速率不足更隐蔽、更致命。
7. 高速场景仍用光敏三极管型——带宽不足导致波形严重失真，应改逻辑输出/光电 IC 型或数字隔离器。
8. 只看单页数据手册就定型——务必索取可靠性报告、CTR 退化曲线、认证文件。
9. 忽略 PCB 开槽——即使选了大爬电封装，PCB 不开槽也达不到标称隔离。
10. 不做第二供应商布局——光耦是典型"单一来源风险"器件，同参数等级至少布局两家。

## 8. 选型速查表

| 你的需求 | 首选方向 | 最关键参数 |
| --- | --- | --- |
| 低成本通用信号隔离 | PC817 类光敏三极管光耦 | CTR_min、隔离电压 |
| 高速数据隔离 | 6N137 类逻辑输出光耦 / 数字隔离器 | 速率、t_PLH/t_PHL、PWD |
| 精密模拟隔离 | HCNR 类线性光耦 | 线性度、增益温漂 |
| 功率开关驱动 | 达林顿输出光耦 | I_O、V_CE(sat)、功耗 |
| IGBT/SiC 栅极驱动 | 专用光耦栅极驱动器 | CMTI、峰值电流、UVLO |
| 医疗/电网安全隔离 | 宽体大爬电安规光耦 | V_IORM、爬电距离、认证 |
| 高密度多通道 | 数字隔离器 | 通道数、速率、CMTI |

**核心结论**：选型没有"最好的光耦"，只有"最匹配的隔离方案"。先算清最坏情况（EOL CTR、最坏 CMTI、安规爬电），再谈性价比。

> 本文档为技术参考速查，具体设计以器件官方数据手册与安规标准为准。涉及医疗、电网、充电桩等安全性应用时，请进行实际隔离耐压测试与认证评估。

## 一、文档目的与适用范围

本文档规定硬件产品中 SDIO（Secure Digital Input Output）接口的电气设计、上拉与总线处理、总线模式与速率等级、初始化与数据传输时序、电源与卡座设计、可靠性设计及测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：单板内主控制器与 SD/SDIO 从设备之间的互连，包括 SD/TF 卡座、SDIO 无线组合模组、SDIO 定位模组等。eMMC 器件虽与 SDIO 同源，但其为焊接型器件、不支持热插拔，且定义了专属的高速模式，不在本文档范围内。

## 二、接口概述

SDIO 由 SD 协会定义，是在 SD 存储卡总线基础上扩展出来的通用输入输出接口，核心特征如下：

- **命令、时钟、数据三类线**：CMD（命令线，双向）、CLK（时钟，由主机提供）、DAT0~DAT3（数据线，双向），另有 VDD 与 VSS。
- **双向命令线**：CMD 由主机发起命令、从机返回响应，两个方向分时复用同一条线。
- **总线宽度可协商**：支持 1 位（仅 DAT0）与 4 位（DAT0~DAT3）两种宽度。上电默认为 1 位，初始化完成后由 ACMD6 切换为 4 位。
- **速率可协商**：从默认速度逐级提升到高速，再进阶到 UHS-I 的各档模式，每一档都需要相应的 IO 电平与信号质量支持。
- **存储与 IO 功能并存**：SDIO 设备同时定义了 SD 存储器部分与多功能 IO 部分，通过专用命令访问其寄存器与数据通道。
- **完整 CRC 保护**：CMD 线采用 CRC7，每根 DAT 线各自独立采用 CRC16，位错误与块错误均可被硬件检出。

SDIO 的优势是带宽较高、引脚数适中、产业链成熟；难点在于初始化流程长且必须严格按顺序执行、高速模式对 PCB 与电源要求高，且总线电容与上拉处理有明确约束。

## 三、物理层设计

物理层的核心任务是把这组可双向切换的信号在目标速率下可靠传导，重点落在上拉配置、速率与电平的匹配、总线电容控制以及电源设计四个方面。

### （一）信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| CLK | 主机输出 | 时钟，初始化阶段典型 400kHz，工作阶段可达 25~208MHz |
| CMD | 双向 | 命令与响应复用，空闲与初始化阶段为开漏 |
| DAT0~DAT3 | 双向 | 数据线；1 位模式只用 DAT0；中断可借用 DAT1 |
| VDD / VSS | 电源 | 卡或模组的供电与地 |
| CD / WP | 输入 | 卡座上的插入检测与写保护机械开关，非电气协议信号 |

### （二）总线模式与速率等级

| 模式 | 最高时钟 | IO 电平 | 理论带宽 | 说明 |
| --- | --- | --- | --- | --- |
| Default Speed | 25MHz | 3.3V | 12.5MB/s（4 位） | 上电默认，兼容性最好 |
| High Speed | 50MHz | 3.3V | 25MB/s | 需由命令切换进入 |
| UHS-I SDR25 | 50MHz | 1.8V | 50MB/s | 需先切换到 1.8V IO |
| UHS-I SDR50 | 100MHz | 1.8V | 50MB/s | 对 PCB 要求高 |
| UHS-I SDR104 | 208MHz | 1.8V | 104MB/s | 需进行采样点调谐 |
| UHS-I DDR50 | 50MHz | 1.8V | 50MB/s | 时钟双沿采样 |

选择原则：追求成本与稳定性时工作在默认速度或高速模式即可；只有在有明确带宽需求时才启用 UHS-I——因为它会强制切到 1.8V IO，并对布板与电源提出很高要求。

### （三）上拉电阻要求

这是 SDIO 设计中最容易遗漏的一点：CMD 线与所有 DAT 线都必须在主机侧配置上拉电阻，典型取值 10~47kΩ。

原因在于 SD 总线在初始化与总线释放阶段工作于开漏模式，器件只能拉低而不能拉高，必须靠外部上拉提供高电平；此外上拉还能避免未初始化时信号浮空。

- **DAT3 的特殊性**：规范要求卡内部对 DAT3 有上拉，可用于卡插入检测。若主机侧也给 DAT3 加上拉，可能与采用 DAT3 做卡检测的主控逻辑冲突。工程上更推荐由卡座提供独立的插入检测开关。
- **CLK 不需要上拉**：部分设计会给 CLK 串联一个小电阻以改善边沿。
- **放置位置**：上拉电阻应靠近主机端并紧邻对应信号，避免引出长引线。
- **内部上拉**：许多 SoC 内部已集成上拉，若内部上拉阻值合适即可不重复放置外部上拉，但必须在原理图上明确标注，避免后续误判。

### （四）总线电容与拓扑

SD 总线属于并联型总线，总线总电容由各器件引脚电容、卡座寄生电容、ESD 保护器件结电容与 PCB 走线电容累加而成。总线电容超标会使上升沿变缓，直接限制可实现的最高速率。因此有三个约束：

- ESD 防护器件必须选低结电容型号，通常要求在数皮法以内。
- 一个 SDIO 控制器原则上只挂一个从设备；多设备共享总线时应改用总线开关切换。
- 调试线与其他高速信号不可与 SDIO 走线长距离平行。

### （五）电平与电源设计

- **电平对应关系**：默认与高速模式为 3.3V IO；UHS-I 需在主从双方协商后切换到 1.8V，因此主机侧必须具备可控的 1.8V IO 电源轨或支持电平切换的 IO 组。
- **跨电平域处理**：1.8V 主机与 3.3V 从设备之间需要双向电平转换。但在 UHS-I 的高频条件下，绝大多数通用电平转换器件的带宽无法满足要求，因此高速 SDIO 设计应尽量统一双方 IO 电平，从源头避免转换。
- **卡座电源**：推荐使用 MOS 管作为可控开关，便于在热插拔后对卡彻底断电复位。电源需能提供足够的瞬时电流（SD 卡写入瞬间可达数百毫安）。
- **去耦配置**：卡座电源附近建议配置一颗大容量电容配合一颗陶瓷电容，确保大电流瞬变时电压不跌落。
- **上电斜坡**：卡电源的上电斜坡应满足规范要求，过缓会导致卡初始化失败。

## 四、协议层设计

SDIO 的协议层活动可分为三类：卡的识别与初始化、面向存储的数据传输、面向 IO 外设的寄存器访问。其中初始化的顺序性是整个接口的成败关键。

### （一）命令与响应格式

SD 总线上所有命令都是固定的 48 位格式：起始位（0）+ 传输方向位（1）+ 6 位命令索引 + 32 位参数 + 7 位 CRC7 + 结束位（1）。

响应按长度与内容分为若干类型：R1 为常规状态（48 位），R2 用于返回寄存器内容（136 位），R3 用于返回工作电压寄存器（48 位），R6 用于发布相对地址（48 位），R7 用于返回接口条件（48 位）。由于 R2 长度不同，软件处理时需要特别注意移位逻辑与缓冲区长度。

### （二）卡工作状态机

卡从插入到可以传输数据要经历若干状态：空闲态、准备态、识别态、待机态、传输态。每一次状态跃迁都由特定命令驱动（复位、读标识、发地址、选中卡等），软件必须严格按序执行，跳步会导致后续命令全部失败。

### （三）初始化流程

标准 SD 卡的初始化序列如下：

1. **CMD0**：复位所有卡至空闲态。
2. **CMD8**：探测卡是否支持规定的工作电压范围，携带的电压信息与回波模式用于判定卡的版本。
3. **ACMD41**：携带电压窗口参数重复发送，直到卡的上电完成标志置起，同时获知是否为高容量卡。
4. **CMD2**：获取卡的唯一标识寄存器。
5. **CMD3**：由主机向卡发布相对地址。
6. **CMD9**：获取卡特性寄存器，得知容量、块长度与速率等级等信息。
7. **CMD7**：选中该卡，使其进入传输态。
8. **ACMD6**：切换总线宽度为 4 位。
9. **CMD16**：设置块长度，一般为 512 字节。
10. 需要时通过模式切换命令进入高速或 UHS-I 模式。

初始化阶段时钟必须保持在低速（典型 400kHz），全部协商完成后才能提升到工作频率。这是 SDIO 设计中必须遵守的硬性要求。

### （四）存储数据传输

- 单块读用 CMD17，多块读用 CMD18，多块读结束后用 CMD12 终止。
- 单块写用 CMD24，多块写用 CMD25，同样以 CMD12 终止。
- 写入完成后需查询卡状态，确认已退出编程忙状态。
- DAT0 在编程或擦除期间会被卡拉低表示忙，主机必须检测该状态。

### （五）SDIO 外设的 IO 访问

SDIO 组合芯片不使用存储读写命令，而是使用两类专用命令：单寄存器读写命令用于配置寄存器与查询状态，是最常用的访问手段；扩展读写命令可连续读写多个字节或多个数据块，用于搬运数据帧。

SDIO 卡内部划分为若干功能单元，公共部分为卡公共控制寄存器，其后是每个功能单元的功能寄存器与信息结构。在 1 位模式下，DAT1 可被用作 SDIO 中断线，这是模组通知主机有数据可读的关键机制，必须在硬件连接与软件配置两方面都保留该能力。

### （六）错误检测

命令线的 CRC7 错误与数据线的 CRC16 错误都会被硬件检出，主机侧驱动必须读取并记录错误计数，并在重试仍失败时上报。此外还有命令超时、非法命令、地址越界、写保护违规等错误状态，均应纳入软件的错误处理分支。

## 五、读写操作时序

SDIO 的数据操作围绕数据块展开。理解好"命令—响应—数据—忙"这条主线，处理各种读写时序就清晰了。

**单块与多块读**：主机发送读命令后，卡在若干时钟周期的响应延迟之后开始在 DAT 线上以数据块形式返回数据，每个数据块后附带 CRC16。多块读会持续产生数据块，直到主机发送停止命令。软件侧一般配合 DMA 接收，缓冲区按块边界对齐。

**单块与多块写**：主机先发送写命令，卡返回响应后拉低 DAT0 表示进入编程状态。主机在此期间不得停止时钟，应持续查询卡状态直到忙指示释放。多块写入必须以停止命令正确结束，否则卡会停留在接收等待状态。

**总线繁忙与编程等待**：在 1 位模式下 DAT0 同时承担数据传输与忙状态指示；在 4 位模式下四条数据线都用于数据传输，忙状态需通过查询卡状态获得。设计上必须为写入流程预留充分的等待时间与重试逻辑，不能假设写入立即完成。

**SDIO 模组的访问模式**：无线组合模组的典型访问模式是：用单寄存器命令配置并使能中断，数据收发通过扩展读写命令批量搬运，模组借用 DAT1 触发主机中断。软件应尽量减少单寄存器的零星访问，改为批量读写以提升实际吞吐。

**DMA 与缓冲要求**：SDIO 数据量大且突发性强，必须使用 DMA 搬运，并保证缓冲区满足控制器对地址对齐与物理连续性的要求。缓冲区深度应足以覆盖中断延迟与上层文件系统的抖动。

## 六、硬件设计要点

SDIO 的硬件设计可归纳为"上拉、等长、地平面、电容、电源"五个关键词，以下逐条展开：

- **上拉必须完整**：CMD 与全部 DAT 线都要有上拉，1 位模式下至少 CMD 与 DAT0 必须具备，遗漏任一都会导致初始化失败。
- **就近放置**：上拉电阻靠近主机端并紧邻信号，去耦电容靠近卡座或模组的电源引脚。
- **走线等长且短**：CLK、CMD、DAT0~DAT3 应同组走线，四根数据线之间的长度偏差要尽量小，高速模式下建议控制在数毫米量级，整组走线总长也应尽量短。
- **完整地平面**：SDIO 走线下方必须有连续的地平面作为回流路径，严禁跨分割走线。
- **远离干扰源**：应远离射频天线馈点、开关电源电感、高速并行总线与内存走线。无线模组的 SDIO 走线尤其不能与射频走线平行。
- **总线电容控制**：选用低结电容的 ESD 器件；一个控制器只挂一个从设备；多设备场景改用总线开关。
- **卡座电源可控**：用 MOS 管作为电源开关，支持彻底断电复位，并具备足够的瞬时电流能力。
- **ESD 防护**：卡座属于对外接口，必须配置 TVS 阵列，并核对结电容是否满足目标速率要求；金属外壳卡座的壳体必须可靠接地。
- **检测脚处理**：插入检测与写保护引脚建议接到 GPIO 并配置上拉，配合软件防抖。
- **避免长引线分支**：以短线、单点、星型为原则，禁止在总线上引出长分支。
- **模组布局**：无线模组应远离模拟前端与音频走线，模组的地要保证低阻抗回流。
- **测试点预留**：CLK、CMD、DAT0~DAT3 应各留一个测试点，便于用逻辑分析仪抓取初始化序列来定位问题。

## 七、典型应用场景

SDIO 既用于可移动存储，也广泛用于把无线、定位等功能的外挂，不同应用的重心差别较大：

| 应用对象 | 典型器件 | 设计关注点 |
| --- | --- | --- |
| 可移动存储 | microSD/TF 卡座 | 热插拔检测、ESD 防护、卡座电源可控、上拉完整性 |
| 无线组合模组 | Wi-Fi 与蓝牙组合芯片 | DAT1 中断线、批量读写吞吐、与射频部分的隔离 |
| 卫星定位模组 | SDIO 接口 GNSS | 供电稳定性、命令响应带宽与中断处理 |
| 摄像头模组 | SDIO 摄像头 | 带宽是否满足帧率需求，必要时应改用专用摄像头接口 |
| 车载与工业终端 | SD 卡作为数据记录介质 | 写入寿命与掉电保护、高低温下的卡可靠性 |
| 嵌入式主板 | SD 卡作为启动介质 | 启动时序、卡槽相关引脚的上拉配置 |

需要区分：eMMC 虽然与 SDIO 同源，但它属于焊接型器件、不可热插拔，且定义了专属的高速模式，设计时应按 eMMC 规范单独处理，不可直接套用 SD 卡的经验。

## 八、可靠性与测试验证

SDIO 的失效绝大多数集中在两个阶段：初始化阶段与高速读写阶段。验证时应先用逻辑分析仪定位失败发生在哪一条命令，再针对性排查电气问题，避免盲目改板。

**常见故障模式**：

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 完全检测不到设备 | CMD/DAT 上拉缺失、卡未供电、卡座接触不良 | 检查上拉焊接；测量卡座供电；抓取复位命令是否有波形 |
| 电压探测命令无响应 | 供电电压不在要求范围、初始化时钟过高 | 核对供电电压；确认初始化阶段仍使用低速时钟 |
| 初始化命令持续返回忙 | 电压窗口参数不符、卡未真正完成上电 | 核对电压参数；延长上电等待；检查电源上电斜坡 |
| 只能工作于 1 位模式 | DAT1~DAT3 上拉缺失、未发送总线宽度切换命令 | 补齐三根数据线的上拉；核对初始化序列 |
| 读写偶发 CRC 错误 | 走线过长、上拉过弱、总线电容超标、时钟抖动 | 缩短走线；减小上拉阻值；更换低结电容 ESD 器件；降速复测 |
| 高速上不去、降速正常 | 时序裕量不足、布板不满足高速要求 | 降速到高速模式使用；优化布板；检查地平面完整性 |
| 热插拔后不再识别 | 未对卡断电复位、插入检测中断未处理或未防抖 | 检测用 MOS 管重新上电；完善去抖与重初始化流程 |
| 写入速度远低于预期 | 未使用多块写、文件系统开销大、卡本身等级低 | 改用多块写；核对卡的速率等级；减少碎片 |
| 切到 1.8V 后不通 | 1.8V IO 电源未就绪、电平切换时序不对 | 核对切换流程；确认低压电源在切换前已稳定 |
| 无线模组偶尔失联 | DAT1 中断线未正确连接或被复用为其他功能 | 核对 DAT1 连接与中断配置；检查引脚复用 |

**测试要点**：

- 初始化时序抓取：用逻辑分析仪或专用协议分析仪完整抓取从复位到选中卡的全部初始化序列，确认每一步都有正确响应。
- 时钟与电平测量：测量 CLK 的频率、占空比与上升下降时间；确认 CMD 与 DAT 的高电平由外部上拉可靠建立，上升时间满足所选速率要求。
- 总线电容核算：累加器件引脚电容、ESD 器件结电容与走线电容，确认未超出目标速率下的允许范围。
- 吞吐测试：连续写入与读取数百兆字节并做数据校验，实测吞吐应与所选模式的理论值接近。
- 压力与一致性：长时间连续读写并对每个数据块做校验，统计错误块数与重试次数。
- 热插拔寿命：按产品要求完成规定次数的插拔，典型不少于一千次，每次均应正确识别并完成读写。
- 电源瞬态：测量写入瞬间的电流与电压跌落，确认供电网络能够支撑瞬时负载。
- 极限条件：在高低温与极限电压下重复初始化与读写测试，确认全条件下均可识别。
- ESD 与射频共存：卡座按对外接口要求完成接触放电与空气放电测试；有无线功能的设备应验证 SDIO 通信在射频工作时不受干扰。

## 九、设计检查清单

1. CMD 与全部 DAT 线均已配置上拉，阻值在推荐范围内且确认已焊接。
2. 已核对主机内部是否已集成上拉，避免外部重复并与内部冲突。
3. 已确定是否使用独立插入检测引脚，DAT3 上拉策略已明确。
4. CLK、CMD、DAT0~DAT3 已同组走线，四根数据线长度偏差满足目标速率要求。
5. SDIO 走线总长受控，下方有连续地平面，未跨分割。
6. SDIO 走线远离射频天线、开关电源电感与高速总线。
7. 已选用低结电容的 ESD 防护器件，并核算总线电容未超标。
8. 卡座电源由 MOS 管可控，具备重新上电复位能力。
9. 卡座供电的瞬时电流能力与去耦满足写入瞬态要求，上电斜坡符合规范。
10. 卡座金属外壳已可靠接地。
11. 一个 SDIO 控制器仅挂一个从设备，多设备已改用总线开关。
12. 数据搬运使用 DMA，缓冲区对齐与连续性满足控制器要求。
13. 软件已按复位、电压探测、工作条件、读标识、发地址、选中、设总线宽度的标准序列实现初始化。
14. 初始化阶段时钟为低速，协商完成后才提升到工作频率。
15. 写入流程已包含忙状态检测或状态轮询，并有超时重试机制。
16. 多块读写均以停止命令正确终止。
17. SDIO 模组的 DAT1 中断线已完成硬件连接与软件注册。
18. 使用 UHS-I 时，1.8V IO 电源与电平切换流程已实测验证。
19. 已完成规定次数的热插拔测试与数百兆字节的读写一致性校验。
20. 已完成高低温、电源瞬态与 ESD 测试。

> 注：本文为 SDIO 接口的通用设计说明。具体项目的电气参数、初始化序列细节与时序要求，最终以所用主控制器、SD 物理层规范版本及从设备的数据手册为准，关键参数应在样板阶段通过实测确定。

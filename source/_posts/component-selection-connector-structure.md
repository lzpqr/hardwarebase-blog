连接器是系统中"失效率不高、但失效代价极高"的器件——多数现场故障并非选错型号，而是漏评某个维度。结构件（散热、机械固定、外壳）决定的是产品的寿命与可维护性。两者的共性是：**按最恶劣工况值校核，而非典型值**。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。高速连接器信号完整性参考[ESD篇](/posts/component-selection-esd/)布局要求；传感器接口参考[传感器与射频篇](/posts/component-selection-sensor-rf/)。

## 1. 核心观点

连接器选型的起点是**四类边界条件**：电气（载流/耐压/速率）、机械（间距/位数/插拔）、环境（温度/湿度/振动/防护）、寿命（插拔次数/微动风险）。任何一类漏评，后期都以返修或召回收场。

结构件选型的核心是**热路径、装配力、可维护性**三者兼顾——散热够、装得上、修得了。

## 2. 连接器电气参数：必须按最恶劣工况校核

### 2.1 载流与降额

规格书首页"额定电流"是单 Pin、标准环境温度下的理想值，与整机实际工况差距可达 40%。

| 校核项 | 判据 | 备注 |
| --- | --- | --- |
| 单 Pin 载流 | ≥ 最大电流 ÷ 降额系数（0.7~0.8） | 用全 Pin 通电曲线 |
| 温升 | ≤ 规范限值（常 30 K） | 在最恶劣箱内温度下实测 |
| 浪涌 | 不产生端子熔焊或镀层烧蚀 | 电机启动/预充电 |
| 多 Pin 叠加 | 相邻 Pin 发热叠加再降额 | 取规格书全 Pin 通电曲线 |

### 2.2 绝缘耐压与爬电距离

- 按 IEC 60664 体系确定污染等级与过压类别，校核端子间、端子与壳/屏蔽的爬电距离。
- 海拔 2000 m 以上需按气压放大电气间隙。
- 高压场景（车载电池）需确认 IPXXB / IPXXD 防触摸等级与 HVIL 时序。

### 2.3 接触电阻与微动

接触电阻是"可靠性体温计"：初始值要求 10~20 mΩ 量级，耐久试验后变化量（ΔR）更关键。微动腐蚀（振动+锡镀层）是长期失效首因——振动场景应选金镀层或加二次锁（TPA/CPA）。测量必须用四线法（Kelvin）消除引线电阻。

### 2.4 信号速率

| 信号类别 | 第一约束 | 备注 |
| --- | --- | --- |
| 低速 IO | 接触电阻、位数 | 无特殊阻抗 |
| 电源 | 载流、温升、压降 | 多 Pin 并联优于单 Pin |
| 差分高速 | 插损、回损、串扰、SCD21 | 取 S 参数仿真 |
| 射频 50 Ω | VSWR、插损、屏蔽 | 计入链路预算 |
| 微弱模拟 | 接触电阻稳定性、热电势 | 金镀层、避免异种金属 |

## 3. 机械与结构参数

| 维度 | 选型要点 |
| --- | --- |
| 间距 / 位数 | 0.4 mm 以下 BTB 需产线对应能力，无能力不选；位数优先标准规格 |
| 安装方式 | SMT / THT / 压接 / 面板安装 / 螺钉固定；压接免焊接，高可靠场景优选 |
| 堆叠高度 | 板对板按插头+插座**组合高度**选型，不能只看单侧 |
| 插拔寿命 | 消费电子 30~50 次，USB-C 数千~10000 次，工业可维护 500 次，高压维修 ≤ 50 次 |
| 锁合方式 | 振动场景必须带锁止；汽车/振动选 TPA+CPA |
| 防误插 | 键位编码 + 色标 + 外形，同电压等级连接器必须物理不可互换 |

## 4. 环境与材料

| 因子 | 关注点 |
| --- | --- |
| 温度 | 工作/存储范围覆盖整机极值；高温加速镀层氧化与塑料蠕变 |
| 湿度 | 湿热后绝缘下降、金属腐蚀、塑料水解 |
| 盐雾 / 腐蚀 | 沿海、化工、车规机舱，选不锈钢或特殊镀层 |
| 振动 / 冲击 | 微动磨损、退 Pin、焊点疲劳；选螺纹锁或卡口锁 |
| 防护等级 | IP65/67/68/69K；IP68 为厂商自定义条件，需确认水深与时长 |
| 镀层 | 锡（低成本）、金（低微动/高速）、银（载流高，有硫化银风险）、钯/镍（中高频） |

**M12 工业连接器**：选型三要素——编码正确（A/B/D/X/L/S/T）+ 屏蔽方式正确（非屏蔽/360°）+ 线缆外径匹配格兰头。三者任一错配都会导致现场故障。

## 5. 结构件选型：散热、装配与可维护性

### 5.1 散热路径

| 场景 | 第一约束 | 关注参数 |
| --- | --- | --- |
| 铝壳 / 散热片 | 热阻 | 壳体热阻 θ_Case-amb、散热面积、风冷/液冷匹配 |
| 导热垫 | 热阻与压缩量 | 热导率、压缩量、界面接触压力 |
| 冷板 / 液冷 | 流量与压降 | 冷板面积、流速、接口兼容性 |
| 塑料壳 | 阻燃 | UL94 V-0/V-1，车规 EN 45545-2 |

散热设计铁律：**先看热阻，再定面积**。铝壳壳体热阻通常 2~8 ℃/W，导热垫 0.2~0.5 ℃/cm²·W，液冷冷板可降至 0.5 ℃/cm²·W 以下。

### 5.2 装配与可维护性

- **螺钉扭矩**：关键固定螺钉标注扭矩范围，防松用螺纹胶/防松垫圈/锁紧螺母。
- **维修可达性**：保险、连接器、存储等关键器件可单手操作；螺丝规格统一，减少工具种类。
- **应力释放**：线缆必须有弯折约束（格兰头/固定夹），避免插拔力直接传到端子焊点。
- **防误装**：不同电压等级/功能的接口通过键位、色标、尺寸差异物理隔离。

## 6. 六步选型流程

1. **定边界条件**：最大电流/电压、速率、温区、防护、插拔次数。
2. **初筛候选**：按间距/位数/安装方式/认证筛 2~3 家。
3. **参数校核**：逐项对照降额曲线、配合尺寸、镀层，**不查降额 = 未完成选型**。
4. **风险识别**：梳理失效模式（微动/退 Pin/防水/EMI），确定是否需专项测试。
5. **样品验证**：实装插拔、温升、振动、SI 实测，不做"仅功能测试"。
6. **量产导入**：确认包装/工艺窗口/二供/EOL 策略。

### 检查清单（设计评审逐项确认）

| 类别 | 检查项 |
| --- | --- |
| 电气 | 最大电流按全 Pin 通电+最恶劣温度降额校核；最高电压（含回馈/充电）校核；爬电距离满足污染等级与海拔；接触电阻 ΔR 确认 |
| 机械 | 间距/位数/安装/BTB 组合高度确认；插拔次数与锁止确认；防误插键位/色标确认；板端机械固定（焊片/螺钉）已设计 |
| 环境 | 工作/存储温区、湿热、盐雾、振动等级确认；IP 等级及厂商自定义条件确认；密封件材质兼容；镀层类型与厚度按微动风险选定 |
| 制造 | 焊接/压接工艺窗口、共面度、吸嘴区、包装方式确认；MSL 等级与烘烤要求确认；返修可行性评估 |
| 供应 | 生命周期、第二货源、交期、MOQ、工装成本评估 |
| 散热 | 壳体热阻、导热垫压缩量、风道/液冷匹配确认；塑料件阻燃等级确认 |

## 7. 常见失效模式与规避

| 失效 | 根本原因 | 规避 |
| --- | --- | --- |
| 接触电阻升高 / 信号断续 | 微动腐蚀（锡+振动）、镀层磨损、正力衰减 | 振动/热循环场景选金镀层；提高正力；加二次锁 |
| 端子烧蚀 / 熔焊 | 未按降额曲线选型、多 Pin 叠加、浪涌 | 按全 Pin 通电曲线降额；校核浪涌；温升实测 |
| 焊点开裂 | 插拔应力直接传到焊点 | 增加板锁焊片/螺钉固定；增加应力释放 |
| 端子退 Pin | 保持力不足、TPA 失效、线束受力 | 选带 TPA 产品；做拉拔力测试；固定线束 |
| 防水失效 | 线缆外径与密封件不匹配、未拧紧、密封件老化 | 逐项核对适配外径；规定扭矩；选耐介质材料 |
| 误插损坏 | 无键位编码、同面板同规格 | 强制键位/色标/外形防呆 |
| EMI 超标 | 屏蔽层"猪尾巴"接地、360° 搭接缺失 | 360° 搭接；增加地 Pin；SI/EMC 早期仿真 |
| 散热不足 | 热阻没算通、风道设计缺失 | 壳体热阻实测；导热垫压缩量确认；风道仿真 |

## 8. 专项加严条款

**汽车高压大电流**：高压连接器必须集成 HVIL（高压互锁），HVIL 触点在功率触点分离之前断开；防触摸等级（IPXXB/D）；按 USCAR-2 振动等级选型；扭矩规范与扭矩标记；橙色标识。

**工业户外**：M12 编码正确 + 屏蔽方式正确 + 线缆外径匹配格兰头；沿海盐雾时长；EN 45545-2 阻燃等级（轨道交通）；随机振动为失效首因，选螺纹锁或卡口锁。

**高速射频**：Pin 分配优先 G-S-S-G 排列；高速差分下方不得跨参考平面分割；过孔残桩优化（背钻/埋盲孔）；屏蔽壳多点低阻抗接地，360° 搭接，禁止猪尾巴；向厂商索取 S 参数模型做通道仿真。

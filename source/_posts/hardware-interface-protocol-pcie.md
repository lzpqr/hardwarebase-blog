## 一、文档目的与适用范围

本文档规定硬件产品中 PCIe（PCI Express）接口的信号定义、速率与链路宽度选择、参考时钟架构、协议与配置空间、链路训练机制、PCB 布局与信号完整性要求、测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：处理器根复合体与端点设备、交换芯片、桥接器件之间的板内互连，以及通过标准插槽或高速连接器实现的板间互连。电缆式 PCIe 与基于 PCIe 的上层协议（如 NVMe）的功能实现不在本文档范围内；具体器件的电气参数、能力寄存器定义与训练时序以对应数据手册和 PCIe 基础规范为准。

## 二、接口概述

PCIe 是当前主流的高速串行扩展总线，它用"可聚合的通道"取代了并行总线，设计者需要理解它与并行总线的本质差异：

- **点对点串行**：每条链路是两组单向差分对组成的双工通道，不再有共享总线，因此不存在总线仲裁，也不再有固定的并行走线组。
- **通道可聚合**：链路可由 1、2、4、8、16 条通道聚合而成，带宽随通道数线性增长，并且两端宽度可以不对等（协商取小）。
- **分层协议**：事务层负责包与寻址，数据链路层负责校验与重传，物理层负责编码与训练。分层使它在保持软件兼容的同时可以不断提速。
- **软件向后兼容**：配置空间与寻址模型延续自传统 PCI，操作系统可用同一套机制枚举与分配资源，这是它快速取代 PCI 与 PCI-X 的关键。
- **自动协商与降级**：链路在初始化时自动协商速率与宽度，条件不好时会降级运行，这既是鲁棒性也是最常见的性能问题来源。
- **速率演进快**：从 2.5GT/s 到 64GT/s，每代翻倍的速率对板材、叠层与走线长度的容忍度越来越低。
- **支持热插拔与功耗管理**：标准插槽定义了热插拔的检测与电源控制机制，链路支持多种低功耗状态。

PCIe 的优势是带宽高、可扩展、生态成熟；代价是设计门槛集中在信号完整性上，PCB 叠层、板材、过孔与连接器的任何一处妥协都可能在高速率下暴露为降速或误码。

## 三、物理层设计

物理层要解决的是：用几条通道、跑多快、时钟怎么给、以及信号能不能在目标速率下打开眼图。

### （一）信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| PETp / PETn | 发送端 → 对端 | 发送差分对，每条通道一对 |
| PERp / PERn | 对端 → 本端 | 接收差分对，每条通道一对 |
| REFCLK+ / REFCLK− | 时钟源 → 设备 | 差分参考时钟，100MHz，可来自公共时钟或独立时钟源 |
| PERST# | 主机 → 设备 | 低电平有效的链路复位，上电时序的关键控制信号 |
| WAKE# | 设备 → 主机 | 可选，用于从低功耗状态唤醒 |
| PRSNT1# / PRSNT2# | 插槽检测 | 插槽存在检测与功耗能力指示，引脚长度按热插拔要求设计 |
| 12V / 3.3V / 3.3Vaux | 供电 | 插槽供电引脚，引脚数与载流能力按功耗等级确定 |

### （二）速率与编码

| 代际 | 速率 | 编码方式 | 单通道有效带宽 |
| --- | --- | --- | --- |
| Gen1 | 2.5 GT/s | 8b/10b | 约 250 MB/s |
| Gen2 | 5 GT/s | 8b/10b | 约 500 MB/s |
| Gen3 | 8 GT/s | 128b/130b | 约 985 MB/s |
| Gen4 | 16 GT/s | 128b/130b | 约 1.97 GB/s |
| Gen5 | 32 GT/s | 128b/130b | 约 3.94 GB/s |
| Gen6 | 64 GT/s | PAM4 与固定长度流控单元 | 约 7.88 GB/s |

Gen1 与 Gen2 采用 8b/10b 编码，开销约 20%；Gen3 及以上改用 128b/130b，开销降到约 1.5%。因此从 Gen2 到 Gen3，速率只提升 60% 而有效带宽接近翻倍，这一点常被误判为"速率翻倍"。

### （三）链路宽度与插槽形态

- **宽度**：x1、x2、x4、x8、x16 五种，实际链路宽度在初始化时协商，取两端能力的最小值。
- **不对等连接**：x4 端点可以插入 x16 插槽，反之 x16 端点在 x4 插槽上只能以 x4 运行，这是正常的降级行为。
- **通道拆分**：处理器或交换芯片可以把一个宽端口拆成多个窄端口，需在硬件设计与固件配置中同时支持。
- **插槽与连接器**：标准插槽、M.2、U.2 与各类高速背板连接器各有插损预算，选型时应按目标速率核算。

### （四）参考时钟架构

参考时钟的供给方式有三种，选错会导致链路训练失败或在高速率下误码：

- **公共时钟架构（Common Clock）**：主机与设备共用同一个时钟源，是最常见也是推荐的方案，对时钟抖动要求相对宽松。
- **独立时钟架构（Separate Clock / SRNS）**：两端各自使用独立时钟源，要求时钟频率偏差在规定范围内（±500ppm 级），且需正确配置相关寄存器，靠 SerDes 内部的时钟恢复与补偿机制对齐。
- **扩频时钟（SSC）一致性**：是否使用扩频时钟需要在两端一致配置，一端扩频另一端不扩频会造成训练不稳定。

无论采用哪种架构，参考时钟的抖动指标都是硬约束。速率越高，允许的抖动越小，Gen3 以上通常要求亚皮秒量级的相位抖动，普通时钟缓冲器往往无法满足，需选用专用时钟发生器或低抖动缓冲器。

### （五）交流耦合与端接

- **交流耦合电容**：发送端串联耦合电容，容值需落在规范允许区间内（典型 180~720pF，按速率选择），并靠近发送引脚放置，封装宜小以减少寄生。
- **差分阻抗**：差分对按 100Ω 设计（部分规范允许 85Ω 实现），需按叠层计算并在制板说明中明确。
- **无外部端接**：PCIe 的端接在芯片内部完成，板上不应再并联端接电阻，这是与某些并行总线的重要区别。
- **极性可反转**：规范支持差分对极性与通道顺序反转，用于简化布线，但应在设计说明中记录以避免误解。

### （六）拓扑结构

- **根复合体直连端点**：处理器直接接一个设备，最简单且性能最好。
- **经交换芯片扩展**：通过交换芯片扩展出多个下游端口，注意上游链路带宽是所有下游共享的瓶颈。
- **桥接转换**：把 PCIe 转换为其他协议（如 USB、SATA），桥接器两侧的配置与时序需分别设计。
- **背板互连**：经连接器跨板传输时，连接器与线缆的插损必须计入链路预算，高速率下往往需要重定时器（Reterimer / Reroute）。

## 四、协议层设计

硬件设计者不必实现协议栈，但必须理解包的类型、流控与训练机制，才能读懂链路状态、定位降速与误码问题。

### （一）分层与包类型

| 层次 | 包类型 | 主要职责 |
| --- | --- | --- |
| 事务层 | TLP（事务层包） | 读写请求与完成、地址路由、事务排序 |
| 数据链路层 | DLLP（数据链路层包） | 应答、流控信用更新、电源管理握手 |
| 物理层 | 有序集（Ordered Set） | 链路训练、时钟补偿、电气空闲与唤醒 |

### （二）事务类型

- **存储器读写**：访问内存空间，是最主要的传输方式，支持突发传输与字节使能。
- **配置读写**：访问配置空间，用于枚举与配置设备。
- **I/O 读写**：兼容传统 I/O 空间，现代设备很少使用。
- **消息事务**：用于中断、电源管理与错误上报，包括传统中断消息与 MSI/MSI-X。
- **完成包（Completion）**：对读请求的回应，携带数据与完成状态。

### （三）地址空间与基址寄存器

设备通过基址寄存器（BAR）向系统声明自己需要的地址空间大小与类型（存储器空间或 I/O 空间），系统软件写入全 1 后读回，从低位零的个数推算出空间大小，再分配基地址。硬件设计需要保证：基址寄存器对应的资源大小与器件实际资源一致，且不得与其他设备冲突。

### （四）数据链路层机制

- **序列号与校验**：每个 TLP 带序列号与 LCRC 校验码，接收端据此检测错误。
- **应答与重传**：接收端返回 ACK 或 NAK，发送端在收到 NAK 时从重传缓冲区重发。
- **基于信用的流控（Credit-Based Flow Control）**：接收端持续通告各类包的可用缓冲信用，发送端在信用不足时暂停发送，从机制上避免了丢包。
- **错误上报**：可纠正错误与不可纠正错误的统计与上报（AER），是定位链路质量问题的重要手段。

### （五）链路训练与状态机

链路初始化由物理层的链路训练状态机（LTSSM）完成，典型流程为：

1. **检测（Detect）**：发送端检测接收端是否存在，通过对端端接的电气特征判断。
2. **轮询（Polling）**：两端交换有序集，完成位锁定与通道极性识别，并协商速率。
3. **配置（Configuration）**：确定链路宽度与通道编号，完成通道到通道的映射。
4. **正常工作（Recovery → L0）**：进入正常工作状态，开始传输事务层包。
5. **速率切换与恢复（Recovery）**：在正常工作状态下可再次进入恢复状态以切换到更高速率，失败则回落到上一档。
6. **低功耗与复位**：包括多级低功耗状态（L1/L2 等）、热复位与链路禁用。

训练过程中若在某一步反复失败，链路会停在低速率或低宽度状态。读取链路状态寄存器（PCIe Link Status）是当前速率与宽度的权威判据。

### （六）功耗管理

- **主动状态电源管理（ASPM）**：链路空闲时自动进入浅度（L0s）或深度（L1）省电状态，唤醒需要一定时延，对时延敏感的应用需评估是否关闭。
- **设备状态**：设备功能层有多种电源状态（D0~D3），与链路状态组合形成完整的功耗策略。
- **唤醒机制**：通过 WAKE# 信号或 PME 信标把链路从低功耗状态恢复到工作状态。

## 五、枚举与配置流程

枚举由系统软件完成，但硬件设计决定了枚举能否成功以及能拿到多少资源。以下流程是排查"设备识别不到"的基础。

### （一）上电与复位时序

1. 电源按序上电并达到稳定，辅助电源（3.3Vaux）按规范保持。
2. 参考时钟先于复位释放前稳定，且持续提供。
3. PERST# 在电源与时钟稳定后保持足够长时间（典型 ≥999ms 冷复位窗口）再释放。
4. 器件完成内部初始化后开始链路训练，通常在毫秒量级内进入正常工作状态。

复位与时钟的时序是硬件上最容易出错的地方：复位释放过早、时钟未稳就释放复位，都会导致链路训练失败，表现为设备偶发识别不到。

### （二）枚举流程

1. 系统软件扫描总线，读取设备的厂商标识（Vendor ID）与设备标识（Device ID）。
2. 读取并解析基址寄存器（BAR），确定所需地址空间大小与类型。
3. 为设备分配地址空间与总线号，写入配置空间。
4. 遍历能力链表，完成最大载荷（MPS/MRRS）、通道数、电源管理等高级配置的协商。
5. 配置中断方式（传统 INTx、MSI 或 MSI-X）并加载驱动。

### （三）DMA 与中断

- **DMA（直接存储器访问）**：设备通过总线主控直接读写系统内存，是高性能传输的基础，需要在配置空间中使能总线主控位（Memory Space + Bus Master）。
- **MSI/MSI-X 中断**：以写内存事务的形式投递中断，避免了传统中断线的引脚开销，支持多向量。
- **地址宽度限制**：部分老旧设备只能访问低 32bit 地址空间，需要在驱动或硬件上配置地址转换。

### （四）热插拔与重训

支持热插拔的插槽需实现存在检测（PRSNT）、电源控制、指示灯与复位控制。插入后先给电、再释放复位、然后触发链路训练；拔出前应先通知软件停用驱动并断电。运行中的链路重训（如切换速率、恢复错误）由状态机自动完成，软件可通过相关寄存器触发。

## 六、硬件设计要点

PCIe 的设计成败几乎全部落在物理层。以下 12 条按优先级排列，前六条是硬性约束：

1. **板材与叠层**：高速率下应选用低损耗板材，并按插损预算核算最大走线长度。Gen3 以上使用普通损耗板材时，走线长度往往被限制在十几英寸以内。
2. **差分阻抗控制**：按 100Ω 设计（或按规范允许的 85Ω 方案），线宽线距由叠层计算确定，并要求板厂出具阻抗报告。
3. **长度匹配**：同一通道的发送与接收对内部长度差要小；多通道之间的长度差应控制在允许范围内，通常按英寸量级的 skew 预算核算。
4. **禁止跨分割**：差分对下方必须保持完整的参考平面，换层时需在附近增加回流地过孔。
5. **减少过孔与连接器**：每个过孔与连接器都会引入插损与反射，高速率下应尽量减少换层次数，必要时使用背钻（Back-drill）去除过孔残桩。
6. **耦合电容放置**：靠近发送端放置，容值落在规范区间内，选用小封装（如 0201）以减少寄生参数。
7. **参考时钟质量**：选用满足抖动指标的时钟源与缓冲器，时钟走线按差分规则处理并做包地，避免与高速数据线长距离平行。
8. **复位与检测信号**：PERST# 按上电时序要求设计，插槽存在检测与电源控制引脚按热插拔规范连接。
9. **电源与去耦**：按器件功耗配置足够的电源引脚与去耦电容，高速 SerDes 的电源通常需要单独的滤波与隔离。
10. **金手指与连接器**：插槽接触部分的长度、倒角与镀层（金厚）按规范执行，连接器型号需与目标速率匹配。
11. **远离干扰与散热**：高速 SerDes 对电源噪声敏感，应远离开关电源；高功耗器件需评估散热，因为温度升高会劣化误码率。
12. **测试点与可测性**：预留一致性测试所需的测试点或夹具接口，便于眼图与误码率测试。

## 七、典型应用场景

| 应用对象 | 典型链路 | 设计关注点 |
| --- | --- | --- |
| 固态存储 | M.2 / U.2，x4 | 速率与带宽核算、散热、电源完整性与掉电保护 |
| 网卡与无线模组 | x1 / x2 | 低时延、中断方式、热插拔与兼容性 |
| 图形与加速卡 | x16 | 供电能力、散热、机械强度、插损预算 |
| 交换与桥接扩展 | 上行 x4~x16 | 上行带宽瓶颈核算、下游端口分配、配置空间资源 |
| 采集与处理卡 | x4 / x8 | 持续带宽与 DMA 效率、缓冲深度 |
| 背板互连 | x4 / x8，跨连接器 | 连接器插损、重定时器选型、跨板等长与 skew |
| 嵌入式 SoC 扩展 | x1 / x2 | 通道数与引脚复用、参考时钟供给、复位时序 |

## 八、可靠性与测试验证

PCIe 的故障往往不表现为"不通"，而表现为"降速""偶发误码""高温下丢包"，这类问题只有在量化测试中才会暴露。

### （一）常见故障模式

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 设备完全识别不到 | 复位时序错误、参考时钟缺失、耦合电容漏装、存在检测引脚未接 | 核对上电与复位时序；测量参考时钟；检查耦合电容与插槽检测引脚 |
| 链路降速运行 | 插损过大、走线过长、连接器或过孔过多、训练反复失败 | 读取链路状态寄存器确认当前速率；做插损预算与眼图测试 |
| 链路降宽运行 | 某条通道焊接不良、走线损伤、通道映射错误 | 读取链路宽度寄存器；逐通道检查通断与极性 |
| 能识别但传输报错 | 误码率过高、电源噪声、时钟抖动超标 | 查看可纠正错误计数（AER）；测电源纹波与时钟抖动；做误码率测试 |
| 高温下掉设备 | 温度劣化误码率、散热不足、器件靠近热源 | 在高温箱中复测；优化散热；核对插损余量 |
| 时有时无 | 插槽接触不良、金手指污染、虚焊 | 检查连接器与金手指；更换线缆或插槽对比测试 |
| 跨板互连不通 | 连接器插损超标、未使用重定时器、等长失控 | 核算整链路插损；增加重定时器；核对跨板走线长度 |
| 热插拔失败或死机 | 热插拔控制电路与时序不符合规范、软件未正确处理 | 检查存在检测与电源控制引脚；验证软件热插拔流程 |
| 从低功耗唤醒失败 | 主动电源管理配置不当、唤醒信号未连接 | 核对 WAKE# 信号连接；评估关闭 ASPM 的影响 |
| 性能远低于理论带宽 | 最大载荷（MPS）与最大读请求（MRRS）配置偏小、DMA 效率低 | 核对 MPS/MRRS 配置；优化突发长度与调度 |
| 多卡共存异常 | 地址空间冲突、总线号资源不足、上行带宽瓶颈 | 核对地址分配；评估交换芯片上行带宽 |

### （二）测试要点

- **链路状态核查**：读取链路寄存器，确认当前速率与宽度等于设计目标，且未发生降级。
- **眼图与抖动**：按要求在发送端做一致性测试，测量眼高、眼宽、抖动与上升下降时间。
- **误码率（BER）**：进行足够长时间的误码率测试，确认满足对应速率等级的要求（如 10⁻¹² 量级）。
- **通道裕量（Compliance/Channel Margining）**：条件允许时做通道裕量测试，评估链路在电压、时序与温度维度上的余量。
- **插损核算**：用实测或仿真得到整链路插损曲线，确认在奈奎斯特频率处仍留有余量。
- **长时间压力**：持续大流量传输数小时，检查可纠正与不可纠正错误计数是否为零。
- **热插拔循环**：对支持热插拔的插槽反复插拔，确认每次都能正常枚举与释放资源。
- **电源与温度**：在极限电压与高低温下重复关键测试，确认不降速、不误码。
- **多卡与满配**：按产品最大配置装满所有端口同时工作，确认无资源冲突与带宽异常。
- **复位与恢复**：反复触发热复位与链路重训，确认能稳定恢复到目标速率与宽度。

## 九、设计检查清单

1. 已确定目标速率与链路宽度，并按实际需求核算带宽且留有裕量。
2. 参考时钟架构（公共时钟或独立时钟）已确定，扩频配置两端一致。
3. 参考时钟源的抖动指标满足目标速率要求，时钟缓冲器选型已确认。
4. 上电、时钟与复位的时序关系已按器件手册设计，复位释放晚于电源与时钟稳定。
5. 板材与叠层已按插损预算选定，最大走线长度在允许范围内。
6. 差分对已按目标阻抗设计，制板说明中已注明阻抗控制要求。
7. 同一通道内与多通道间的长度匹配已核算，skew 在允许范围内。
8. 差分对未跨平面分割，换层次数受控，换层处已加回流地过孔。
9. 发送端交流耦合电容容值符合规范，已靠近发送引脚放置。
10. 板上未额外并联端接电阻，极性反转与通道反转情况已在设计说明中记录。
11. 插槽或连接器的型号、引脚数、机械尺寸与功耗能力已核对。
12. 热插拔相关的存在检测、电源控制与指示灯信号已按规范连接。
13. SerDes 电源已单独滤波，去耦电容配置满足要求。
14. 高功耗器件已评估散热方案，热源与高速走线已隔离。
15. 链路状态寄存器实测速率与宽度等于设计目标，未降级。
16. 已完成眼图、抖动与误码率测试，指标满足对应速率等级要求。
17. 已完成长时间压力测试，错误计数为零。
18. 已完成高低温与极限电压下的复测。
19. 支持热插拔的产品已完成插拔循环测试。
20. 跨板互连的产品已完成整链路插损核算与实测验证。

> 注：本文为 PCIe 接口的通用设计说明。具体速率等级、电气参数、时序要求与配置空间定义，最终以 PCIe 基础规范（PCI-SIG）与所用处理器、端点设备、交换芯片及连接器的数据手册为准；高速率设计应在样板阶段完成仿真与实测双重验证。

## 一、文档目的与适用范围

本文档规定硬件产品中 SATA（Serial ATA）接口的信号定义、速率协商机制、连接器与线缆要求、协议分层与帧结构、建链与读写流程、PCB 布局与测试验证要求，作为原理图设计、PCB 设计、存储器件选型与整机联调的通用依据。

适用范围：主机控制器与硬盘、固态硬盘之间的板内或机箱内串行连接，包括标准 SATA、mSATA 与 M.2 插槽上的 SATA 通道。运行于 PCIe 之上的 NVMe 存储不属于 SATA 接口，其设计要求另行规定；具体控制器与盘体的电气参数、时序与寄存器定义以对应数据手册为准。

## 二、接口概述

SATA 是为替代并行 ATA 而生的串行存储接口，理解它与并行时代的差异以及它与 NVMe 的分工，是选型的起点：

- **点对点串行**：每个主机端口只连一个设备，不再有主从跳线与共享排线，从根本上消除了并行时代的冲突问题。
- **差分低电压**：采用低压差分信号，速率高、功耗低、线缆细，但走线必须按差分规则处理。
- **速率分档协商**：1.5Gbps、3Gbps、6Gbps 三档，上电时自动协商，条件不足会降级，这是盘速变慢的常见原因。
- **命令集延续**：沿用 ATA 命令集，主机侧通过 AHCI 控制器访问，软件栈与并行时代保持兼容。
- **支持热插拔**：规范定义了热插拔的检测与电源控制，连接器引脚长度按此设计。
- **支持原生指令队列（NCQ）**：允许设备内部重排命令顺序以优化寻道，显著提升随机性能。
- **与 NVMe 的分工**：SATA 面向成本敏感与容量优先的场景，NVMe 面向性能优先场景。同一 M.2 插槽可能同时支持两者，必须在原理图上明确通道来源。

SATA 的优势是成本低、生态成熟、兼容性好；代价是协议开销较大、队列深度有限，在高性能场合已被 NVMe 取代。

## 三、物理层设计

物理层的重点是三组信号：高速差分对、带外协商信号、以及电源与热插拔相关引脚。

### （一）信号定义

| 信号 | 说明 | 备注 |
| --- | --- | --- |
| A+ / A− | 发送差分对（主机到设备方向） | 交流耦合，阻抗 100Ω |
| B+ / B− | 接收差分对（设备到主机方向） | 交流耦合，阻抗 100Ω |
| GND | 信号地，7pin 数据连接器中有多根 | 必须保证足够的接地引脚 |
| 3.3V / 5V / 12V | 15pin 电源连接器提供的三路电源 | 不同盘体需求不同，需按规格配置 |
| 预充电引脚 | 电源连接器中较长的引脚，用于热插拔时的缓启动 | 不可与普通引脚互换 |
| DEVSLP | 设备深度睡眠控制信号，可选 | 用于进一步降低待机功耗 |
| PRESENT / 检测 | 盘体在位检测，具体实现随形态而异 | mSATA 与 M.2 上有对应引脚 |

需要特别注意发送与接收的方向：主机的 A 对应设备的 B，交叉连接。若两端同为 A 对 A，链路无法建立，这是改版和飞线阶段最容易犯的错。

### （二）速率等级与编码

| 等级 | 线路速率 | 编码 | 理论有效带宽 |
| --- | --- | --- | --- |
| SATA 1.0 | 1.5 Gbps | 8b/10b | 约 150 MB/s |
| SATA 2.0 | 3.0 Gbps | 8b/10b | 约 300 MB/s |
| SATA 3.0 | 6.0 Gbps | 8b/10b | 约 600 MB/s |

8b/10b 编码带来 20% 的开销，因此 6Gbps 的实际持续吞吐上限约为 550MB/s 左右。若实测速度长期停留在 150MB/s 或 300MB/s，应首先怀疑速率协商降级。

### （三）连接器与形态

| 形态 | 构成 | 特点与适用 |
| --- | --- | --- |
| 标准 SATA | 7pin 数据 + 15pin 电源 | 台式机与工控机主流，线缆长度可达 1m |
| 薄型 SATA | 整合数据与电源的小型连接器 | 用于空间受限的便携设备 |
| mSATA | 小型扩展卡插槽 | 占用 PCIe 小型插槽形态，走 SATA 信号 |
| M.2 SATA | M.2 插槽上的 SATA 通道 | 与 NVMe 共用物理插槽，需确认通道来源 |
| eSATA | 对外屏蔽型连接器 | 用于外置存储，对线缆与屏蔽要求更高 |

### （四）带外信号与速率协商

SATA 在正常工作前，先用一组低速的带外（Out-Band）信号完成握手，这是它区别于其他高速接口的独特机制：主机与设备交替发送复位、初始化与唤醒序列，序列由特定长度的突发与间隔组成。协商过程为：

1. 主机发送复位序列，设备回应初始化序列。
2. 双方按各自支持的最高速率发送唤醒序列并等待回应。
3. 若高速率无回应，则回落到较低速率重试。
4. 协商成功后进入正常工作，开始发送对准原语。

带外信号的电平与时序要求与正常工作状态不同，硬件上不得在其路径上放置会削峰或阻断突发的电路。

### （五）拓扑结构

- **点对点直连**：一个主机端口接一个盘，最常用。
- **端口倍增器（Port Multiplier）**：通过倍增器把一端口扩展为多端口，所有下游共享上游带宽，且需要主机与盘体同时支持。
- **多路控制器**：主机侧集成多个独立端口，每端口各连一盘，性能最好。
- **禁止并联**：多个盘不得并联到同一组差分对上。

### （六）端接与阻抗

- **差分阻抗**：按 100Ω 设计，线宽线距由叠层计算确定。
- **交流耦合**：差分对上串联耦合电容，容值按控制器手册选取，靠近发送端放置。
- **无外部端接**：端接在芯片内部完成，板上不应额外并联端接电阻。
- **极性反转支持**：多数控制器支持差分对极性反转，可用于简化布线，但应在设计说明中记录。

## 四、协议层设计

SATA 协议分为四层，硬件设计者需要掌握的重点是帧信息结构与链路层的流控机制，因为排查"识别不到""掉盘"这类问题都依赖它们。

### （一）四层模型

| 层次 | 职责 | 关键内容 |
| --- | --- | --- |
| 物理层 | 信号收发与链路初始化 | 带外信号、8b/10b 编码、速率协商 |
| 链路层 | 帧的封装与流控 | 原语、加扰、校验、信用流控 |
| 传输层 | 帧信息结构（D2F/F2D）的组装与拆解 | 帧信息结构与控制 |
| 应用层 | 命令执行与寄存器模型 | ATA 命令集、设备识别 |

### （二）原语与控制字符

链路层通过原语（Primitive）完成链路控制，常见原语包括对准确认、帧起始与结束、保持与释放、数据接收就绪、以及各类带外序列。主机与设备通过交换这些原语建立帧边界、暂停数据流（接收缓冲区满时）与维持链路同步。理解原语的作用，就能读懂协议分析仪的抓包结果。

### （三）帧信息结构类型

| 类型 | 方向 | 用途 |
| --- | --- | --- |
| 寄存器（主机→设备） | 主机 → 设备 | 下达命令与参数，是最常用的命令帧 |
| 寄存器（设备→主机） | 设备 → 主机 | 返回状态与错误信息 |
| 数据帧 | 双向 | 承载读写数据净荷 |
| 直接存储器访问激活（DMA Activ） | 设备 → 主机 | 设备请求启动 DMA 传输 |
| 设置设备位（Set Device Bits） | 设备 → 主机 | 上报中断与错误状态 |
| 输入输出建立 | 设备 → 主机 | 用于编程 I/O 模式下的数据传输 |
| 内建自检激活 | 双向 | 用于链路自检与测试 |

### （四）链路层可靠性机制

- **加扰（Scrambling）**：对数据进行加扰以避免长连 0 或长连 1，保证时钟恢复与降低电磁干扰。
- **校验**：每个帧带 CRC 校验码，接收端据此判断帧是否正确，错误会触发重传。
- **信用流控（Credit-based）**：接收端通告可用缓冲（Data Ready），发送端据此决定发送量，避免溢出。
- **保持与释放（Hold/Release）**：接收端缓冲区将满时用 HOLD 原语暂停发送端，恢复后再 RELEASE，这是流控的具体执行方式。
- **重传**：校验失败的帧会被重传，重传次数过多会触发链路恢复。

### （五）命令层与特性

- **设备识别（Identify）**：主机通过 IDENTIFY 命令获取盘体的型号、容量、支持特性与速率能力，是枚举的基础。
- **直接存储器访问（DMA）**：数据直接在内存与盘之间搬运，不需处理器逐字节参与，是主流传输方式。
- **原生指令队列（NCQ）**：允许设备对多条命令重排序执行，提升随机访问性能，需要主机与盘体同时支持。
- **读写校验与错误恢复（Read/Write Verify & Error Recovery）**：由盘体内部完成，主机侧通过状态寄存器感知。

### （六）AHCI 与主机侧实现

主机侧通常通过 AHCI 控制器接入，它把 SATA 的命令模型映射为内存中的命令表（HBA）与接收区，由硬件自动完成命令下发与完成上报。硬件设计需要注意：AHCI 需要总线主控能力，配置空间中相关使能位必须打开，且命令表内存需位于可访问的地址范围内。

## 五、建链与读写操作流程

从插入盘体到能读写数据，中间要经过建链、识别、配置三步。任何一步失败都会表现为"识别不到盘"。

### （一）建链流程

1. **上电与复位**：盘体电源稳定后释放复位，控制器开始检测对端。
2. **带外协商**：主机与设备交换复位与初始化序列，完成速率协商。
3. **链路同步**：双方发送对准原语，确认链路进入正常工作状态。
4. **能力交换**：通过 IDENTIFY 命令获取盘体能力，按双方共同支持的最高速率与特性重新配置。
5. **进入就绪**：设备上报就绪（Device Ready）状态，主机开始下发读写命令。

### （二）读操作流程

1. 主机构造 READ 命令帧，写入命令表并触发命令下发。
2. 设备准备好数据后发送 DMA Activ 帧。
3. 设备以数据帧把数据送入主机内存，期间可用 HOLD 原语调节速率。
4. 传输完成后设备返回寄存器帧报告状态。
5. 主机通过完成标志或中断确认命令结束。

### （三）写操作流程

1. 主机把待写数据放入内存并构造 WRITE 命令帧下发。
2. 设备发送 DMA Activ 帧请求数据。
3. 主机以数据帧把数据送往设备。
4. 设备写入介质后返回完成状态。

### （四）热插拔与移除

支持热插拔的盘位应实现在位检测与电源控制。插入时先通过预充电引脚缓慢建立电源，再释放复位触发建链；移除前应先由软件同步数据并停用盘体，再断电。带电硬拔可能造成数据丢失甚至盘体损坏，产品上应在结构与软件两个层面同时防范。

### （五）速率与性能核算

设计时应按盘体标称性能、接口速率与控制器能力三者取小值，并考虑协议开销与实际负载类型。顺序读写通常能接近接口上限，随机小文件的性能则取决于盘体内部的队列与介质特性，与接口速率关系不大。

## 六、硬件设计要点

SATA 的硬件风险主要在差分走线、电源能力与热插拔控制三处。以下 12 条按此展开：

1. **收发交叉确认**：原理图上明确主机的发送（A）对接设备的接收对，反之亦然，并在丝印与走线表中记录方向。
2. **差分阻抗控制**：按 100Ω 设计，线宽线距由叠层计算，制板说明中注明阻抗要求。
3. **等长与对称**：同一差分对的两线长度尽量相等，过孔对称，避免直角与不必要的换层。
4. **禁止跨分割**：差分对下方保持完整参考平面，换层处增加回流地过孔。
5. **耦合电容放置**：串联耦合电容靠近发送端，容值按手册选取，选用小封装。
6. **走线长度与连接器**：控制从控制器到连接器的走线长度，减少过孔与转接，跨板时计入插损预算。
7. **接地引脚充足**：连接器的地引脚必须全部可靠接地，差分对旁应有伴随地。
8. **电源能力核算**：按盘体规格配置 3.3V、5V、12V 三路电源的载流能力，机械盘的启动电流峰值远高于工作电流，必须留足余量。
9. **SSD 去耦与掉电保护**：固态盘对电源纹波敏感，应在盘位附近配置足够的去耦电容；有掉电保护需求的产品需设计储能（电容）与掉电检测电路。
10. **热插拔控制**：使用受控的电源开关（MOS）实现盘位上下电，预充电引脚按规范连接，禁止直接带电插拔。
11. **ESD 与防护**：对外露的连接器配置低结电容防护器件，同时防止插拔瞬间的浪涌冲击。
12. **测试点预留**：在差分对与电源上预留测试点，便于眼图测试与电源纹波测量。

## 七、典型应用场景

| 应用对象 | 典型形态 | 设计关注点 |
| --- | --- | --- |
| 台式机与工控机存储 | 标准 SATA 盘位 | 线缆长度、电源载流、热插拔与减震 |
| 嵌入式小体积设备 | mSATA / M.2 SATA | 通道来源确认（SATA 还是 PCIe）、散热、固定方式 |
| 网络存储与服务器 | 多盘位背板 | 多端口控制器、背板插损、热插拔与统一供电 |
| 视频监控录像 | 大容量机械盘 | 持续写入带宽、启动电流、散热与振动 |
| 工业与车载记录 | 宽温固态盘 | 宽温适应性、掉电保护、抗振动与电源冗余 |
| 外置存储 | eSATA | 屏蔽线缆、对外防护、热插拔可靠性 |
| 老旧设备升级 | 转接方案 | 桥接芯片选型、速率匹配与兼容性验证 |

## 八、可靠性与测试验证

存储接口的故障代价是数据丢失，因此验证重点在长时间稳定性、异常掉电与速率一致性上。

### （一）常见故障模式

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 识别不到盘 | 收发接反、电源缺失、复位未释放、耦合电容漏装 | 核对收发方向与电源；测量复位时序与耦合电容 |
| 速率协商降到 1.5G | 线缆质量差、走线插损过大、盘体或控制器限制 | 读取协商结果；更换线缆；核对两端能力配置 |
| 读写过程中掉盘 | 电源跌落、接触不良、误码过多触发链路恢复 | 测电源纹波与瞬态跌落；检查连接器；查看错误计数 |
| 传输速度慢 | 速率降级、未启用 DMA、盘体本身限制 | 核对协商速率与控制器配置；对比盘体标称性能 |
| 机械盘启动失败 | 启动电流不足、电源响应慢、线损过大 | 实测启动电流峰值；加大电源余量与线宽 |
| 固态盘偶发无响应 | 电源纹波超标、温度过高、固件问题 | 测电源纹波；检查散热；更新盘体固件 |
| 热插拔后系统异常 | 热插拔电路与时序不规范、软件未正确处理 | 检查预充电与电源控制；验证软件拔插流程 |
| 多盘位互相干扰 | 电源共阻抗耦合、背板走线串扰 | 分区供电并加强去耦；加大走线间距 |
| 异常掉电后数据损坏 | 无掉电保护、未完成写入被中断 | 设计掉电检测与储能；验证文件系统一致性 |
| 高温下性能下降 | 盘体温控降速、散热不足 | 优化散热风道；核对盘体温度规格 |
| 跨背板互连不稳定 | 连接器插损过大、线缆过长 | 核算整链路插损；缩短线缆；选用高质量背板 |

### （二）测试要点

- **速率确认**：读取协商结果，确认工作在目标速率等级，未发生降级。
- **信号质量**：测量差分信号的眼图与抖动，确认满足规范要求。
- **误码与重传**：长时间传输后检查校验错误与重传计数，应保持在极低水平。
- **持续读写**：进行数小时的连续顺序与随机读写，确认无掉速、无掉盘、无报错。
- **电源测试**：测量盘体电源在启动与读写过程中的电压跌落与纹波，确认满足规格。
- **热插拔循环**：反复插拔数十次以上，确认每次都能正常识别与释放。
- **异常掉电**：在读写过程中强行断电，重复多次后检查数据一致性与盘体可恢复性。
- **兼容性**：在不同品牌、不同容量、不同固件的盘体上逐一验证识别与读写。
- **高低温**：在极限温度下重复关键测试，确认不掉盘、不降速。
- **振动与机械**：对含机械盘的产品做振动测试，确认连接器不松脱、性能不劣化。

## 九、设计检查清单

1. 已在原理图上确认主机与设备的收发差分对交叉连接，方向记录清晰。

3. 差分对两线等长、过孔对称，未跨平面分割，换层处已加回流地过孔。

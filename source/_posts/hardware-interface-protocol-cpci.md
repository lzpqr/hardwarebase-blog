## 一、文档目的与适用范围

本文档规定硬件产品中 CPCI（Compact PCI，ANSI/ISA-201.1）机箱背板接口的设计要求，覆盖 Z 总线信号定义、热插拔电源时序、背板走线阻抗控制、连接器选型、VITA 48 扩展、ESD/EMC 验证，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：采用 CPCI 机箱的嵌入式系统、通信板卡、测试测量与工业控制设备。PICMG 3.0（3U/6U CPCI）之外的 CPCI Express（VITA 48）扩展另文说明。

## 二、接口概述

CPCI 是 PCI 总线的机箱化实现，核心特征如下：

- **Z 总线**：CPCI 在 PCI 64-bit 总线基础上新增 32-bit 扩展总线（Z 总线），共 36 个信号引脚，用于多板卡系统间的高速数据交换。
- **热插拔**：CPCI 连接器带弹片结构，支持带电插拔；电源引脚（+5V/+12V）先接触，信号引脚后接触，热插拔时序由 PWR_OK 信号控制。
- **Z1/Z2 引脚**：Z1 侧（近机箱后部）承载 PCI 总线地址/数据，Z2 侧（近机箱前部）承载 Z 总线扩展信号，两侧接地引脚交替排列。
- **背板走线**：CPCI 背板信号阻抗标称 50Ω（单端）/ 100Ω（差分），走线长度 ≤ 25cm 时可不串接终端；超过 25cm 需评估反射。
- **VITA 48 扩展**：在 Z 总线基础上预留 PCIe/Star 接口，支持 10GbE、PCIe 3.0 等高速信号，与标准 CPCI 兼容。
- **板框尺寸**：3U CPCI 板框 100mm × 160mm，6U CPCI 板框 100mm × 233.4mm；厚度 1.6mm（3U）/ 2.0mm（6U）。

## 三、物理层设计

### （一）Z 总线引脚定义

CPCI 36 脚连接器（Z 总线）引脚分配如下：

| 引脚 | Z1 侧 | Z2 侧 | 说明 |
| --- | --- | --- | --- |
| 1~8 | PCI 地址 | PCI 地址 | 32-bit 地址总线 |
| 9~12 | PCI 数据 | PCI 数据 | 32-bit 数据总线 |
| 13~16 | PCI 控制 | PCI 控制 | FRAME/IRDY/TRDY/STOP |
| 17~20 | +5V PWR | +5V PWR | 热插拔电源（先接触） |
| 21~24 | +12V PWR | +12V PWR | 热插拔电源（先接触） |
| 25~28 | GND | GND | 接地 |
| 29~36 | Z 扩展 | Z 扩展 | 高速差分/单端信号 |

### （二）热插拔电源时序

CPCI 热插拔时序是设计核心，必须严格遵守：

1. **插入顺序**：PWR 弹片先接触 → 弹片建立电气通路 → PWR_OK 高电平（≥ 10ms）→ 信号弹片接触 → 总线通信。
2. **PWR_OK 信号**：由背板 PWR_OK 网络提供，高电平表示 5V/12V 电源稳定；板内电路在 PWR_OK 上升沿后使能。
3. **断电时序**：PWR_OK 低电平 → 板内电路关断 → PWR 弹片断开 → 信号弹片断开；禁止在 PWR_OK 高电平时直接拔掉板卡。
4. **过流保护**：每槽 5V/12V 独立保险丝（额定 3A/2A），背板 PWR_OK 检测电路含过流/短路报警。

### （三）背板走线阻抗控制

CPCI 背板走线要求：

- **阻抗**：单端 50Ω，差分 100Ω；TDR 实测偏差 < ±10%。
- **走线长度**：PCI 地址/数据线 ≤ 25cm（不串接终端）；Z 总线扩展信号 ≤ 15cm。
- **等长匹配**：32-bit 数据线偏斜 < 2ns（PCI 66MHz），PCIe lane 偏斜 < 5ps（PCIe 3.0）。
- **串接终端**：发送端串接 22~33Ω（PCI 单端），接收端 100Ω 并接（差分对）。
- **GND 铺铜**：信号层下方完整 GND 层，禁止开窗；背板 GND 层与板卡 GND 层通过多 pin（≥ 6 pin）桥接。

### （四）ESD 与 EMC

- Z 总线对外接口预留 TVS 保护：双向 TVS，Vcl 3.3V，Cj < 0.5pF，每信号独立。
- 板框导电衬垫：CPCI 板框与机箱屏蔽框配合面加导电衬垫，缝隙 < 0.5mm；整机屏蔽覆盖率 ≥ 90%。
- 背板高速信号层远离机箱金属框架，避免形成天线；PCIe 走线下方 GND 过孔密度 ≥ 每 5mm 一个。

## 四、协议层设计

CPCI 信号层协议随系统而异，常见组合：

| 应用场景 | 信号类型 | 速率 | 协议层要求 |
| --- | --- | --- | --- |
| 通信基站 | PCI 66MHz | 533Mbps | 32-bit 数据，等长 < 2ns |
| 测试测量 | Z 总线 LVDS | 100Mbps~1Gbps | 50Ω 单端，串接 22Ω |
| VITA 48 扩展 | PCIe 3.0 | 8GT/s | 100Ω 差分，走线 ≤ 10cm |
| 机箱管理 | I2C / 1-Wire | 100kHz | 背板公共总线，上拉 10kΩ 至 3.3V |

## 五、收发操作时序

CPCI 热插拔时序：

1. **插入**：PWR 弹片接触 → PWR_OK 高（≥ 10ms）→ 信号弹片接触 → PCI 复位释放（RST# 高）→ 总线枚举。
2. **拔出**：软件发起拔出（PWR_OK 低）→ 板内关断 → PWR 弹片断开 → 信号弹片断开；带电拔出必须经过 PWR_OK 控制，禁止直接机械拔出。
3. **PWR_OK 监控**：背板每槽 PWR_OK 网络独立，任一角 PWR_OK 低电平时系统报故障，对应槽位禁止通信。

## 六、硬件设计要点

- **板框**：3U CPCI 板框 100mm × 160mm，6U 板框 100mm × 233.4mm；板框角部加导电衬垫，与机箱屏蔽框接触电阻 < 10mΩ。
- **连接器**：推荐 Molex 105214 系列（CPCI 专用）或 Samtec 弹片连接器，镀层 30µin 镍 + 5µin 金；弹片弹簧力 ≥ 0.5N，接触电阻 < 20mΩ。
- **背板层叠**：12~16 层，信号层与 GND 层交替；5V/12V 电源层独立，厚度 ≥ 1oz 铜；PCI 信号层阻抗 50Ω 控制。
- **接地**：板卡 GND 铺铜与背板 GND 层通过 ≥ 6 pin 桥接，接触电阻 < 10mΩ；避免单点接地。
- **散热**：CPCI 板卡散热路径：芯片 → 热沉 → 板框 → 机箱导风板；3U 板卡热通量密度 < 30W/cm²，6U 板卡 < 50W/cm²。

## 七、典型应用场景

| 场景 | 配置 | 说明 |
| --- | --- | --- |
| 通信基站 | 8 槽 CPCI 机箱 | PCI 66MHz 互联，热插拔，符合 VITA 31 |
| 测试测量 | 12 槽 CPCI 机箱 | Z 总线 LVDS 互联，带宽 1GHz |
| 工业控制 | 6 槽 3U CPCI | 宽温 -40~+85°C，符合 VITA 31.2 |
| VITA 48 系统 | 10 槽 CPCI + PCIe | PCIe 3.0 x8 互联，支持 10GbE |

## 八、可靠性与测试验证

1. **TDR 阻抗测试**：单端 50Ω / 差分 100Ω，TDR 实测偏差 < ±10%；记录背板与板卡各段实测值。
2. **PCI 总线时序**：66MHz PCI 数据线偏斜 < 2ns，FRAME/IRDY/TRDY/STOP 时序符合 PCI 2.2 规范。
3. **热插拔应力**：模拟 5000 次带电插拔，弹片弹簧力衰减 < 10%，接触电阻变化 < 5mΩ。
4. **PWR_OK 时序**：插入时 PWR_OK 高电平建立 < 100ms；断电时 PWR_OK 低电平释放 < 50ms。
5. **ESD 测试**：IEC 61000-4-2，接触放电 ±4kV（Z 总线），空气放电 ±8kV；系统无复位、无数据丢失。
6. **EMC 辐射**：IEC 61000-6-3，30MHz~1GHz 辐射 < 30dBµV/m（3m）；屏蔽覆盖率 ≥ 90%。
7. **5V/12V 电源波动**：满载时 5V 跌落 < 5%，12V 跌落 < 5%；板内 DC-DC 输出纹波 < 50mVpp。
8. **温度循环**：-40°C~+85°C，100 循环，无弹片松动、无背板层间脱焊。

## 九、设计检查清单

1. 板框尺寸 3U（100×160mm）或 6U（100×233.4mm），公差 ±0.1mm，已确认。
2. CPCI 连接器型号已确认，弹片弹簧力 ≥ 0.5N，接触电阻 < 20mΩ。
3. PWR_OK 信号已预留，插入时高电平建立 < 100ms，断电时释放 < 50ms。
4. 热插拔时序：PWR 弹片先接触 → PWR_OK 高 → 信号弹片后接触，已确认。
5. 每槽 5V/12V 独立保险丝已放置，额定电流匹配系统功耗。
6. 背板走线阻抗：单端 50Ω / 差分 100Ω，TDR 实测偏差 < ±10%。
7. PCI 数据线等长匹配 < 2ns（66MHz），PCIe lane 偏斜 < 5ps（3.0），已标注。
8. 串接终端：发送端 22~33Ω，接收端 100Ω 并接（差分），已确认。
9. GND 铺铜完整，背板与板卡 GND 桥接 ≥ 6 pin，接触电阻 < 10mΩ。
10. ESD 保护：Z 总线对外接口 TVS 阵列已放置，Vcl 3.3V，Cj < 0.5pF。
11. 板框导电衬垫已加，缝隙 < 0.5mm；屏蔽覆盖率 ≥ 90%。
12. 散热路径：芯片 → 热沉 → 板框 → 导风板，热通量密度满足板框规格。
13. 已完成 TDR、PCI 时序、热插拔、ESD、EMC 测试，指标满足产品要求。

> 注：本文为 CPCI 接口的通用设计说明。具体项目的槽位数量、背板层叠、热插拔时序与可靠性指标最终以所用连接器与机箱系统的数据手册为准，关键指标应在样板阶段通过实测确定。

电容器是元器件清单上数量最多的器件，却常常是设计评审中最容易被跳过的一项。一颗 0402 封装的 100nF 陶瓷电容单价不足一分钱，看起来"随便选一个"似乎也不会有后果。

真正的代价出现在下游。一颗选错的电容可能在样机阶段毫无异常，却在量产半年后集中暴露：电源模块电解电容批量鼓包、车载电源模块在低温启动时环路失稳、通信设备在高温环境下 EMC 余量不足。这类问题的共同特征是——根因在选型阶段就已埋下，却在交付后才显现。

电容选型是一个逐步收敛的过程，而非一次性查找。把决策拆成五步，可以避免"反复推翻重来"这类最常见的效率损失。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。建议先阅读[电阻篇](/posts/component-selection-resistor/)。

## 1. 选型决策链

在电子硬件设计中，同一个标称值——例如 100nF——在不同电路位置上可能是完全不同的器件要求。把功能定位错误，看再多规格书也无济于事。

| 决策步骤 | 需要回答的问题 | 产出结论 | 跳过该步的典型后果 |
| --- | --- | --- | --- |
| 第一步：功能定位 | 这颗电容承担什么电路角色？ | 储能 / 滤波 / 去耦 / 耦合 / 定时 / 谐振 / 安规 | 从错误起点出发，后续全部返工 |
| 第二步：应力分析 | 它将承受多大电压与纹波电流？ | 工作电压上限、纹波电流有效值、频率范围 | 忽略纹波电流，长期发热失效 |
| 第三步：环境与寿命 | 工作温度范围与寿命要求是什么？ | 温度上限、寿命指标、机械与认证约束 | 高温寿命不足，量产批量失效 |
| 第四步：类型选择 | 哪一类电容最适合这个场景？ | 陶瓷 / 铝电解 / 钽 / 薄膜 / 聚合物 | 类型错配，性能指标先天不足 |
| 第五步：参数与封装校核 | 具体参数和封装是否全部满足？ | 容值 / 耐压 / ESR / ESL / 尺寸 / 成本 | 参数达标但装配无空间或成本失控 |

**实践提示**：第一步到第三步通常只需一张纸和十分钟，但它约束了后面绝大多数选择。建议在设计评审中要求工程师书面写出这三步的结论，而不是等到出图后再解释。

### 1.1 功能定位是全部工作的起点

| 电路功能 | 作用机理 | 决定性参数 | 常用类型 |
| --- | --- | --- | --- |
| 电源去耦 | 为负载瞬态电流提供就近能量，抑制电源轨噪声 | ESL、自谐振频率、摆放位置 | MLCC（多层陶瓷） |
| 输入/输出滤波 | 平滑整流或开关产生的电压纹波 | 容值、ESR、纹波电流额定值 | 铝电解 / 聚合物 / MLCC |
| 储能（Bulk） | 为大电流负载提供能量缓冲 | 容值、纹波电流、寿命 | 铝电解 / 聚合物 |
| 信号耦合/隔直 | 传递交流分量，隔离直流偏置 | 容值精度、漏电流、无极性要求 | MLCC / 薄膜 |
| 定时/振荡 | 与电阻共同决定时间常数 | 容值精度、温度稳定性、介质吸收 | 薄膜 / C0G（NP0） |
| 谐振 | 与电感构成谐振回路，决定频率 | 容值精度、ESR（影响 Q 值） | C0G / 薄膜 |
| 安规（X/Y 电容） | 抑制共模与差模干扰 | 安规认证、耐压等级、失效安全 | 安规薄膜电容 |

## 2. 关键参数解析

### 2.1 标称容值与容差

容差常被当作"精度问题"而轻视，实际上它是系统性问题：它直接决定滤波截止频率的分散度、振荡电路的时间精度、以及反馈环路的稳定裕量。

| 代号 | 允许偏差 | 典型介质 | 适用场合 |
| --- | --- | --- | --- |
| C | ±0.25pF | C0G | 高频谐振、精密匹配 |
| D | ±0.5pF | C0G | 高频谐振 |
| J | ±5% | C0G / 薄膜 | 定时、谐振、滤波 |
| K | ±10% | X7R / 薄膜 | 通用滤波 |
| M | ±20% | X5R / X7R / 铝电解 | 去耦、储能 |
| Z | +80% / -20% | Y5V | 仅限容值不敏感场合 |

**易错点**：铝电解电容容差普遍为 ±20%，且低温下容值显著下降——-40℃ 时可能仅剩标称值的 60%~70%。依赖大容值做能量缓冲的设计，必须按低温容值校核，不能按常温标称值计算。

### 2.2 额定电压与降额规则

降额是电容选型中最重要、也最常被省略的一步。按额定电压直接使用，短期通常不会暴露问题，但长期可靠性与容值稳定性都会明显恶化。

| 电容类型 | 推荐工作电压占比 | 限制原因 |
| --- | --- | --- |
| MLCC（陶瓷） | ≤ 50%（高可靠场合 ≤ 30%） | 直流偏压效应导致有效容值衰减 |
| 铝电解（液态） | ≤ 80% | 电压加速电解液劣化，缩短寿命 |
| 固体钽电容 | ≤ 50%（推荐 ≤ 40%） | 过压易引发热失控 |
| 薄膜电容 | ≤ 60%~70% | 电压影响介质损耗与长期稳定性 |
| 超级电容 | ≤ 80% | 影响循环寿命 |

**MLCC 为何需要降到一半？** 这源于两个并行的物理效应：

1. **直流偏压效应**：施加直流电压后，高介电常数陶瓷（X5R / X7R / Y5V）的等效容值大幅下降。一颗标称 10μF / 6.3V 的 0805 X5R 在 5V 偏压下实测可能只剩 3~5μF。
2. **电压加速老化**：工作电压越高，介质老化速率越快，容值随时间漂移越明显。

**工程口诀**：MLCC 的设计依据是"偏压后的容值"，不是标称容值。选型时必须查阅厂商提供的 DC Bias 曲线，按实际工作电压下的容值设计。

### 2.3 ESR 与纹波电流

ESR（等效串联电阻）同时决定电容的纹波抑制能力与自身发热量，是开关电源选型的核心参数。

| 电容类型 | 典型 ESR 区间 | 对电路的实际影响 |
| --- | --- | --- |
| MLCC | 1~20 mΩ | 极低，高频滤波性能最优 |
| 聚合物铝电解 | 5~50 mΩ | 低，适合中高频滤波 |
| 薄膜 | 5~100 mΩ | 低，且全频段特性稳定 |
| 固态钽 | 50~500 mΩ | 中等 |
| 液态铝电解 | 100 mΩ ~ 数 Ω | 较高，需依靠容值弥补 |

纹波电流流过 ESR 时产生焦耳损耗：

```text
P_ESR = I_ripple(rms)² × ESR
```

这部分功率转化为热量，直接抬升电容内部温度。工程上有一个重要近似：**内部温度每升高 10℃，液态铝电解的寿命约减半**。因此必须校核：

```text
实际纹波电流(rms) ≤ 额定纹波电流 × 温度修正系数 × 频率修正系数
```

**易错点**：厂商给出的额定纹波电流通常附带两个前提条件——测试频率（如 100kHz）与测试温度（如 105℃）。当实际工作频率低于测试频率时，必须乘以频率修正系数（额定值会下降）。省略这一步，是电源设计中电解电容批量鼓包的高发原因。

### 2.4 ESL 与自谐振频率

ESL（等效串联电感）决定电容在高频下"是否仍然表现得像一颗电容"。电容阻抗随频率下降，在自谐振频率（SRF）处达到最低点，此时阻抗约等于 ESR；超过 SRF 后，电容呈感性，阻抗随频率上升，滤波能力迅速丧失。

| 封装 | 典型 ESL | 100nF 时的典型 SRF |
| --- | --- | --- |
| 0402 | ~0.4 nH | ~25 MHz |
| 0603 | ~0.6 nH | ~18 MHz |
| 0805 | ~0.9 nH | ~13 MHz |
| 1206 | ~1.2 nH | ~10 MHz |

由此可得出三条工程结论：

1. **高频去耦优先选用小封装**——ESL 更小，SRF 更高。
2. **单颗电容的有效滤波带宽有限**，实际设计采用多容值并联覆盖宽频段（如 10μF + 1μF + 100nF + 10nF）。
3. **不同容值并联会在特定频率形成反谐振阻抗尖峰**，需通过 PDN 仿真或阻抗分析仪确认该尖峰不落在敏感频段。

### 2.5 温度特性与介质选择

MLCC 的介质类型决定容值随温度、电压、时间的稳定性。这是选型中"性能与容量密度"的核心权衡点。

| 介质类型 | 容值温度系数 | 容量密度 | 典型用途 |
| --- | --- | --- | --- |
| C0G（NP0） | ±30ppm/℃ | 极低 | 谐振、定时、精密滤波 |
| X7R | ±15%（-55 ~ +125℃） | 中高 | 通用滤波、去耦 |
| X5R | ±15%（-55 ~ +85℃） | 高 | 通用去耦 |
| Y5V | +22% / -82%（-30 ~ +85℃） | 极高 | 仅限容值不敏感场合 |

**选择优先级**：C0G 优于 X7R，X7R 优于 X5R，X5R 优于 Y5V。能用 C0G 就优先用 C0G；仅在需要大容值且空间受限时退到 X7R/X5R，并必须校核偏压后的有效容值。新设计中应避免使用 Y5V。

### 2.6 漏电流

漏电流对高阻抗电路、采样保持电路以及电池供电设备具有决定性影响。

| 电容类型 | 典型漏电流量级 | 备注 |
| --- | --- | --- |
| C0G MLCC | 小于 1 μA | 极小 |
| 薄膜 | nA 级 | 适合精密采样与保持 |
| X7R / X5R MLCC | 数 μA ~ 数十 μA | 与容值、电压正相关 |
| 固态钽 | 数 μA ~ 数十 μA | 需关注 |
| 铝电解 | I ≈ 0.01×C×V 或 3μA 取大 | 随温度升高显著增大 |

## 3. 五类电容横向对比

选型的核心动作是在候选类型之间做取舍。下表把五类常用电容放在同一坐标系下对比，便于快速定位。

| 对比维度 | MLCC | 液态铝电解 | 固态钽 | 薄膜 | 聚合物铝电解 |
| --- | --- | --- | --- | --- | --- |
| 容值范围 | 0.1pF~100μF | 0.1μF~1F | 0.1μF~1000μF | 100pF~100μF | 10μF~1000μF |
| 容量密度 | 中 | 高 | 高 | 低 | 高 |
| 耐压范围 | 6.3V~数kV | 6.3V~450V+ | 2.5V~50V | 50V~数kV | 2.5V~100V |
| ESR | 极低 | 高 | 中 | 低 | 低 |
| ESL | 极低 | 高 | 中 | 中 | 低 |
| 温度稳定性 | 差（X5R/X7R） | 中 | 较好 | 优秀 | 较好 |
| 寿命 | 极长 | 有限，需校核 | 较长 | 极长 | 长 |
| 极性 | 无 | 有 | 有 | 无 | 有 |
| 失效模式 | 短路（机械开裂） | 干涸开路 | 短路（易热失控） | 开路 | 开路 |
| 单位容值成本 | 低 | 低 | 高 | 高 | 中高 |

### 3.1 各类型的关键限制与规避措施

**MLCC（多层陶瓷电容）**

- 适用：高频去耦、电源旁路、信号耦合、高频滤波、谐振回路。
- 关键限制：大容值高偏压下容值衰减严重；机械应力易开裂；焊接热冲击敏感。
- 规避：板边与拼板分割线附近避免使用 1210/1206 大尺寸器件，改用多颗小封装并联；大尺寸器件焊接前充分预热。

**液态铝电解电容**

- 适用：大容量储能、电源输入/输出滤波、成本敏感的大容值场合。
- 关键限制：存在明确寿命上限；低温下 ESR 上升、容值下降；纹波电流必须严格校核。
- 规避：寿命按 `L = L0 × 2^((T0-Ta)/10)` 估算（L0 为额定寿命，如 2000h @105℃；Ta 为实际工作温度），并将结果纳入设计评审。

**固态钽电容**

- 适用：空间受限的中等容值场合、低 ESR 需求、高可靠性场景。
- 关键限制：过压、浪涌、反接极易导致热失控起火。
- 规避：保证 50% 以上降额（推荐 60%）；优先选用带内置保险丝的安全型钽电容；严禁在低阻抗大电流回路上使用普通钽电容——其失效模式是短路而非开路，可能引发火灾。

**薄膜电容**

- 适用：高精度定时、谐振、安规（X/Y 电容）、高耐压、大电流脉冲。
- 关键限制：体积大，单位容值成本高，不适合大容量储能。
- 规避：安规场合必须选用带认证标志（VDE / UL / CQC）的 X1/X2/Y1/Y2 电容，普通薄膜电容不可替代。

**聚合物铝电解电容**

- 适用：开关电源输出滤波、需要兼顾低 ESR 与大容值的场合。
- 关键限制：价格高于液态电解；耐压通常不超过 100V。
- 规避：在中压大电流电源中作为"液态电解容量 + MLCC 级 ESR"的折中方案，性价比突出。

## 4. 典型场景配置

### 4.1 开关电源（DC-DC）输入/输出滤波

| 位置 | 推荐类型 | 必须校核的参数 |
| --- | --- | --- |
| 输入端 Bulk | 液态铝电解 或 聚合物 | 纹波电流额定值；耐压不低于 1.3 倍 Vin(max) |
| 输入端高频 | MLCC X7R | 偏压后有效容值；封装不大于 0805 |
| 输出端 Bulk | 聚合物 或 低 ESR 铝电解 | 纹波电流（含温度与频率修正） |
| 输出端高频 | MLCC X7R | 与 Bulk 并联后的阻抗特性 |

### 4.2 高速数字芯片电源去耦（PDN）

- 采用多容值并联 + 多封装组合，覆盖 kHz 至数百 MHz 的宽频段。
- 小封装（0402 / 0201）紧邻芯片引脚摆放，走线与过孔越短越好——其引入的寄生电感往往超过电容自身 ESL。
- 大容值（10μF / 22μF）布置在稍远处承担储能职能。
- 关键高速器件建议进行 PDN 阻抗仿真，确认工作频段内阻抗低于目标阻抗 Ztarget。

### 4.3 模拟信号链路

- 优先选用 C0G/NP0 或薄膜电容，以保证容值稳定性与低介质吸收（DA）。
- 音频耦合电容需关注耐压与漏电流。
- 采样保持电路必须选用低介质吸收电容（C0G，或 PPS / PP 薄膜）。

### 4.4 安规场合

- **X 电容**（跨接火线—零线）：抑制差模干扰，选用 X1/X2 安规电容。
- **Y 电容**（跨接火线/零线—地）：抑制共模干扰，选用 Y1/Y2 安规电容。
- 必须选用带安规认证的产品，其失效模式为开路，不得用普通电容替代。

## 5. 设计评审核对表

### 5.1 十项高发误区

1. 只看标称容值，忽略直流偏压效应——大容值 MLCC 实际容值可能不足标称的一半。
2. 忽略纹波电流额定值——电解电容鼓包与聚合物电容失效的首要原因。
3. 电解电容未做高温寿命校核——环境 85℃ 时，105℃/2000h 的电容寿命可能仅剩约 500h。
4. 钽电容降额不足——低于 50% 降额是热失控风险的主要来源。
5. 用普通电容替代安规电容——直接影响安规认证通过率。
6. 高频去耦使用大封装——ESL 大、SRF 低，高频滤波失效。
7. 忽略低温特性——电解电容在 -40℃ 时 ESR 可上升 5~10 倍。
8. 多容值并联未考虑反谐振——阻抗尖峰可能恰好落在敏感频段。
9. 忽略机械应力——板边、安装孔附近的 MLCC 易开裂失效。
10. 容值不取标准系列值——应使用 E6/E12/E24 标准容值，非标值成本高且供货不稳。

### 5.2 评审清单

评审时按下表逐项确认，每项须给出明确结论，而非"应该没问题"。

| 序号 | 核对项 | 判定标准 |
| --- | --- | --- |
| 1 | 每个电容的功能定位是否明确 | 能说明其承担的具体电路角色 |
| 2 | 工作电压是否满足降额要求 | 对照第 2.2 节降额规则 |
| 3 | MLCC 是否校核过偏压后容值 | 已查阅 DC Bias 曲线 |
| 4 | 电解/聚合物是否校核纹波电流 | 已含温度与频率修正系数 |
| 5 | 电解电容是否完成寿命估算 | 有明确的寿命计算数值 |
| 6 | 钽电容降额是否达标 | 不低于 50%（推荐不低于 60%） |
| 7 | 高低温极限是否校核 | -40℃ 与最高工作温度均已核算 |
| 8 | 高频去耦封装与位置是否合理 | 小封装紧邻引脚 |
| 9 | 机械应力薄弱位置是否规避 | 远离板边与拼板分割线 |
| 10 | 安规电容是否具备认证 | 认证标志齐备且参数匹配 |
| 11 | 容值是否采用标准系列 | E6/E12/E24 系列 |

## 6. 常见问题解答

**问：去耦电容是不是越多越好？**

不是。容值总量增加带来的收益递减，而反谐振风险、布局复杂度与成本会上升。合理做法是：按目标阻抗确定总容值，按频段分配容值组合，最后通过 PDN 仿真验证。

**问：10μF 的 0805 X5R 能直接用于 5V 电源轨吗？**

需先确认两件事：一是实际工作电压下的偏压后容值（5V 偏压下可能仅剩约 4μF）；二是温度范围是否超出 X5R 的 85℃ 上限。两者均满足才可使用。

**问：为什么电解电容要校核寿命，MLCC 却不用？**

MLCC 为陶瓷介质，不存在电解液蒸发问题，寿命主要由机械应力与介质老化决定，量级远高于一般产品寿命。而铝电解电容的电解液会持续干燥，且干燥速率随温度指数上升，高温场合必须校核寿命。

**问：什么情况下必须选用聚合物电容而非普通电解？**

出现以下任一条件时优先考虑：纹波电流大、要求低 ESR、安装空间受限、或要求高可靠性。代价是成本较高，且耐压通常不超过 100V。

**问：能否用两颗普通电容串联替代一颗安规电容？**

不能。安规电容的认证涵盖失效安全（失效必须开路）、耐压脉冲与阻燃要求，普通电容不具备这些认证，串联也无法解决认证问题。

## 7. 小结

电容选型的本质，是在电气应力、环境应力、成本与空间之间寻找平衡点。不存在普适的最优解，只有针对特定场景最合适的解。

把第一章的决策链与第五章的评审清单贴在工位上，每次选型完整走一遍，足以规避绝大多数批量失效问题。至于具体型号，始终以厂商规格书与实测数据为准。

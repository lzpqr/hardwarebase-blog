原理图决定电路“能不能工作”，PCB 决定电路“能不能稳定工作”。

同一张原理图，换一种布局和布线方式，可能出现完全不同的结果：有的板一次通过 EMC 和高速接口测试，有的板在实验室能运行，到现场却频繁死机；有的板量产良率稳定，有的板装配缺陷不断。

PCB 设计不是简单的“网络连通图”，而是一项同时涉及电气性能、结构装配、散热、电磁兼容、生产工艺和成本控制的系统工程。

布局决定电流回路和信号路径，叠层决定阻抗和回流，布线决定串扰和时序，焊盘和丝印决定焊接良率与可维修性。

> 本文是硬件开发流程系列的第五篇。建议先阅读 [原理图设计篇](/posts/hardware-development-schematic-design/)、[方案设计篇](/posts/hardware-development-solution-design/) 和 [需求分析篇](/posts/hardware-development-requirements-analysis/)。

## PCB 设计的目标与边界

### PCB 设计要解决的五个问题

1. 电流从哪里流回哪里？
2. 信号在什么环境中传输？
3. 热量从哪里传到哪里？
4. 产品如何被制造出来？
5. 问题如何被定位和修复？

如果这些问题在设计阶段没有答案，就会在样机调试或量产阶段被迫返工。

### PCB 设计的三层目标

| 层次 | 目标 | 典型表现 |
| --- | --- | --- |
| 电气连通 | 网络全部正确连接 | 上电可用、接口能通、功能正常 |
| 工程可靠 | 在真实环境和全生命周期内稳定 | 通过 EMC、高低温、振动和寿命测试 |
| 量产可交付 | 高良率、低成本、易测试、易维护 | 一次通过、良率稳定、返修方便 |

布局布线首先服务于第一层，但评审必须覆盖后两层。很多“能用的板子”无法量产，问题就出在只完成连通，没有完成工程化设计。

### 上下游边界

PCB 设计需要与上下游明确边界：

- 与原理图：网络、封装、约束和变更是否一致；
- 与结构：板框、安装孔、连接器、限高、散热器和屏蔽罩；
- 与工艺：最小线宽线距、孔径、工艺边、拼板和表面处理；
- 与测试：测试点、夹具空间、烧录和校准接口；
- 与软件：调试接口、状态指示、启动配置和引脚定义。

边界不清会导致结构干涉、焊接不良或测试困难，必须在设计输入阶段逐项确认。

## 1. 设计输入：动手布线之前必须确认的内容

开始布局前，至少应确认：

- 已评审通过的原理图网表；
- 板框、安装孔、限高区和装配关系；
- 叠层、铜厚、介质厚度和目标阻抗；
- 关键器件数据手册、封装图和布局建议；
- 各电压域电流、压降和散热要求；
- 爬电距离、电气间隙、隔离带和认证要求；
- 板厂的最小线宽线距、孔径、板厚和表面处理能力；
- 层数、面积、工艺复杂度和量产规模。

### 设计规则与约束体系

| 约束类型 | 内容 |
| --- | --- |
| 电气约束 | 网络类、电压域、电流、阻抗、差分对和等长组 |
| 物理约束 | 线宽、线距、过孔尺寸、铜皮间距和焊盘尺寸 |
| 间距约束 | 器件间距、铜到板边、铜到安装孔和隔离距离 |
| 布线约束 | 拓扑、最大长度、最小长度、匹配公差和层限制 |
| 生产约束 | 最小孔径、环宽、阻焊桥和字符尺寸 |

约束应先建立、后布线。先画完再补规则，等于放弃了对设计的控制。

### 常见设计输入错误

- 原理图未定型就匆忙布局；
- 结构文件版本过期；
- 封装未核对实物；
- 未确认板厂工艺能力；
- 高速接口缺少阻抗和等长要求。

## 2. 布局：决定成败的第一步

### 布局基本原则

- 先大后小：先放连接器、大器件、结构件和发热器件；
- 先难后易：先处理高速、敏感、大电流和特殊封装；
- 按功能分区：数字、模拟、射频、电源和接口分区；
- 信号流向顺畅：避免走线绕远和大量交叉；
- 电源路径短：减小电源和去耦回路面积；
- 热源分散：避免热敏器件靠近热源；
- 便于生产和返修：留出焊接、检测和维修空间。

### 结构与装配

- 核对板框、安装孔和定位方式；
- 确认连接器与外壳开孔对齐；
- 检查限高区，避免器件与外壳、散热器或屏蔽罩干涉；
- 考虑拼板、分板和工艺边；
- 为螺钉、卡扣、泡棉和导热垫预留空间；
- 保证装配顺序和操作空间。

### 关键器件布局

- 连接器靠近板边，保护器件靠近连接器；
- 晶振靠近芯片时钟引脚，远离开关节点和高速信号；
- 电源器件的高频环路面积最小，反馈走线远离开关节点；
- 去耦电容靠近电源引脚，回路面积最小；
- 模拟、传感器和射频器件远离开关电源和高速数字电路；
- 发热器件分散布置，温度敏感器件远离热源；
- 大电流器件核算铜厚、载流能力和压降。

## 3. 叠层设计与阻抗控制

### 叠层原则

- 每个信号层尽量有相邻完整参考平面；
- 电源平面和地平面成对布置；
- 关键高速信号靠近参考平面；
- 叠层尽量对称，减少翘曲；
- 介质厚度和铜厚与板厂工艺参数一致；
- 叠层确定后固化到设计文件中。

### 常见叠层

| 层数 | 典型叠层 | 适用场景 |
| --- | --- | --- |
| 双层板 | 信号 / 地或电源 | 低速、低成本、简单产品 |
| 四层板 | 信号 / 地 / 电源 / 信号 | 通用数字产品和中低速接口 |
| 六层板 | 信号 / 地 / 信号 / 电源 / 地 / 信号 | 中高速接口和较好 EMC 性能 |
| 八层及以上 | 多组信号与平面交替 | 高速总线、DDR 和复杂系统 |

四层板是常见通用选择，但必须明确各信号层以哪个平面为参考，避免参考平面被分割。

### 阻抗控制

- 明确单端 50Ω、差分 90Ω/100Ω 等目标；
- 阻抗由线宽、介质厚度、介电常数和参考平面共同决定；
- 与板厂确认阻抗模型；
- 差分对保持线宽线距一致；
- 在生产文件中明确阻抗测试条和测试报告。

## 4. 电源完整性（PI）设计

### 电源平面与分割

- 电源平面尽量完整，避免细长瓶颈；
- 不同电压域按区域分割，但必须基于电流路径；
- 避免信号跨越平面分割；
- 大电流路径核算铜箔截面积和温升；
- 电源与地平面尽量靠近，形成低阻抗平面电容。

### 去耦电容

- 按从大到小、就近放置的原则布置；
- 小容量高频电容靠近电源引脚；
- 电容过孔短粗，减少寄生电感；
- 多个电容并联时注意安装电感和自谐振频率；
- 关键芯片使用专用去耦，不与噪声电路共用。

### 电源回路与地平面

- 开关电源高频环路面积最小；
- 功率路径使用多过孔并联，降低阻抗和温升；
- 反馈采样点从输出电容末端取样；
- 地平面保持完整、低阻抗；
- 高速信号换层时提供就近回流过孔。

## 5. 信号完整性（SI）与高速布线

### 传输线与匹配

- 高速信号按传输线处理；
- 保持阻抗连续，避免线宽突变和跨分割；
- 根据拓扑选择串联、并联、戴维南或 RC 端接；
- 源端串联端接尽量靠近驱动端。

### 差分对

- 等长、等距、同层、同参考平面；
- 保持差分阻抗一致；
- 控制对内和组间偏差；
- 差分对内避免测试点和分支；
- 必要时增加包地和过孔屏蔽。

### 长度匹配、参考平面与过孔

- 区分对内等长和组间等长；
- 避免过度绕线；
- 高速信号必须有连续参考平面；
- 换层时保持参考平面一致并增加回流过孔；
- 减少高速信号过孔，评估残桩和背钻需求。

### 串扰控制

- 增大线间距；
- 避免长距离并行走线；
- 敏感信号远离高摆幅和高速边沿信号；
- 减小信号与参考平面间距；
- 注意连接器、插座和排针内部串扰。

## 6. 时钟、复位与敏感信号

- 时钟走线尽量短、直，远离板边和接口；
- 时钟下方保持完整地平面；
- 复位信号远离时钟和高速信号；
- 敏感模拟信号避免与数字信号平行长距离走线；
- 高阻节点关注漏电流、寄生电容和防护；
- 关键信号预留测试点。

## 7. 模拟与混合信号 PCB

### 分区与接地

模拟区、数字区和功率区分区布置，减少相互耦合。模拟地与数字地的连接方式应根据信号回流路径确定，避免地环路。

### ADC/DAC

- 模拟输入远离数字信号和时钟；
- 基准源靠近 ADC 并充分去耦；
- 采样时钟短且稳定；
- 数字输出与模拟输入分区；
- ADC 下方地平面保持完整。

### 低噪声与射频

- 基准源远离热源和开关电源；
- 使用开尔文连接减少压降影响；
- 敏感信号采用差分传输或屏蔽；
- 射频走线按 50Ω 控制，并布置接地过孔阵列；
- 天线区域保持净空；
- 屏蔽罩接地和开孔设计合理。

## 8. 接地设计

### 地平面策略

- 优先使用完整地平面，而不是大量细碎地岛；
- 地平面分割必须有明确目的和回流依据；
- 单点接地适用于低频模拟，多点接地适用于高频和数字；
- 混合接地需要谨慎，避免形成天线或地环路。

### 地类型

| 类型 | 特点 | 处理方式 |
| --- | --- | --- |
| 数字地 | 噪声大、电流跳变快 | 完整平面、低阻抗、靠近信号回流 |
| 模拟地 | 对噪声敏感 | 独立区域，按回流路径连接 |
| 功率地 | 电流大，压降和温升明显 | 短粗走线、大面积铜皮、多过孔 |
| 机壳地 | 屏蔽和安规相关 | 低阻抗搭接，按安规要求处理 |

### 地环路与屏蔽

避免大面积地环路；屏蔽罩、屏蔽线和结构件保持低阻抗搭接；线缆屏蔽层按频率和安规要求选择接地方式。## 9. EMC 设计

EMC 问题通常与高速信号、时钟、开关电源、接口线缆和地回路有关。

### 干扰来源

- 辐射主要来自高速信号、时钟、开关电源和线缆；
- 传导主要来自电源输入输出和接口线缆；
- 从源头降低干扰：降低边沿速率、减小环路面积、增加滤波；
- 从路径阻断耦合：分区、屏蔽、隔离和合理接地。

### 接口滤波和保护

- 对外接口增加共模电感、滤波电容和 TVS；
- 按“先保护、后滤波、再进芯片”的原则布局；
- 滤波电容的接地回路尽量短；
- 保护器件靠近连接器，减少耦合路径。

### 开关电源 EMC

- 输入输出电容紧靠芯片，减小高频环路；
- 开关节点铜皮面积适中，避免成为辐射天线；
- 必要时增加 RC 吸收、磁珠或共模电感；
- 反馈和使能走线远离开关节点。

### 结构与屏蔽

- 屏蔽罩接地过孔密集，避免缝隙谐振；
- 机壳开孔尺寸与最高频率相关；
- 导热垫、导电泡棉和屏蔽材料搭接可靠；
- 线缆进出位置的滤波和屏蔽统一设计。

### 常见整改手段

| 问题 | 常用手段 |
| --- | --- |
| 时钟谐波辐射 | 串联电阻、降低驱动、包地和屏蔽 |
| 电源传导发射 | 共模电感、X/Y 电容和输入滤波 |
| 接口线缆辐射 | 共模电感、磁环、屏蔽和良好接地 |
| 开关电源噪声 | 减小环路、优化布局、增加吸收 |
| 地弹和共阻抗 | 降低地阻抗、优化分区和回流 |

## 10. 热设计

### 热阻与散热路径

从芯片结温到环境的总热阻决定温升。主要散热路径通常为：

```text
芯片 → 焊盘 → 铜皮 → 过孔 → 内层铜 → 环境
```

铜皮面积、铜厚、过孔数量和风道都会影响散热效果。

### 铜皮、过孔与散热焊盘

- 散热焊盘通过密集过孔连接内层地平面；
- 过孔数量足够并均匀分布；
- 大功率器件下方铺铜，必要时开窗加锡；
- 考虑焊接工艺对散热焊盘的要求，避免虚焊。

### 风道与测温

- 热敏器件布置在进风口或低温区；
- 高热器件沿风道方向排列，避免互相加热；
- 留出足够的器件间距和空气流通空间；
- 对高功耗板卡进行热仿真；
- 样机阶段使用热电偶或热像仪实测关键温度。

## 11. 可制造性设计（DFM）

### 工艺能力匹配

- 最小线宽、线距、孔径和环宽与板厂能力匹配；
- 考虑厚径比、板厚公差和层间对位精度；
- 不同表面处理对应不同焊接和存储要求；
- 高密度设计需要与成本和交期权衡。

### 焊盘和阻焊

- 焊盘尺寸按器件规格和工艺要求设计；
- 阻焊桥宽度满足工艺能力，避免连锡；
- 散热焊盘、接地焊盘和过孔处理方式明确；
- 避免在焊盘上打孔造成漏锡。

### 拼板、工艺边和丝印

- 拼板方式考虑分板应力、器件方向和利用率；
- 工艺边宽度和定位孔满足产线要求；
- 分板位置避免损伤器件和走线；
- 器件位号清晰，避免遮挡焊盘和测试点；
- 极性方向、第一脚和接口方向标识明确。

### 常见 DFM 问题

- 焊盘尺寸不当导致立碑、偏移或虚焊；
- 阻焊桥过窄导致连锡；
- 过孔塞孔或盖油方式不当导致漏锡；
- 拼板分板应力导致器件开裂；
- 器件间距过小导致无法返修。

## 12. 可测试性与可组装性（DFT/DFA）

### 测试点设计

- 关键电源、时钟、复位和总线预留测试点；
- 测试点尺寸、间距和位置满足探针或夹具要求；
- 测试点周围避免被高器件遮挡；
- 关键网络可在不同位置增加测试点，便于分段排查。

### 产线测试方式

| 方式 | 特点 | 设计要求 |
| --- | --- | --- |
| 飞针测试 | 灵活、无需夹具 | 测试点可达、间距足够 |
| ICT | 速度快、覆盖广 | 测试点布局规则化 |
| 功能测试 | 验证整机功能 | 预留接口和状态指示 |
| 老化测试 | 筛选早期失效 | 考虑散热和供电能力 |

### 组装与返修

- 器件间距满足贴片、焊接和返修要求；
- 大器件周围留出返修工具空间；
- BGA、QFN 等封装考虑返修和检测方式；
- 避免在难返修区域布置关键易损器件。## 13. 设计检查与评审

### 评审流程

1. 自检：按检查清单完成自检；
2. 交叉评审：检查布局、布线和规则；
3. 专项评审：电源、高速、EMC、热、结构和工艺参与；
4. 投板评审：确认所有问题闭环后才能发板。

### 评审角色

| 角色 | 关注重点 |
| --- | --- |
| 硬件设计者 | 网表、布局、布线、规则完整性 |
| 硬件评审人 | 设计规范、常见错误和可读性 |
| 电源工程师 | 电源路径、去耦、压降和温升 |
| SI/PI 工程师 | 阻抗、回流、串扰和电源噪声 |
| EMC 工程师 | 滤波、接地、屏蔽和接口 |
| 热工程师 | 散热路径、器件温度和风道 |
| 结构工程师 | 板框、限高、连接器和装配 |
| 工艺工程师 | 焊盘、拼板、工艺能力和可制造性 |
| 测试工程师 | 测试点、夹具、烧录和测试接口 |

### 常见错误

- 布局：连接器冲突、晶振靠近电感、去耦过远、热源集中；
- 叠层：参考平面不连续、阻抗与工艺不一致、铜厚不足；
- 布线：高速信号跨分割、差分不等长、回流路径中断；
- EMC：滤波位置错误、开关环路过大、地平面过度分割；
- DFM：焊盘不当、阻焊桥过窄、分板应力集中。

问题的根源通常集中在三点：约束不完整、评审不充分、变更不受控。

## 14. 从设计到制造

投板前需要向板厂和产线交付完整生产文件：

- Gerber 文件：铜箔、阻焊、丝印、钻孔和成型；
- 钻孔文件：孔径、孔数以及金属化、非金属化区分；
- 叠层与阻抗报告：层结构、铜厚、介质厚度和目标阻抗；
- 拼板文件：拼板方式、工艺边、定位孔和分板方式；
- 坐标与钢网文件：贴片坐标、钢网开孔和特殊工艺要求；
- 装配图和 BOM：器件位置、极性方向、替代料说明；
- 测试与检验要求：测试点、检验标准、阻抗测试和外观要求；
- 变更说明：版本变化、影响范围和验证结果。

设计文件与生产文件必须一致，避免“图纸改了、文件没更新”。

## 15. PCB 设计的四个层次

PCB 设计能力可以分为四个层次：

1. 会连：能把网络正确连通，完成基本功能；
2. 会布：能按规则布局布线，控制阻抗、回流和串扰；
3. 会防：能预见 EMC、热、机械和工艺风险；
4. 会交付：能兼顾成本、良率、测试和维护。

从“会连”到“会交付”，靠的不是更多技巧，而是系统化设计、严谨评审和持续的问题闭环。

一块好的 PCB，是原理图意图的忠实实现，也是产品可靠性和量产能力的直接体现。

## 附录 A：PCB 设计评审检查清单

### 设计输入与规范

- 网表已评审，封装与器件一致；
- 结构文件版本正确；
- 叠层、阻抗、铜厚和工艺要求已确认；
- 设计规则和约束完整；
- 版本变更记录完整。

### 布局

- 器件均在板框内，无结构干涉；
- 功能分区和信号流向合理；
- 关键器件靠近对应接口；
- 电源和去耦布局合理；
- 热源分散，热敏器件远离热源；
- 留出焊接、检测和返修空间。

### 叠层、阻抗与电源

- 每个信号层有完整参考平面；
- 叠层对称，铜厚和介质厚度合理；
- 阻抗计算与板厂工艺一致；
- 电源平面完整，去耦近芯片；
- 大电流路径满足载流和压降；
- 地平面完整，跨分割已处理。

### 信号完整性

- 高速信号阻抗连续，无跨分割；
- 差分对等长、等距、同层；
- 等长组公差满足接口规范；
- 过孔数量和残桩影响合理；
- 串扰控制措施到位。

### EMC、热和制造

- 接口滤波和保护靠近连接器；
- 开关电源环路面积最小；
- 屏蔽、搭接和开孔合理；
- 散热路径清晰，铜皮和过孔充分；
- 线宽线距、孔径满足板厂能力；
- 拼板和工艺边满足产线要求；
- 测试点布局满足夹具要求。

### 生产文件

- Gerber、钻孔、叠层和阻抗报告完整；
- 拼板、钢网和坐标文件正确；
- 装配图和 BOM 与设计一致；
- 检验和测试要求明确。

## 一、文档目的与适用范围

本文档规定硬件产品中 SPI（Serial Peripheral Interface）接口的电气设计、总线拓扑、时钟模式与时序要求、PCB 布局、可靠性设计及测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：单板内主控制器与外围器件（SPI Flash、EEPROM、ADC/DAC、传感器、显示屏、射频芯片等）之间的 SPI 互连设计。板间长距离传输不在本文档范围内，应改用差分总线或 LVDS、隔离方案。

## 二、接口概述

SPI 由 Motorola 定义，是一种四线制同步串行外设总线。它与 I2C 同属板内短距离串行总线，但在电气形式与协议机制上有本质差异，核心特征如下：

- **四线制**：SCK（串行时钟）、MOSI（主出从入）、MISO（主入从出）、CS（片选），另加一根共地 GND。
- **全双工同步**：主机与从机在同一时钟驱动下同时收发，时钟由主机单向提供，不需要双方约定波特率。
- **单主多从**：协议本身不支持多主竞争，也没有总线仲裁机制；从机的选择完全依赖独立的片选信号。
- **推挽输出**：与 I2C 的开漏结构不同，SPI 采用 CMOS 推挽输出，无需上拉电阻，边沿陡峭、可达到很高的数据率。
- **无寻址机制**：从机没有地址字段，靠 CS 引脚选中，因此每增加一个从机需多占用一根主机 GPIO。
- **无硬件应答**：协议层没有 ACK/NACK 握手，数据是否被正确接收无从机反馈，通信可靠性完全依赖硬件时序裕量与软件校验。
- **速率灵活**：没有标准速率上限，常见 1~50MHz，SPI Flash 类器件可达 80~133MHz，Dual/Quad/Octal 模式按位宽成倍提升。

SPI 的优势是速率高、协议简单、全双工、软件开销小；代价是引脚数随从机增加而线性增加、缺少应答机制，且没有统一的帧格式标准（命令集由各厂商自定，需逐一核对手册）。

## 三、物理层设计

物理层设计直接决定信号完整性与时序裕量，内容涵盖信号定义、电气特性与速率、拓扑形式的选择、跨电压域的电平转换，以及上拉与端接的处理。

### （一）信号定义

| 信号 | 方向（相对主机） | 说明 |
| --- | --- | --- |
| SCK | 输出 | 串行时钟，由主机产生，决定位传输速率 |
| MOSI | 输出 | Master Out Slave In，主机数据输出 |
| MISO | 输入 | Master In Slave Out，从机数据输出 |
| CS/SS | 输出 | 片选，低电平有效，每个从机一根 |
| GND | — | 必需共地，不可省略 |

### （二）电气特性与速率

SPI 采用推挽 CMOS/TTL 电平，不需要上拉电阻，这是与 I2C 的关键区别之一。总线速率上限由三个因素共同决定，取其中的最小值：从机支持的最高速率、主机 SPI 控制器在其时钟源下能分出的速率、以及在当前 PCB 走线与寄生参数条件下仍能保证建立保持时间裕量的最高频率。

逻辑电平必须与两侧 IO 电平一致（常见 1.8V/2.5V/3.3V）。同一总线上若存在不同电平域，必须做电平转换处理。

### （三）拓扑形式

- **点对点**：最简形式，主机与单个从机直连，用于高速、大流量场合（如 ADC 采样数据回读、显示屏刷屏）。信号完整性最好、容性负载最小。
- **多从独立片选**：最常用形式，SCK、MOSI、MISO 三根线并联到所有从机，每个从机单独分配一根 CS。任一时刻仅允许拉低一根 CS，未被选中的从机其 MISO 必须处于高阻态。
- **菊花链 Daisy-chain**：各从机的 MOSI 与 MISO 首尾相接，数据依次穿过各级移位寄存器，主机一次移出 N×8 位。适用于级联 LED 驱动、级联移位寄存器，仅需一根公共 CS；缺点是任一级故障会导致整条链失效，且软件需倒序拼接数据。
- **片选扩展**：当从机数量多于主机可用 CS 引脚时，可用 3-8 译码器或多路复用器扩展 CS，但须评估译码延迟对 CS 建立时间的影响。

### （四）电平转换设计

电平不一致时应按信号方向分别处理：单向信号（SCK、MOSI、CS）可用单向缓冲器（如 74LVC1G125 类）；MISO 方向与 MOSI 相反，应与 MOSI 共用双向自动方向转换器件（如 TXS/TXB 系列），或按方向单独转换。

选型时必须注意两点：转换器的传播延迟要远小于一个时钟周期，否则会吃掉建立保持裕量；转换方向要与信号方向匹配，避免自动方向器件在强推挽驱动下误判方向。

### （五）上拉、下拉与端接

- **CS 引脚**：建议为每个从机的 CS 加 10kΩ 弱上拉至从机 IO 电源，确保在主机复位、GPIO 尚未配置为输出（处于高阻）期间从机不被误选中。
- **MISO 引脚**：所有从机均未被选中时 MISO 处于高阻态，总线浮空。主机侧引脚建议配置为带弱上拉或弱下拉的输入，避免浮空引入误触发与额外功耗。
- **串联端接**：当 SCK 频率超过约 25MHz 或走线较长时，在驱动器侧串联 22~50Ω 电阻以匹配阻抗、抑制过冲与振铃。具体阻值需结合引脚驱动强度，通过实测波形确定。

## 四、协议层设计

SPI 没有统一的帧格式标准，主机侧真正需要配置的参数只有"时钟极性 CPOL、时钟相位 CPHA、位序、数据位宽、片选极性"几项，但每一项都必须与从机严格一致，否则数据必然出错。

### （一）时钟极性 CPOL 与相位 CPHA

CPOL 决定 SCK 空闲状态的电平，CPHA 决定数据在第几个边沿被采样，二者组合构成四种工作模式：

| 模式 | CPOL | CPHA | SCK 空闲电平 | 采样边沿 | 数据翻转边沿 |
| --- | --- | --- | --- | --- | --- |
| Mode 0 | 0 | 0 | 低 | 上升沿 | 下降沿 |
| Mode 1 | 0 | 1 | 低 | 下降沿 | 上升沿 |
| Mode 2 | 1 | 0 | 高 | 下降沿 | 上升沿 |
| Mode 3 | 1 | 1 | 高 | 上升沿 | 下降沿 |

其中 Mode 0 与 Mode 3 最为常用，多数传感器与 Flash 器件采用这两种之一，具体以从机数据手册的时序图为准。主机与从机模式不一致时，典型表现是数据整体错位一位或完全无法识别。

### （二）帧格式与位序

每帧数据的位数通常为 8 位，部分器件（如某些 ADC/DAC、音频 codec）支持 12/16/24/32 位。位序绝大多数为 MSB 先行（MSB first），少数器件支持 LSB first，需按手册配置。

SPI 没有起始位、停止位，也没有地址字节和应答位。帧的边界完全由 CS 信号界定：CS 拉低标志一次传输开始，CS 拉高标志传输结束。因此任何导致 CS 未按预期释放的软件错误都会使从机内部状态机错位，这是 SPI 最常见的失效模式之一。

### （三）片选时序要求

片选相关的三个时间参数必须从从机手册获取并在设计中满足：

- **建立时间 tCSS**：CS 下降沿到第一个有效 SCK 边沿的最小间隔。
- **保持时间 tCSH**：最后一个 SCK 边沿到 CS 上升沿的最小间隔。
- **帧间隔 tCS**：CS 上升沿到下一次下降沿的最小间隔（即 CS 无效时间）。很多 SPI Flash 与 ADC 要求几十纳秒到数百纳秒不等；若硬件 SPI 控制器的自动 CS 无法满足，应改用软件 GPIO 控制片选并插入延时。

### （四）全双工特性与哑元周期

SPI 是全双工：主机每发送一个字节，从机必然同时返回一个字节。因此读操作的本质是"主机发送哑元字节（dummy byte，通常为 0x00 或 0xFF）来产生时钟，把从机数据换出来"。主机不可能在不发送数据的情况下读到从机数据，这是理解 SPI 读时序的关键。

部分器件（尤其是 SPI Flash）在发送完读地址后还需要若干个哑元时钟周期才能输出有效数据，控制器或软件必须按手册插入这些周期，否则读回数据会整体错位。

### （五）多字节突发传输

在 CS 保持连续的条件下，可对地址自动递增的器件连续读写多个字节。突发传输过程中不得拉高 CS，否则从机地址计数器会被复位。单次传输长度不得超过从机的页边界，超页会发生地址回卷。

## 五、读写操作时序

绝大多数 SPI 外设采用"命令字节 + 地址 + 数据"的三段式访问模型，以下分别说明通用寄存器读写流程与 SPI Flash 的典型操作序列。

**通用寄存器写操作**：CS 拉低 → 发送命令或寄存器地址字节（通常最高位为读写方向位，写为 0）→ 连续发送数据字节 → CS 拉高。写完成后若器件要求延时（如内部写周期），须等待完成后再发起下一次操作。

**通用寄存器读操作**：CS 拉低 → 发送命令或寄存器地址字节（读方向位为 1）→ 按需插入哑元周期 → 主机持续发送哑元字节以产生时钟，同时从 MISO 接收返回数据 → CS 拉高。需特别注意：某些器件的返回数据从第二个字节才开始有效（首字节为哑元），也有器件在同一帧内立即返回，二者软件处理方式不同，必须以手册时序图为准。

**SPI Flash 典型操作序列**（以通用 SPI NOR Flash 为例）：

| 操作 | 指令字 | 关键流程 |
| --- | --- | --- |
| 读数据 | 0x03 | 发指令 + 24 位地址 → 连续读 |
| 快读 | 0x0B | 发指令 + 地址 + 8 位哑元 → 连续读 |
| 写使能 | 0x06 | 每次写或擦除前必须先行发送 |
| 页编程 | 0x02 | 写使能 → 发指令 + 地址 + 数据（不跨页，典型 256 字节） |
| 扇区擦除 | 0x20 | 写使能 → 发指令 + 地址 |
| 读状态寄存器 | 0x05 | 轮询 BUSY 位判断操作是否完成 |

Flash 的写入与擦除是异步操作，必须轮询状态寄存器的 BUSY 位或按手册等待最大耗时（典型数百微秒至数十毫秒），期间不可发起新的写操作。

**菊花链传输**：主机一次性移出 N×8 位数据，最先发出的字节最终落到链路末端的器件。软件需按倒序组织发送缓冲区，链路任一级时序异常都会导致整串数据错位。

**Dual / Quad / Octal 扩展模式**：为提升吞吐，厂商在标准 SPI 基础上扩展出多位并行接口：

- Dual SPI：MOSI 与 MISO 同时用于数据传输，较单线模式速率翻倍。
- Quad SPI：复用 WP#、HOLD# 引脚作为 IO2、IO3，形成 4 位并行。
- Octal / OSPI + DDR：8 位并行并在时钟上下沿均采样，可支持片上执行（XIP）。

采用扩展模式时，硬件上要求主控与从机同时支持，且需注意相关引脚在标准模式下的复用关系，避免上拉配置与复用冲突。

## 六、硬件设计要点

结合 SPI 推挽、高速、无应答的特点，硬件设计中应重点落实以下各项：

- **每条 CS 独占**：任一从机必须有独立的 CS 信号，禁止多个从机共用一根 CS（菊花链除外）。共用 CS 会导致多个从机同时驱动 MISO 造成总线冲突，甚至损坏器件。
- **CS 弱上拉**：每个 CS 加 10kΩ 上拉至从机侧 IO 电源，防止主机复位或 IO 未初始化期间从机被误选中。
- **电平匹配**：跨电压域必须使用专用电平转换器件，禁止用电阻分压凑合；转换器带宽与延迟要满足目标速率要求。
- **星型布线**：多从机时应采用星型或短分支布线，避免长 stub。过长的分支线会引起反射与边沿劣化，必要时加缓冲器扇出。
- **高速端接**：SCK 频率较高或走线较长时，在驱动侧串 22~50Ω 电阻，并通过实测波形微调阻值与驱动强度。
- **等长控制**：SCK 与数据线应同组走线并控制长度偏差，使数据相对时钟的偏移远小于建立保持裕量；高速场合应按传播延迟定量核算。
- **完整地平面**：SPI 走线下方须有连续地平面作为回流路径，严禁跨分割；走线应远离开关电源节点、电感、时钟源与射频区域。
- **模拟与数字隔离**：当从机为 ADC、RF 收发等敏感器件时，SPI 走线应与模拟前端分区布局，必要时加屏蔽地过孔或串联阻尼电阻降低串扰。
- **电源去耦**：每个从机电源就近放置去耦电容。SPI Flash 在写入瞬间电流较大，电源跌落会直接造成数据错误。
- **IO 属性配置**：主机侧 SPI 引脚需正确配置为复用功能，并设置合适的驱动强度与压摆率，避免强驱动引起振铃或弱驱动导致边沿过缓。

## 七、典型应用场景

SPI 凭借其高带宽被广泛应用于存储、数据转换、传感与显示等场景，各类应用的关注重点差异较大：

| 应用对象 | 典型器件 | 设计关注点 |
| --- | --- | --- |
| 非易失存储 | SPI NOR Flash、EEPROM、FRAM | 写使能、擦除与 BUSY 轮询流程；XIP 与 Quad 模式的引脚复用 |
| 数据转换 | ADC、DAC | 帧宽（12/16/24 位）、采样时钟抖动、转换完成信号的配合 |
| 惯性传感器 | IMU、加速度计、磁力计 | FIFO 突发读取的长度限制、模式选择、中断引脚配合 |
| 显示与触控 | OLED、TFT 驱动 IC | 数据 / 命令切换（D/C 线）、刷屏带宽计算、走线端接 |
| 射频收发 | LoRa、Sub-G、Wi-Fi 模组 | 寄存器配置时序、突发读写长度限制、与射频走线的隔离 |
| 存储卡 | MicroSD（SPI 模式） | 初始化阶段的降速要求、命令响应等待周期 |
| 端口扩展 | 数字电位器、IO 扩展、移位寄存器 | 菊花链数据拼接、级联刷新独立性 |

## 八、可靠性与测试验证

SPI 的工程问题集中在模式配置错误、片选时序违规与高速信号完整性三类。由于协议本身没有应答机制，任何错误都不会有硬件反馈，必须在设计阶段建立故障模式清单并在调试测试中逐条排查。

**常见故障模式**：

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 读回全 0xFF 或全 0x00 | MOSI/MISO 未连通或接反、从机未被选中 | 核对接线；测量 CS 是否真的拉低；确认从机已上电并完成初始化 |
| 数据整体偏移一位 | CPHA 配置错误 | 切换 CPHA 后重测（Mode 0 与 Mode 1 互换验证） |
| 数据位顺序颠倒 | MSB/LSB 位序配置错误 | 修改主机位序配置 |
| 首字节错、后续正确 | 地址后缺少哑元周期 | 按手册在地址与数据之间插入 dummy cycle |
| 只有第一次读正确 | CS 未在帧间释放 | 检查 CS 是否每帧拉高；检查帧长是否为数据宽度的整数倍 |
| 多从机互相干扰 | 未选中从机的 MISO 未进入高阻态 | 核对无关从机的驱动状态与 CS 电平；检查 CS 上升沿后从机释放时间 |
| Flash 写入失败或写坏 | 未发写使能、未先擦除、未等待 BUSY、跨页写 | 补齐 0x06 写使能；先擦后写；轮询 BUSY；按页边界分包 |
| 上电状态异常 | 复位期间 CS 浮空导致误选中 | CS 增加弱上拉；检查主机 GPIO 上电默认状态 |
| 波形过冲、振铃严重 | 阻抗不匹配、走线过长未端接 | 驱动侧串 22~50Ω；缩短走线；降低 IO 驱动强度 |
| 高速下偶发误码 | 速率超出时序裕量、走线 skew 过大 | 降速后对比验证；核算建立保持时间与走线长度差 |

**测试要点**：

- 电气参数测量：用示波器测量 SCK 频率、占空比、上升下降时间，确认不超过从机额定最大值，且高低电平满足器件 VIH/VIL 要求。
- 建立保持裕量：在数据线上测量相对采样边沿的建立时间与保持时间并量化裕量，不能仅凭"能通信"判定合格。
- 片选时序验证：逐项验证 tCSS、tCSH 与 CS 帧间隔满足手册要求。
- 波形质量：检查有无过冲、振铃、台阶与地弹，必要时调整端接电阻与驱动强度。
- 极限条件验证：在高低温、极限工作电压条件下重复上述测量。
- 压力与一致性测试：连续读写循环，写入有规律的数据并做逐字节校验或 CRC 校验，覆盖跨页、突发、菊花链最长帧等关键路径，统计误码率与重试次数。
- 多从机并发验证：分时切换所有从机，确认无互相干扰与总线冲突。

## 九、设计检查清单

1. 已确认所有从机均支持目标 SCK 频率，且主机分频配置正确。
2. 已逐一核对每个从机的 CPOL/CPHA 模式，主机配置与之一致。
3. 已确认数据帧宽度与位序（MSB/LSB first）配置正确。
4. 每个从机均有独立 CS 信号，且已配置弱上拉。
5. 已核实 tCSS、tCSH、tCS 三项片选时序，必要时改为软件控制 CS。
6. 已按手册插入哑元周期，读写序列与器件时序图一致。
7. 跨电平域部分已使用专用电平转换器件，带宽与延迟满足要求。
8. 多从机采用星型或短分支布线，无长 stub，走线未跨分割。
9. 高速走线已完成端接，实测波形无明显过冲与振铃。
10. SCK 与数据线长度偏差受控，建立保持裕量已量化。
11. 从机为模拟敏感器件时已完成分区与隔离设计。
12. 电源去耦电容已就近配置。
13. Flash 类器件已完成写使能、擦除、BUSY 轮询与页边界处理。
14. 已完成高低温与极限电压下的电气与时序裕量验证。
15. 软件层已增加超时重试与数据校验机制，弥补 SPI 无应答机制的不足。

> 注：本文为 SPI 接口的通用设计说明。SPI 没有统一的帧格式标准，具体项目的命令集、时序参数与速率上限最终以所用主控制器与从器件的数据手册为准，关键时序应在样板阶段通过实测确定。

DC-DC 是整机供电的地基，但选型阶段往往只被当作"一颗降压 IC"对待。真实的翻车场景高度集中：电流评估只算平均值、热设计缺失、静态功耗被忽视、环路/布局不当、拓扑选错。本文按"先锁定硬约束、再优化软指标、最后用检查清单兜底"的顺序给出一套可落地的选型方法。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。后级低噪声供电用 LDO 级联见[LDO篇](/posts/component-selection-ldo/)，功率开关管选型见[MOS管篇](/posts/component-selection-mosfet/)，储能电感选型见[电感篇](/posts/component-selection-inductor/)。

## 1. 为什么 DC-DC 选型容易"翻车"

- 电流评估只算平均值：忽略峰值与瞬态电流，导致满载掉压、过流保护误触发。
- 热设计缺失：只看 25 ℃ 参数表，忽略 RθJA 与降额曲线，实测结温超限。
- 静态功耗被忽视：电池产品待机电流做不下去，整机待机时间腰斩。
- 环路 / 布局不当：输入回路面积过大辐射 EMI 超标；反馈走线受扰，输出振荡。
- 拓扑选错：把只能降压的 Buck 用在需要升降压的场合，或用 LDO 硬扛大压差。

## 2. 选型五步法

1. 锁定系统级硬约束（输入范围、输出电流、温升、拓扑）。
2. 确定拓扑（第一性决策，选错后面全盘皆输）。
3. 筛选核心电气参数（电流、频率、效率、精度）。
4. 评估外围与系统代价（电感、电容、MOS、反馈、补偿）。
5. 核算成本与供货（单价 × 用量 × 生命周期可用性）。

**系统级硬约束清单**：

| 问题 | 决定什么 |
| --- | --- |
| 输入电压范围（含瞬态/浪涌） | 拓扑与耐压等级 |
| 输出电压/电流（稳态+峰值+瞬态斜率） | 电流能力与反馈方式 |
| 是否需要隔离 | 拓扑大类（非隔离/隔离） |
| 允许的最高环境温度与温升 | 热设计余量与封装 |
| 静态/待机功耗要求 | 是否必须低 Iq 或 Burst 模式 |

## 3. 拓扑是第一性决策

| 拓扑 | 输入/输出关系 | 典型场景 | 关键特点 |
| --- | --- | --- | --- |
| Buck（降压） | Vin > Vout | 12V→3.3V、5V→1.8V | 效率高、应用最广、无隔离 |
| Boost（升压） | Vin < Vout | 3.7V 锂电→5V/12V | 存在直通风险，需软启动 |
| Buck-Boost | Vin 跨 Vout 摆动 | 锂电 3.0~4.2V→3.3V | 输入跨输出时无掉压 |
| LDO（线性） | Vin > Vout，压差小 | 后级噪声敏感供电 | 无开关噪声，效率=Vo/Vin，大压差发热严重 |
| Flyback（反激） | 升降压+隔离 | AC-DC 辅助源、多路隔离 | 隔离、成本适中 |
| Charge Pump | 倍压/反压 | 小电流偏置 | 无电感、电流能力小 |

**经验规则**：压差小于 0.3~0.5 V 且电流较小时优先 LDO；输入输出存在交叉或大压差时上 Buck-Boost；效率优先且 Vin 恒大于 Vout 时用 Buck。

## 4. 九类核心参数判据

**输入/输出电压范围**：覆盖最坏情况（瞬态跌落/浪涌、热插拔尖峰、电池满充/放空），标称范围外留 10%~20% 余量。确认 UVLO 落在系统工作区间内，否则"低压不启动"或"误关断"。输出电压精度由反馈基准精度+电阻容差+调整率共同决定，注意区分初始精度与全温精度。

**输出电流能力（最易低估）**：区分平均电流、峰值电流、瞬态电流（负载阶跃）。芯片标称电流通常在 25 ℃ 特定条件下测得，实际按 60%~80% 降额，并核对降额曲线与封装热阻。过流保护点应高于系统最大峰值电流，否则误触发。大电流考虑多相 Buck 或并联均流。

**开关频率**：高频不总是"更先进"——效率、热、EMI 都会变差，除非体积是硬约束。

| 频率 | 优势 | 代价 |
| --- | --- | --- |
| 低（100 kHz~500 kHz） | 效率高、EMI 好处理 | 电感/电容体积大 |
| 中（500 kHz~1 MHz） | 体积与效率平衡 | 常规选择 |
| 高（1 MHz~3 MHz+） | 外围极小、瞬态响应快 | 开关损耗大、EMI 难、对布局敏感 |

**效率与损耗分解**：总损耗 ≈ 导通 + 开关 + 驱动 + 静态 + 电感/电容损耗。重载看导通损耗（I²R，与 RDS(on)、DCR 相关）；轻载看开关损耗与静态损耗，关注是否有 PSM/Burst/FCCM 模式切换；峰值效率点通常在中载，别只看满载。效率曲线（η-Iout）比单点效率更有参考价值。

**静态电流 Iq 与待机功耗**：电池产品必须关注 Iq（静态）与 Isd（关断）。微安级 Iq（<10 µA）是多节电池长期待机的关键；Iq 与轻载效率同向优化，但常与瞬态响应冲突。

**环路稳定性与补偿**：电流模式（CM）通常比电压模式（VM）补偿更简单、抗扰动更好；COT（恒定导通时间）瞬态响应快，但频率随工况变化，EMI 滤波设计更敏感；内部补偿省事但带宽受限，外部补偿灵活但需设计。关注相位裕度 ≥ 45°（目标 60°）及负载阶跃的过冲/下冲。

**保护功能清单**：

| 保护项 | 说明 | 是否必需 |
| --- | --- | --- |
| OCP 过流保护 | 逐周期限流 | 必需 |
| OVP 过压保护 | 输出过压关断 | 建议 |
| UVP 欠压保护 | 输出欠压告警/关断 | 建议 |
| OTP 过温保护 | 结温超限关断 | 必需 |
| 软启动 SS | 抑制启动浪涌 | 建议 |
| 输入 UVLO | 低压闭锁 | 必需 |
| 短路保护 Hiccup | 短路打嗝恢复 | 建议 |

**封装与热设计**：Tj = Ta + P_loss × RθJA，务必按实际功耗核算。小封装（SOT-23、DFN）散热差，大电流要选 QFN/带散热焊盘封装；关注散热焊盘（Thermal Pad）的 PCB 铺铜与过孔设计。

**EMI 与布局要点**：输入回路面积决定辐射 EMI，Cin 尽量贴近 VIN/GND；SW 节点走线短而粗（主要噪声源），避免大面积铺铜；电感选屏蔽型；反馈 FB 走线远离 SW 节点，从输出电容取样；必要时加 RC 吸收（Snubber）与输入 π 型滤波。

## 5. 关键参数速查与常见误区

| 参数 | 关注点 | 常见误区 |
| --- | --- | --- |
| Vin 范围 | 含瞬态与浪涌，留 10%~20% 余量 | 只按标称电压选 |
| Iout | 平均/峰值/瞬态三算，60%~80% 降额 | 只算平均电流 |
| Fsw | 体积 vs 效率 vs EMI 权衡 | 盲信"高频更好" |
| 效率 | 看 η-Iout 曲线，不只看峰值 | 只对比满载单点 |
| Iq | 电池产品关键，<10 µA 级 | 忽略轻载/待机 |
| 基准精度 | 全温精度而非仅初始精度 | 忽略温漂 |
| 环路 | 相位裕度 ≥ 45°（目标 60°） | 忽略瞬态过冲 |
| RθJA | 按实际功耗算结温 | 只看 25 ℃ 数据 |
| 保护 | OCP/OTP 必需，OVP/UVP 建议 | 缺保护裸跑 |
| 封装 | 大电流选带散热焊盘 | 封装与电流不匹配 |

**典型错误与对策**：

| # | 错误现象 | 对策 |
| --- | --- | --- |
| 1 | 按平均电流选型 → 峰值过流误保护 | 用峰值/瞬态电流选，留 20%~30% 裕量 |
| 2 | 忽略静态电流 → 待机功耗超标 | 电池产品把 Iq、Isd 列为一级指标 |
| 3 | 热计算缺失 → 高温满载降额后掉压 | 用 RθJA 正算结温，做 85 ℃ 验证 |
| 4 | 拓扑不匹配 → 输入交叉时输出塌陷 | Vin/Vout 存在交叉必选 Buck-Boost |
| 5 | 反馈走线受扰 → 输出振荡或精度差 | FB 远离开关节点，就近取样 |
| 6 | 输入电容不足/过远 → 辐射 EMI 超标 | Cin 紧贴 VIN/GND，选低 ESR |
| 7 | 忽略软启动 → 启动瞬间拉低输入 | 大容性负载必查 SS 与启动电流能力 |
| 8 | 只看单价 → 总成本失控 | 按 BOM 综合成本（含外围+PCB+调试）评估 |

## 6. 场景化选型建议

| 应用场景 | 推荐拓扑 | 关键指标优先级 |
| --- | --- | --- |
| 消费电子主板（12V→多路低压） | 多路 Buck | 效率、瞬态、路数集成度 |
| 锂电池便携设备 | Buck / Buck-Boost | Iq、轻载效率、封装体积 |
| 可穿戴 / 耳戴 | 高频 Buck + LDO | 静态电流、外围体积极小 |
| 工业控制（宽压 9~36V） | 宽输入 Buck | 耐压、EMI、保护完备 |
| 通信 / 服务器（大电流） | 多相 Buck | 电流能力、效率、热 |
| 汽车电子 | 宽压 Buck（≥40V 耐压） | 耐压、EMI、AEC-Q100 |
| 隔离辅助电源 | Flyback | 隔离电压、成本 |
| ADC/DAC 模拟供电 | Buck + LDO 级联 | 低噪声、PSRR |

## 7. 选型检查清单

选型评审时逐项勾选，任一项不可确认即需补充验证：

- 输入电压范围是否覆盖瞬态/浪涌，并留有余量？
- 输出电流是否按峰值/瞬态核算，并做了降额？
- 拓扑是否与 Vin/Vout 关系匹配？
- 开关频率是否兼顾了体积、效率与 EMI？
- 效率曲线是否满足各负载点要求？
- 静态电流/待机功耗是否达标（电池产品必查）？
- 基准精度是否满足全温要求？
- 环路补偿方式是否合适，相位裕度是否达标？
- 保护功能（OCP/OTP/OVP/UVP/SS/UVLO）是否齐备？
- 封装与 RθJA 是否满足热设计（含散热焊盘）？
- EMI 与布局是否可控（输入回路、SW 节点、屏蔽电感）？
- 外围 BOM 体积与成本是否可接受？
- 供货周期、生命周期、替代料是否落实？

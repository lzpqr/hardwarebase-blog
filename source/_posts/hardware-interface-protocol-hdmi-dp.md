## 一、文档目的与适用范围

本文档规定硬件产品中对外音视频输出接口 HDMI 与 DisplayPort 的信号定义、速率与版本选择、连接器形态、协议与内容保护机制、连接与输出流程、PCB 布局与防护、兼容性测试验证要求，作为原理图设计、PCB 设计、器件选型与整机联调的通用依据。

适用范围：产品对外连接电视、显示器、投影仪与扩展设备的音视频输出接口，含通过多功能接口（如 USB Type-C）复用输出的显示模式。HDMI 与 DisplayPort 的授权与认证流程、音视频编解码算法实现不在本文档范围内；具体发送芯片、接收器件与线缆的电气参数以对应数据手册和规范为准。

## 二、接口概述

HDMI 与 DisplayPort（DP）是当前对外音视频输出的两大主流，二者在定位上有清晰分工，设计时通常不是二选一，而是按产品定位决定支持哪种或两种都支持：

- **HDMI 面向消费电子**：起源于电视与影音设备生态，支持 CEC（消费电子控制）、eARC 音频回传与内容保护，是电视、机顶盒、游戏设备的绝对主流。
- **DisplayPort 面向计算设备**：起源于计算机显示生态，原生支持多流传输（MST）与菊花链，可通过 USB-C 复用输出，是显示器、显卡与扩展坞的主流。
- **视频与音频合一**：两者都在同一条链路上传输视频、音频与辅助数据，不需要独立的音频线缆。
- **都支持内容保护（HDCP）**：受版权保护的内容播放时需要完成认证与加密，认证失败会表现为无画面或降分辨率。
- **都依赖 EDID**：源端通过读取显示器的 EDID 获得支持的分辨率与时序，这一过程不通就无法输出。
- **版本与命名混乱**：两者都有多个版本与多个速率档位，且存在"版本号"与"实际支持特性"不一致的市场情况，选型时应以具体支持的分辨率、刷新率与特性为准。
- **都对线缆敏感**：高速率下线缆成为链路的主要瓶颈，长线缆往往需要主动（有源）器件。

硬件设计上最大的区别有两点：HDMI 的视频通道（TMDS）采用直流耦合并在源端上拉，DP 的主链路采用交流耦合；DP 有独立的 AUX 用于链路管理与多流，HDMI 用 DDC 与 CEC 完成相应功能。

## 三、物理层设计

两种接口的引脚构成差异较大，但设计关注点相同：高速差分通道的完整性、辅助通道的可靠性、以及对外的防护。

### （一）HDMI 信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| TMDS 数据 0/1/2 差分对 | 源 → 接收 | 三条视频数据通道，承载编码后的像素与控制数据 |
| TMDS 时钟差分对 | 源 → 接收 | 像素时钟，接收端据此恢复数据 |
| DDC（时钟与数据） | 双向 | I2C 兼容的显示数据通道，用于读取 EDID |
| CEC | 双向 | 消费电子控制，单线总线，用于设备间联动控制 |
| HPD | 接收 → 源 | 热插拔检测，显示器告知源端已接入 |
| +5V | 源 → 接收 | 为接收端提供小电流电源，用于其待机与 EDID 供电 |
| Utility / HEAC | 双向 | 可选，用于以太网通道与增强音频回传 |

HDMI 2.0 及以前使用 TMDS 传输；HDMI 2.1 在高速模式下改为 FRL（固定速率链路，基于 8 条 PAM 差分线）。HDMI 的视频通道在源端上拉至 3.3V 并采用直流耦合，因此连接器的电源引脚与信号上拉必须按规范设计，缺失上拉会导致接收端无法识别信号。

### （二）DisplayPort 信号定义

| 信号 | 方向 | 说明 |
| --- | --- | --- |
| Main Link 0~3 差分对 | 源 → 接收 | 四条高速单向通道，通道数可为 1/2/4 |
| AUX+ / AUX− | 双向 | 辅助通道，半双工，用于 EDID 读取与链路管理 |
| HPD | 接收 → 源 | 热插拔检测，兼作接收端中断请求 |
| CONFIG1 / CONFIG2 | 配置 | 用于接口复用与模式选择，复用输出时必须正确处理 |
| +3.3V | 源 → 接收 | 为接收端或转换器提供电源 |

### （三）速率与版本对照

| 接口与版本 | 总带宽量级 | 编码方式 | 典型能力 |
| --- | --- | --- | --- |
| HDMI 1.4 | 约 10.2 Gbps | TMDS | 4K 低帧率、3D、音频回传 |
| HDMI 2.0 | 约 18 Gbps | TMDS | 4K 高帧率、高动态范围 |
| HDMI 2.1 | 约 48 Gbps | FRL | 8K、高刷新率、VRR、eARC |
| DisplayPort 1.2 | 约 21.6 Gbps | 8b/10b | MST、菊花链 |
| DisplayPort 1.4 | 约 32.4 Gbps | 8b/10b | HDR、DSC 显示流压缩 |
| DisplayPort 2.x | 最高约 80 Gbps | PAM3/PAM4 编码 | 超高分辨率与刷新率 |

实际可支持的分辨率与刷新率取决于带宽、色深与压缩能力的组合，不能只看版本号。设计时应列出产品必须支持的具体分辨率与刷新率清单，反推所需带宽与版本。

### （四）连接器形态

- **HDMI**：标准型（A）、小型（C，Mini）与微型（D，Micro）三种，另有车载型。选型应考虑插拔寿命、机械强度与空间限制。
- **DisplayPort**：标准型与小型（Mini）两种，后者在轻薄设备上常见。
- **接口复用输出**：通过 USB-C 输出显示信号时，需要高速复用器（Retimer/MUX）与正确的 CC/配置引脚处理，并完整实现 Alt Mode 协商。
- **线缆与转换**：有源与无源线缆、转换器（Active/Passive）与扩展坞都会改变链路特性，兼容性测试必须覆盖这些组合。

### （五）拓扑结构

- **点对点直连**：源端接一台显示设备，最常见。
- **MST 与菊花链**：DP 支持一条链路驱动多台显示设备（Daisy-chain），需显示设备支持并正确配置。
- **分配与切换**：HDMI 通过外部分配器或切换器实现多设备连接，需注意其对 HDCP 与 EDID 的影响。
- **接口复用与转换**：在 USB-C 复用或协议转换场景下，整条链路的插损与协商流程都要重新评估。

### （六）端接与阻抗

- **差分阻抗**：两类接口的视频通道均按 100Ω 设计，需按叠层计算线宽线距。
- **HDMI 上拉**：视频通道在源端上拉至 3.3V，接收端内部端接；板上不应额外并联端接电阻。
- **DP 耦合**：主链路采用交流耦合，电容容值符合规范并靠近发送端放置。
- **禁止滤波元件**：高速通道上不得并联电容或磁珠。

## 四、协议层设计

两类接口的协议都不需要硬件实现，但排查"无信号""分辨率不对""没有声音"这三类问题，必须理解数据组织方式与握手流程。

### （一）HDMI 的三种传输周期

| 周期 | 承载内容 | 说明 |
| --- | --- | --- |
| 视频数据周期 | 有效像素 | 传输编码后的像素数据 |
| 数据岛周期 | 音频与辅助数据 | 承载音频采样与信息帧（INF） |
| 控制周期 | 控制与同步 | 消隐期间传输同步与控制信息 |

三类周期在时间上交替出现，因此视频与音频天然同步，不需要外部时钟对齐。

### （二）信息帧（INF）

| 信息帧 | 作用 | 常见影响 |
| --- | --- | --- |
| AVI | 声明色彩空间、色深与扫描方式 | 错误会造成颜色异常或黑屏 |
| 音频信息帧 | 声明声道数与采样率 | 错误会造成无声或声道错乱 |
| SPD | 声明厂商与产品信息 | 部分显示设备据此切换模式 |
| HDR 帧 | 声明动态范围与传递函数 | 错误会造成画面过曝或偏暗 |

### （三）内容保护（HDCP）

- **认证与密钥交换**：源端与显示设备完成身份认证（基于 RSA 公钥的链路密钥协商）并交换会话密钥。
- **链路加密**：认证通过后视频数据被加密传输，接收端解密显示。
- **失败处理**：认证失败时通常不输出画面或降为低分辨率输出，这是"能亮但播放不了受保护内容"的典型原因。
- **中继设备影响**：分配器、切换器与转换器都参与 HDCP，任一环节不兼容都会导致失败。

### （四）CEC 与音频回传

- **CEC（HDMI）**：一条低速单线总线，支持多设备联动（如一键开机、统一音量）。硬件上需按要求配置上拉，并在多设备共存时避免地址冲突。
- **ARC / eARC**：允许显示设备把音频回传给源端或音响设备，需要链路中的相关通道与引脚支持；eARC 带宽更高，支持对象音频（Dolby Atmos 等）。

### （五）EDID 与链路管理（DP）

- **EDID**：源端通过 DDC（HDMI）或 AUX（DP）读取，获得支持的分辨率与时序。读取失败将无法输出，这是"无信号"的首要排查点。
- **链路训练**：DP 在输出前通过 AUX 完成链路训练，协商速率与通道数，必要时降级。
- **MST**：DP 可在一条链路上传输多路独立视频流，由接收端（MST Hub）拆分。
- **接口复用协商（Alt Mode）**：通过 USB-C 输出时，需先完成 CC 角色协商与高速通道切换，再按对应协议输出。

### （六）HDMI 与 DP 对比

| 对比项 | HDMI | DisplayPort |
| --- | --- | --- |
| 主要生态 | 电视与影音设备 | 计算机与显示器 |
| 视频通道 | 三条 TMDS 加独立时钟（2.1 为 8 线 FRL） | 一至四条通道，无独立时钟 |
| 耦合方式 | 直流耦合，源端上拉 | 交流耦合 |
| 辅助通道 | DDC + CEC | AUX 承担全部管理功能 |
| 多流与菊花链 | 不支持 | 支持（MST） |
| 接口复用输出 | 需转换 | 原生支持 Alt Mode |
| 典型选择 | 影音与电视类设备 | 计算机、显示器与扩展坞 |

## 五、连接与输出操作流程

从插入线缆到画面出现，中间要经过检测、读取、认证、训练、输出五步。任何一步失败都有对应的现象，理解流程是定位问题的基础。

### （一）连接检测与读取

1. 源端为接口提供 +5V（HDMI）或 +3.3V（DP）电源，接收端上电后驱动 HPD 有效。
2. 源端检测到 HPD，去抖后确认设备接入。
3. 源端通过 DDC/AUX 读取 EDID，获得支持的模式清单。
4. 若读取失败或超时，源端会反复重试，表现为长时间无信号。

### （二）模式选择与输出

1. 从 EDID 支持的模式中选定分辨率、刷新率与色深，优先选择设备的原生分辨率。
2. DP 侧完成链路训练，确定速率与通道数。
3. 按需完成 HDCP 认证与密钥交换。
4. 配置发送端的视频时序与音频参数，发送相应的信息帧。
5. 开始输出视频与音频，确认接收端锁定（HSync/VSync 锁存）。

### （三）热插拔与重新协商

HPD 的变化会触发源端重新读取 EDID 并重新协商。设计中应保证：拔线时不损坏接口、插线后能自动恢复输出、快速插拔不会导致系统卡死。软件端需对 HPD 做去抖与状态机处理。

### （四）音频输出

音频随视频在同一链路上传输，参数在音频信息帧中声明。设计要点是：确认接收端支持的声道与采样率、保证音频时钟与视频时钟的对应关系（采样时钟比）正确、避免音视频不同步。唇音同步偏差（Lip-sync offset）是可测量的指标，应在测试中量化。

### （五）模式切换与兼容处理

切换分辨率或刷新率通常需要重新配置发送端并可能重新训练。为提升兼容性，产品常需要维护一份兼容性策略：对已知存在问题的显示设备降级输出，或在 HDCP 失败时给出明确提示而不是黑屏。

## 六、硬件设计要点

对外音视频接口是产品上暴露程度最高的接口，防护与信号完整性同等重要。以下 12 条按此展开：

1. **差分阻抗控制**：视频通道按 100Ω 设计，线宽线距由叠层计算，制板说明中明确要求。
2. **等长匹配**：同一差分对内长度差要小；各通道之间的长度差应控制在允许范围内，通常按毫米量级核算。
3. **禁止跨分割**：高速通道下方保持完整参考平面，换层处增加回流地过孔。
4. **减少过孔与转接**：从发送芯片到连接器尽量走直线，减少过孔与连接器转接，高速率下按需增加中继（Retimer）或重定时器件。
5. **HDMI 上拉与电源**：视频通道按规范上拉至 3.3V；接口的 +5V 电源需具备规范要求的供电能力（100mA 级）并配置过流保护。
6. **DP 耦合电容**：主链路交流耦合电容容值符合规范，靠近发送端放置。
7. **AUX 与 HPD**：按规范配置上拉下拉与限流，走线短且远离高速通道与噪声源。
8. **ESD 与浪涌防护**：对外接口必须配置低结电容的高速 ESD 防护器件（如 TVS 阵列），靠近连接器放置并保证低阻抗泄放路径，这是本接口最关键的可靠性措施。
9. **连接器选型与固定**：选用插拔寿命达标、带可靠机械固定与屏蔽结构的连接器，屏蔽层按整机接地策略处理。
10. **接口复用方案**：通过 USB-C 输出时，需完成高速 MUX/Retimer 选型、CC 电阻与配置引脚处理与整链路插损核算。
11. **远离干扰源**：高速通道远离开关电源、电感与射频天线；同时评估其对无线接收灵敏度的影响。
12. **可测性与预留**：预留高速通道、AUX/CEC 与 HPD 的测试点；为后续一致性（compliance）认证测试预留必要的接入方式。

## 七、典型应用场景

| 应用对象 | 典型接口 | 设计关注点 |
| --- | --- | --- |
| 电视与机顶盒 | HDMI 输出 | 版本与特性支持、HDCP、CEC 联动 |
| 显示器与显卡 | DP + HDMI | MST 与菊花链、高刷新率、线缆兼容性 |
| 笔记本与扩展坞 | USB-C 复用输出 | 复用器选型、Alt Mode 协商流程、供电与充电共存 |
| 投影与会议设备 | HDMI 输入与输出 | 长线缆均衡、热插拔稳定性、兼容性策略 |
| 嵌入式与工控显示 | HDMI 或 DP | 防护等级、宽温稳定性、长期可靠性 |
| 车载影音 | HDMI 车载型 | 连接器机械可靠性、屏蔽与接地、线缆固定 |
| 虚拟现实与高刷设备 | 高版本接口 | 带宽核算、压缩能力、时延与刷新率 |

## 八、可靠性与测试验证

对外音视频接口最大的风险是兼容性——同一台产品在用户家里可能接上几十种显示设备。因此验证重点是兼容性矩阵与热插拔可靠性。

### （一）常见故障模式

| 故障现象 | 可能原因 | 排查建议 |
| --- | --- | --- |
| 完全无信号 | HPD 信号不通、EDID 读不到、接口电源缺失 | 测量接口电源电压与 HPD 电平；抓取 DDC/AUX 通信确认读取是否成功 |
| 分辨率识别错误 | EDID 解析错误、模式选择策略不当 | 读取并解析 EDID；核对首选模式与原生分辨率 |
| 画面闪烁或雪花 | 高速通道误码、线缆质量差、走线插损过大 | 更换已知良好的线缆；测眼图；核算插损 |
| 高分辨率下黑屏 | 带宽不足、线缆不支持、速率降级 | 确认链路当前速率；更换高速线缆；核对版本能力 |
| 有画面无声音 | 音频信息帧错误、接收端不支持该格式 | 核对音频参数与信息帧；改用通用格式（PCM）对比测试 |
| 声音与画面对不上 | 音视频时钟关系配置错误、处理时延过大 | 核对时钟配置；测量唇音同步偏差 |
| 播放受保护内容失败 | HDCP 认证失败、中继设备不兼容 | 核对认证流程；绕过中继设备直连对比测试 |
| 热插拔后不恢复 | HPD 去抖不当、状态机卡死 | 检查去抖与状态机；测试快速插拔场景 |
| 长线缆下掉画面 | 线缆插损超标、缺少中继或重定时 | 核算整链路插损；增加 Retimer；选用有源线缆 |
| 接口插拔后损坏 | ESD 防护不足、放电路径穿过芯片 | 防护器件靠近连接器；保证低阻抗泄放路径 |
| CEC 串扰 | 总线地址冲突、上拉缺失、多设备联动异常 | 核对上拉与地址分配；逐一接入设备定位 |

### （二）测试要点

- **信号质量**：在发送端按对应版本要求测量眼图、抖动与上升下降时间，确认满足模板要求。
- **兼容性矩阵**：覆盖多种品牌与尺寸的显示设备、多种线缆长度与类型、以及分配器与转换器，逐一记录结果。
- **分辨率遍历**：在产品支持的全部分辨率与刷新率下逐一验证画面与声音正常。
- **热插拔循环**：反复插拔数百次以上，确认每次都能正常识别与恢复，统计失败次数。
- **内容保护**：验证受保护内容的播放流程，包括直连与经过中继设备两种情况。
- **音视频同步**：测量唇音同步偏差，确认在可接受范围内。
- **长线缆**：在产品设计支持的最大线缆长度下验证高分辨率输出稳定。
- **ESD 与浪涌**：对接口做接触与空气放电测试，确认不损坏且能自动恢复。
- **长时间播放**：连续播放数小时，确认无闪屏、无掉画面、无声音中断。
- **高低温**：在极限温度下重复关键测试，确认不降级、不掉画面。

## 九、设计检查清单

1. 已确定支持的接口类型与版本，并列出必须支持的分辨率与刷新率清单。
2. 已按清单反推所需带宽，确认版本与通道数满足要求并留有裕量。
3. 高速通道已按 100Ω 设计，制板说明中已注明阻抗控制要求。
4. 通道内与通道间长度匹配已核算，未跨平面分割，换层处已加回流地过孔。
5. 从发送芯片到连接器的过孔与转接已最小化，高速率方案已评估是否需要 Retimer。
6. HDMI 的视频通道上拉与 +5V 电源供电能力已按规范设计，并配置过流保护。
7. DP 主链路的交流耦合电容容值符合规范且靠近发送端。
8. AUX、DDC 与 HPD 信号的上拉下拉与限流已按规范配置。
9. 已配置低结电容的 ESD 与浪涌防护器件，且靠近连接器放置。
10. 连接器插拔寿命、机械固定与屏蔽接地已确认。
11. 接口复用输出方案已完成 MUX/Retimer 选型、配置引脚处理与插损核算。
12. 高速通道已远离干扰源，并评估了对无线接收灵敏度的影响。
13. 高速通道、AUX 与 HPD 信号已预留测试点。
14. 眼图与抖动测试满足对应版本要求。
15. 兼容性矩阵测试已覆盖足够多的显示设备、线缆与中继组合。
16. 全部支持的分辨率与刷新率已逐一验证。
17. 热插拔循环测试通过，失败率为零。
18. HDCP 播放流程在直连与中继两种场景下均已验证。
19. ESD 与浪涌测试通过，长时间播放稳定。
20. 高低温条件下的关键测试已复测通过。

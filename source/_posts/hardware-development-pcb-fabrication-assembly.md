原理图决定电路能不能工作，PCB 设计决定电路能不能稳定工作，而制板与贴片决定产品能不能被稳定制造出来。

很多在实验室表现良好的设计，一旦进入打样或量产，就会暴露出一连串问题：孔无铜、阻抗偏差、板面翘曲、BGA 空洞、立碑、连锡和批量虚焊，最终导致交期延误和成本失控。

制板与贴片是典型的“细节决定成败”环节。一份设计文件可能包含上百个参数，任何一个参数理解偏差，都会在实物上被放大。

对硬件工程师而言，理解制板与贴片工艺，不是为了替代工艺工程师，而是为了让设计真正做到可制造、可检验、可追溯。

> 本文是硬件开发流程系列的第六篇。建议先阅读 [PCB 设计篇](/posts/hardware-development-pcb-design/) 和 [原理图设计篇](/posts/hardware-development-schematic-design/)。

## 先理解整体流程

### PCB 制板主要流程

以多层硬板为例，典型流程包括：

| 序号 | 工序 | 关键控制点 |
| --- | --- | --- |
| 1 | 开料 | 板材、铜厚、板厚和尺寸 |
| 2 | 内层图形转移 | 曝光、显影和线宽精度 |
| 3 | 内层蚀刻 | 蚀刻因子和线宽公差 |
| 4 | 内层检验 | 开路、短路和缺口 |
| 5 | 层压 | 对位精度、介质厚度和翘曲 |
| 6 | 钻孔 | 孔径、孔位和孔壁质量 |
| 7 | 孔金属化与电镀 | 孔壁铜厚和深镀能力 |
| 8 | 外层图形转移 | 对位、线宽和线距 |
| 9 | 外层蚀刻与检验 | 线路完整性 |
| 10 | 阻焊 | 阻焊桥、附着力和厚度 |
| 11 | 字符 | 清晰度、位置和附着力 |
| 12 | 表面处理 | 厚度、可焊性和外观 |
| 13 | 成型与拼板 | 外形精度和分板方式 |
| 14 | 电测与终检 | 通断、阻抗和外观 |

理解流程的意义，是在出现异常时能够判断问题出在哪一道工序，而不是笼统归因于“板厂质量不好”。

### SMT 贴片主要流程

| 序号 | 工序 | 关键控制点 |
| --- | --- | --- |
| 1 | 来料检验 | 型号、批次、包装和湿度 |
| 2 | 物料烘烤 | 湿敏器件烘烤条件 |
| 3 | 锡膏准备 | 冷藏、回温和搅拌 |
| 4 | 锡膏印刷 | 厚度、均匀性和偏移 |
| 5 | SPI 检测 | 锡膏体积、面积和高度 |
| 6 | 贴片 | 精度、压力和方向 |
| 7 | 回流焊 | 温度曲线、峰值温度和冷却 |
| 8 | AOI 检测 | 缺件、偏移、极性和焊接 |
| 9 | X-Ray 检测 | BGA、QFN 等隐藏焊点 |
| 10 | 插件与波峰焊 | 治具、阴影效应和透锡 |
| 11 | 电气测试 | ICT、FCT 和烧录 |
| 12 | 清洗与三防 | 残留、防护和固化 |
| 13 | 终检与包装 | 外观、标识和追溯 |

### 责任边界

制板与贴片涉及硬件工程师、PCB 设计者、板厂、贴片厂、元器件供应商和测试部门。

必须明确：

- 谁负责文件完整性和版本正确性；
- 谁负责工程确认和工艺问题反馈；
- 谁负责来料质量和物料替代确认；
- 谁负责首件确认和批量放行；
- 谁负责异常处理和不良品分析。

责任边界不清，最容易出现“出了问题互相等”的情况。

## 1. 设计文件与生产资料准备

投板和贴片前，应准备完整资料。

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| Gerber | 铜箔、阻焊、字符和成型 | 制板图形 |
| 钻孔文件 | 孔径、孔位和金属化属性 | 钻孔加工 |
| 叠层文件 | 层结构、材料、铜厚和介质厚度 | 层压与阻抗 |
| 阻抗报告 | 目标阻抗、线宽线距和测试要求 | 阻抗控制 |
| 拼板文件 | 拼板方式、工艺边和定位孔 | 生产拼板 |
| 坐标文件 | 器件坐标、角度和位号 | 贴片编程 |
| 钢网文件 | 钢网开孔、厚度和工艺 | 锡膏印刷 |
| BOM | 型号、位号、数量和替代料 | 物料与贴装 |
| 装配图 | 器件位置、极性和方向 | 装配与检验 |
| 测试要求 | 测试点、检验标准和烧录要求 | 电气测试 |

### 文件格式与命名

- Gerber 常用 RS-274X 格式；
- 钻孔文件常用 Excellon 格式；
- 文件名包含产品名、板名、版本、层别和日期；
- 同一项目的文件打包成统一版本；
- 坐标文件的原点和单位必须与装配图一致。

### 工程确认（EQ）

板厂通常会发起工程确认，需要重点关注：

- 最小线宽线距和最小孔径是否超出能力；
- 孔到铜、孔到板边和铜到板边间距；
- 阻焊桥是否过窄；
- 阻抗设计是否需要调整叠层或线宽；
- 拼板、工艺边和分板方式是否合理；
- 表面处理和板厚是否一致；
- 背钻、塞孔、盲埋孔等特殊工艺是否可实现。

EQ 回复需要由了解设计意图的工程师确认。

### 版本控制

设计文件、生产文件、BOM 和装配图必须使用同一版本。每次变更都要有变更单、影响范围说明，并重新确认首件。

## 2. PCB 制板关键工艺

### 开料与板材

- 常用板材为 FR-4；
- 高温或无铅焊接场景可使用高 Tg 板材；
- 高频高速产品可使用低损耗材料；
- 铜厚常用 1oz 和 2oz；
- 玻纤布类型、板厚和层数会影响性能与加工能力。

### 内层图形与蚀刻

曝光、显影和蚀刻共同决定线宽精度。铜厚越大，蚀刻侧蚀越明显，线宽公差越难控制。内层检验重点检查开路、短路、缺口和残铜。

### 层压与对位

层间对位精度直接影响过孔连接的可靠性。介质厚度决定阻抗和耐压，叠层不对称容易导致翘曲，填胶不足可能造成分层和空洞。

### 钻孔与孔金属化

机械钻孔适用于常规孔径，激光钻孔适用于微小孔和盲孔。厚径比过大增加孔壁电镀难度。

孔壁铜厚是关键可靠性指标，深镀能力不足会导致孔中央铜薄甚至无铜。背钻可用于去除高速过孔残桩，但需要控制深度精度。

### 外层线路、阻焊与字符

外层线路决定焊接和载流能力。阻焊层保护线路并防止短路，阻焊桥过窄容易脱落。字符油墨必须清晰，不能覆盖焊盘、测试点和金手指。

### 表面处理

| 类型 | 特点 | 适用场景 |
| --- | --- | --- |
| 喷锡 HASL | 成本低、可焊性好、表面不平整 | 常规插件和低成本产品 |
| 无铅喷锡 | 环保、耐高温、表面较不平整 | 无铅焊接产品 |
| 沉金 ENIG | 表面平整、适合细间距 | BGA、细间距和高可靠性 |
| OSP | 成本低、平整、保存期短 | 一次性回流产品 |
| 沉银/沉锡 | 平整、可焊性好、需控制存储 | 细间距和高速板 |
| 硬金 | 耐磨、接触电阻低 | 金手指和连接器触点 |

### 成型、拼板与电测

- 铣板、V-cut 和邮票孔是常见分板方式；
- 拼板需要考虑利用率、分板方向和设备能力；
- 工艺边宽度和定位孔满足产线要求；
- 飞针测试适合小批量，测试架适合大批量；
- 阻抗测试条和切片分析用于验证关键参数。

## 3. 制板工艺能力与设计匹配

### 常见工艺参数

| 参数 | 常见范围 | 注意事项 |
| --- | --- | --- |
| 最小线宽/线距 | 4/4 mil 至 6/6 mil | 越小成本越高 |
| 最小机械孔径 | 0.2mm 至 0.3mm | 受板厚和厚径比限制 |
| 最小环宽 | 0.05mm 以上 | 过小影响可靠性 |
| 厚径比 | 常见小于 10:1 | 越大电镀越难 |
| 板厚公差 | 约 ±10% | 高精度需求需单独确认 |
| 阻焊桥 | 0.08mm 以上 | 与工艺和油墨有关 |
| 铜到板边 | 0.2mm 以上 | 防止露铜和破损 |

以上数值仅作为常见参考，实际能力必须以板厂工艺能力表为准。

### 载流能力

走线载流能力与铜厚、线宽和允许温升相关。大电流路径优先使用大面积铜皮和多过孔，必要时采用 2oz 铜、开窗加锡或铜排。

### 常见制板缺陷

| 缺陷 | 可能原因 |
| --- | --- |
| 开路 | 蚀刻过度、划伤或显影不良 |
| 短路 | 蚀刻不足、残铜或阻焊缺陷 |
| 孔无铜 | 孔金属化不良或深镀能力不足 |
| 孔壁铜薄 | 电镀参数不当或厚径比过大 |
| 分层起泡 | 层压不良、吸潮或材料不匹配 |
| 白斑白圈 | 玻纤布浸渍不良或热应力 |
| 翘曲 | 叠层不对称、铜分布不均或热应力 |
| 金脆黑盘 | 沉金工艺控制不良 |
| 阻抗偏差 | 叠层、线宽或介电常数波动 |
| 阻焊脱落 | 附着力不足或表面污染 |

## 4. 生产前的可制造性评审

投板前建议由工艺和硬件共同评审：

- 线宽线距、孔径和环宽是否满足板厂能力；
- 阻焊桥、字符和开窗是否合理；
- 叠层是否对称，阻抗是否可制造；
- 拼板、工艺边和分板方式是否合理；
- 表面处理是否与焊接工艺和存储条件匹配；
- 特殊工艺是否明确并已确认可行；
- 关键尺寸和公差是否体现在生产文件中。

评审结论应形成记录，并对问题逐项闭环。## 5. 贴片（SMT）关键工艺

### 来料与仓储

- 核对器件型号、规格、批次和包装完整性；
- 湿敏器件按 MSL 等级管理，必要时烘烤；
- 落实 ESD、防潮和防氧化要求；
- 锡膏冷藏保存，使用前回温，避免结露；
- 超过保存期或开封过久的物料需评估后使用。

### 锡膏和钢网

- 根据工艺选择有铅或无铅锡膏；
- 关注合金成分、粉末粒度、助焊剂活性和残留；
- 钢网厚度常用 0.1mm 至 0.15mm；
- 开孔面积比和宽厚比要满足工艺要求；
- 细间距器件可采用激光切割和电抛光；
- 大焊盘需要控制锡量和防锡珠设计。

### 锡膏印刷与 SPI

印刷压力、速度、脱模速度和清洗频率都会影响质量。需要控制锡膏厚度、面积和偏移，并使用 SPI 监控趋势。

印刷不良的板应清洗后重印，避免反复污染。

### 贴片

- 贴装精度满足最小器件和细间距要求；
- 吸嘴和供料器状态影响抛料和偏移；
- 元件极性、方向和位置必须准确；
- 贴装压力过大会导致锡膏塌陷和元件损伤；
- 首件确认关键器件方向和位置。

### 回流焊

回流曲线包括预热、保温、回流和冷却。峰值温度和液相以上时间要满足锡膏和器件要求。

升温过快会导致立碑、气孔和热冲击。不同板厚和热容需要分别优化曲线。双面回流时还要注意第二面的器件掉落风险。

### 波峰焊与选择焊

波峰焊适用于插件和混装工艺，治具设计影响阴影效应和透锡率。选择焊适用于局部插件和热敏感器件。焊接后检查透锡、桥连和虚焊。

### 焊接质量检测

| 方式 | 用途 | 局限 |
| --- | --- | --- |
| 目视检查 | 外观、缺件、偏移和极性 | 无法检查隐藏焊点 |
| AOI | 在线自动检测焊接和贴装 | 对 BGA 内部无效 |
| X-Ray | 检查 BGA、QFN 和空洞 | 成本较高，判读依赖经验 |
| 首件确认 | 确认方向和关键焊点 | 需要人工参与 |
| 切片分析 | 分析焊点内部结构 | 破坏性检测 |

### 清洗、返修与三防

- 免清洗工艺需确认残留满足要求；
- 水洗工艺需控制清洗剂、温度和干燥；
- 返修要控制温度和次数；
- 三防漆用于防潮、防腐蚀和防霉；
- 连接器和接触件应避免被三防漆污染。

### 常见贴片缺陷

| 缺陷 | 可能原因 |
| --- | --- |
| 立碑 | 两端受热不均、焊盘不当或锡量不均 |
| 连锡 | 锡量过多、间距过小或钢网开孔不当 |
| 虚焊假焊 | 氧化、助焊剂不足或温度不足 |
| 少锡 | 钢网堵塞、锡膏不足或印刷不良 |
| 偏移 | 贴装精度不足、锡膏塌陷或回流扰动 |
| 气孔 | 助焊剂挥发、预热不足或表面污染 |
| 锡珠 | 锡膏飞溅、印刷偏移或钢网清洗不足 |
| BGA 空洞 | 助焊剂残留、回流不足或焊盘氧化 |
| 元件开裂 | 热应力、机械应力或受潮 |
| 极性反 | 来料方向、编程错误或首件缺失 |

## 6. 特殊器件与工艺

### BGA、CSP、QFN 和 LGA

- 焊盘尺寸和钢网开孔按器件规范设计；
- 回流曲线保证焊球充分熔融且不损伤器件；
- X-Ray 检查空洞率和焊点形态；
- QFN 散热焊盘需要足够过孔和锡量；
- LGA 对共面度和印刷精度要求更高。

### 小尺寸器件

01005、0201 等小器件对贴装精度和钢网质量要求高，需要注意抛料率、立碑和偏移问题。

### 连接器、屏蔽罩和散热器

- 连接器需确认共面度、插拔力和焊接方式；
- 屏蔽罩焊接和接地要连续；
- 散热器和导热垫的装配顺序、压力要控制；
- 大质量器件需评估回流时的位移和掉落风险。

### 混装与柔性板

有铅无铅混装需评估温度兼容性和可靠性。柔性板需控制弯折区域和补强设计，刚柔结合板的层压、钻孔和外形加工更复杂。

## 7. 质量控制与检验

### 常用标准

| 标准 | 内容 |
| --- | --- |
| IPC-A-600 | PCB 外观允收标准 |
| IPC-6012 | 刚性板性能规范 |
| IPC-A-610 | 电子组装件允收标准 |
| IPC J-STD-001 | 焊接工艺要求 |
| IPC-7351 | 焊盘图形设计标准 |
| IPC-2221 | PCB 设计通用标准 |

### 检验项目

- 来料检验：型号、批次、外观、包装和湿度；
- 过程检验：印刷、贴装、回流和波峰焊关键参数；
- 成品检验：外观、焊接、功能、尺寸和标识；
- 可靠性检验：温循、热冲击、振动、跌落、湿热和盐雾。

### 首件与追溯

首件是批量生产的基准，必须严格确认器件型号、方向、极性和焊点质量。

通过批次号、二维码或序列号实现物料和工艺追溯，并记录锡膏批次、钢网版本、回流曲线和设备参数。

## 8. 供应链与生产管理

### 板厂和贴片厂评估

- 工艺能力是否匹配产品需求；
- 质量体系和认证是否齐全；
- 交期、产能和响应速度是否稳定；
- 是否具备阻抗控制、盲埋孔和背钻等特殊工艺能力；
- 是否具备不良分析和追溯体系。

### 成本和交期

PCB 成本与层数、面积、板材、线宽线距、孔径和表面处理相关。SMT 成本与点数、器件种类、钢网、测试和返修率相关。

关键长交期物料应提前备料，并预留工程确认、首件确认和异常处理时间。

### 变更管理

设计变更、物料变更和工艺变更都要走变更流程，评估对电性能、结构、可靠性和成本的影响。变更后的首件和验证必须重新确认。## 9. 试产与量产过渡

### 打样、小批与量产

- 打样验证设计功能和工艺可行性；
- 小批验证良率、工艺稳定性和测试方案；
- 量产验证产能、成本和一致性；
- 每个阶段都应有明确的放行标准。

### 良率和工艺能力

- 统计关键工序良率和不良分布；
- 对关键尺寸和参数评估工艺能力指数 CPK；
- 对重复出现的问题进行根本原因分析；
- 通过 DOE 优化工艺窗口，而不是简单调参。

### 常见量产问题

| 问题 | 可能原因 | 对策 |
| --- | --- | --- |
| 批量虚焊 | 锡膏、钢网和回流曲线 | 优化印刷和曲线，加强 SPI |
| BGA 空洞偏高 | 助焊剂、焊盘和回流 | 优化开孔和曲线，控制来料 |
| 立碑增多 | 焊盘和锡量不均 | 优化焊盘和钢网设计 |
| 阻抗超差 | 叠层和线宽波动 | 与板厂确认叠层和补偿 |
| 板翘曲 | 叠层不对称、热应力 | 优化叠层和层压参数 |
| 交期延误 | 物料、产能和异常 | 提前备料，建立升级机制 |

## 10. 常见问题速查

| 现象 | 优先排查方向 |
| --- | --- |
| 焊点发黑、不润湿 | 焊盘氧化、表面处理和助焊剂 |
| 连续多板同一位置失效 | 钢网、焊盘、器件或工艺参数 |
| 首件合格、批量不良 | 过程稳定性、物料批次和设备漂移 |
| X-Ray 可见空洞 | 回流曲线、助焊剂和焊盘设计 |
| 板面局部起泡 | 吸潮、层压或阻焊工艺 |
| 阻抗测试不合格 | 叠层、线宽和材料介电常数 |
| 分板后器件开裂 | 分板应力、器件位置和拼板设计 |

## 11. 制板与贴片的四个层次

1. 会做：能把文件交给板厂和贴片厂，做出样品；
2. 会控：能控制关键工艺参数，保证批次一致；
3. 会防：能预见缺陷风险，提前优化设计和工艺；
4. 会管：能管理供应链、交期、成本和追溯，实现稳定量产。

从“会做”到“会管”，靠的不是单点技巧，而是标准化流程、量化数据和持续的问题闭环。

## 附录 A：制板与贴片检查清单

### 生产资料

- Gerber、钻孔、叠层和阻抗文件完整且版本一致；
- 拼板、坐标、钢网和装配图正确；
- BOM 与设计文件一致，替代料已确认；
- 工程确认问题已全部闭环。

### 制板

- 线宽线距、孔径和环宽满足板厂能力；
- 叠层对称，阻抗可制造并已确认；
- 表面处理与焊接工艺、存储条件匹配；
- 拼板和分板方式合理，应力可控；
- 电测和阻抗测试要求明确。

### 来料与仓储

- 物料型号、批次和包装核对无误；
- 湿敏器件按 MSL 等级管理；
- 锡膏冷藏、回温和使用时间受控；
- ESD 和防潮措施落实。

### 贴片工艺

- 钢网开孔和厚度满足工艺要求；
- 锡膏印刷厚度和均匀性受控；
- 贴装精度和元件方向正确；
- 回流曲线经过验证；
- 波峰焊治具和透锡质量满足要求。

### 检验与量产

- 首件确认完成并保留记录；
- AOI、X-Ray 等检测覆盖关键焊点；
- 外观和功能检验标准明确；
- 不良品分析和追溯机制有效；
- 试产良率和工艺能力满足量产要求；
- 设计、物料和工艺变更受控。

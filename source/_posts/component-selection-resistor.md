电阻是电路中使用频率最高的元件，也是最容易被"随手选一个"的元件。实际上，一颗看似简单的电阻，其失效可能直接导致信号失真、精度漂移、系统功耗异常甚至整机热失效。

本文是「硬件产品器件选型」系列的电阻篇，目标不是罗列参数，而是建立一套"先定功能、再定约束、后定型号"的工程流程，让每一次电阻选型都有据可查、可复现。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。

## 1. 为什么电阻选型需要系统方法

电阻的问题通常不是"选错型号"，而是选型时遗漏了某一个约束维度。工程上常见的事故模式包括：

- **功率余量不足**：实际功耗长期超过额定值，电阻本体持续高温，阻值漂移加速，最终开路。
- **温漂被忽略**：常温标定时精度很好，整机温度升高后采样误差超出规格。
- **电压/浪涌超限**：上电瞬间的浪涌电压超过最大工作电压，形成沿面闪络或膜层击穿。
- **封装机械应力**：大封装贴片电阻在板弯或温度循环下开裂，形成间歇性开路，最难排查。
- **精度选得过高或过低**：过高造成成本浪费，过低使电路无法满足指标，二者都需要通过误差预算来界定。

因此，电阻选型本质上是一套系统流程，而不是在电商平台上按阻值筛选。

## 2. 电阻的功能分类

从电路功能出发，电阻的使用场景可归为以下几类，不同功能对应的选型关注点差异很大：

| 功能类别 | 典型位置 | 选型核心关注点 |
| --- | --- | --- |
| 限流/分压 | LED 限流、基准分压、偏置网络 | 精度、温漂、阻值匹配（比值一致性） |
| 采样/检测 | 电流采样、电流环反馈 | 低温漂、低热电势、功率、四端子结构 |
| 上拉/下拉 | 数字接口、复位、使能 | 阻值合理区间、封装体积、成本 |
| 终端匹配 | 高速总线、差分链路 | 阻值精度、寄生电感/电容、频率特性 |
| 泄放/放电 | 母线泄放、电容放电、安规放电 | 耐压、浪涌功率、长期可靠性 |
| 保护/保险 | 熔断电阻、浪涌抑制 | 浪涌能量承受、开路失效模式 |
| 加热/负载 | 假负载、加热元件 | 功率、散热、长期老化 |

**先问功能，再问参数。** 同一颗电阻放在"分压"位置和"采样"位置，选型逻辑完全不同：前者看比值和温漂匹配，后者看绝对温漂、功率和热电势。

## 4. 阻值、精度与温度特性

### 4.1 标称阻值与 E 系列

电阻不会提供任意阻值，而是按标准 E 系列取值。理解 E 系列是选型的第一步，它决定了你能选到什么阻值，以及系统化选型的余地有多大。

| 系列 | 容差/步进 | 每十倍频程取值数 | 典型用途 |
| --- | --- | --- | --- |
| E6 | ±20% | 6 | 老式、低成本非关键电路 |
| E12 | ±10% | 12 | 通用非精密电路 |
| E24 | ±5% | 24 | 最常用的通用系列 |
| E48 | ±2% | 48 | 一般精密电路 |
| E96 | ±1% | 96 | 精密电路主流选择 |
| E192 | ±0.5% 及更高 | 192 | 高精度、精密仪器 |

**经验**：选阻值时先算出理论值，再就近取 E 系列。若 E24 系列就能满足误差预算，就没必要选 E96；若精度要求 ±0.1%，通常必须使用 E96/E192 系列。不要为了"凑"一个精确值而串联多颗电阻——串联会引入走线、焊点误差和额外的温漂不一致。

### 4.2 阻值容差与误差预算

容差（Tolerance）是电阻在出厂时相对标称值的允许偏差，直接决定电路在常温下的初始误差。

| 容差等级 | 常见材料 | 典型应用 |
| --- | --- | --- |
| ±10% / ±5% | 碳膜、厚膜 | 非关键限流、指示、下拉 |
| ±1% / ±0.5% | 厚膜精密型、薄膜 | 一般分压、反馈网络 |
| ±0.1% / ±0.05% | 薄膜、金属箔 | 精密分压、基准、仪器 |
| ±0.01% 及更优 | 金属箔、精密薄膜 | 计量、校准、超高精度仪表 |

**误差预算概念**：电路输出误差由多个来源共同决定，电阻容差只是其中之一。正确做法是做一份误差预算表，把各项误差按最坏情况（Worst-Case）或均方根（RSS）方式合成：

```text
总误差 = √(初始容差² + 温漂误差² + 长期漂移² + 焊接/安装误差² + 负载效应² + …)
```

| 误差来源 | 典型量级 | 说明 |
| --- | --- | --- |
| 初始容差 | ±1% | 常温出厂偏差，可实测分选 |
| 温漂误差 | ±0.3% | 由 TCR 与温升共同决定 |
| 长期漂移 | ±0.1%~±1% | 随寿命累积，与负载/温度相关 |
| 焊接偏移 | ±0.05%~±0.3% | 焊接应力引起的永久偏移 |
| 负载效应 | 视电路而定 | 自身发热导致的阻值变化 |

**注意**：容差不是唯一误差来源。一颗 ±0.1% 容差但 TCR 高达 ±200 ppm/℃ 的电阻，在 50℃ 温升下的漂移就达到 ±1%，反而不如一颗 ±1% 容差、TCR 只有 ±25 ppm/℃ 的电阻稳定。

### 4.3 温度系数（TCR）

温度系数（Temperature Coefficient of Resistance）表示温度每变化 1℃ 时阻值的相对变化，单位为 ppm/℃（1 ppm = 1×10⁻⁶）。它是精密电路选型的第一约束。

```text
ΔR / R = TCR × ΔT
```

例如一颗 TCR = ±50 ppm/℃ 的电阻，在温升 40℃ 时，阻值变化约为 50 × 40 = 2000 ppm = 0.2%。若电路允许误差为 0.5%，则这一项已占去相当比例。

| TCR 等级 | 对应材料/工艺 | 典型应用 |
| --- | --- | --- |
| ±0.2~±5 ppm/℃ | 精密金属箔 | 计量、精密电流检测 |
| ±5~±25 ppm/℃ | 精密薄膜 | 精密分压、仪表前端 |
| ±25~±50 ppm/℃ | 高精度厚膜/薄膜 | 常规精密电路 |
| ±50~±100 ppm/℃ | 厚膜精密型 | 一般模拟电路 |
| ±100~±250 ppm/℃ | 普通厚膜 | 数字、非关键电路 |

**温漂跟踪（Tracking）**：在分压、增益等比值敏感电路中，真正重要的不是单颗电阻的绝对 TCR，而是两颗电阻 TCR 的一致性。优先选用同型号、同批次、同封装的分立电阻，或直接用集成网络电阻/匹配对。

**经验**：拿到一个精度指标，先别急着选 ±0.1% 的电阻。先估算整机温升，再乘以候选电阻的 TCR，看看温漂误差是否已超预算。很多时候，选择低 TCR 比选择高初始精度更有效、更划算。

### 4.4 实际选型中的精度决策

1. 由电路方程算出理论阻值与允许的总误差。
2. 估算整机温升 ΔT，选定候选 TCR 等级，算出温漂误差。
3. 在总误差中扣除温漂、漂移、负载效应等项，得到留给初始容差的额度。
4. 按剩余额度选定容差等级与 E 系列。
5. 对比值网络，按跟踪 TCR 而非绝对 TCR 评估。

## 5. 功率、电压与浪涌

### 5.1 额定功率与降额

电阻的额定功率是在特定环境温度（通常 25℃ 或 70℃）和特定散热条件下允许承受的最大功率。环境温度升高后，允许功率会按降额曲线下降。

| 应用等级 | 功率降额建议 | 说明 |
| --- | --- | --- |
| 一般消费类 | ≤ 60% 额定功率 | 常温环境，可靠性要求一般 |
| 工业/通信 | ≤ 50% 额定功率 | 长期连续工作，重视寿命 |
| 汽车/医疗/军工 | ≤ 30%~40% 额定功率 | 高可靠性，需按最坏情况 |
| 靠近其他热源 | 进一步降额 | 相邻元件温升会叠加 |
| 高环境温度 | 按降额曲线折算 | 不能只看 25℃ 额定值 |

**注意**：降额要按"最高环境温度 + 自身温升"算。常见错误是用 25℃ 的额定功率做 50% 降额，却忽略了机箱内 55℃ 的环境温度和自身 30℃ 的温升。正确做法是：先算实际功耗 P，再查降额曲线得到该温度下的允许功率 P_allow，确保 P ≤ 0.5 × P_allow（或按等级）。

### 5.2 功耗计算

```text
P = I² × R          或          P = U² / R
```

| 场景 | 计算方式 | 注意点 |
| --- | --- | --- |
| LED 限流 | P = I² × R | 取最大供电电压、最小 LED 压降 |
| 分压网络 | P = U² / R | 取最高输入电压，分别计算上下臂 |
| 电流采样 | P = I² × R | 取最大负载电流，注意持续与峰值之分 |
| 上拉电阻 | P ≈ U² / R | 低电平有效时功耗最大，需核算占空比 |
| 泄放电阻 | P = U² / R | 取最高母线电压，注意长期通电 |
| 反馈网络 | P = U² / R | 输出最高电压时功耗最大 |

### 5.3 最大工作电压

耐压是一个容易被忽略但会导致沿面闪络或膜层击穿的约束。需区分三个电压概念：

| 参数 | 含义 | 典型数值（0603 为例） |
| --- | --- | --- |
| 最大工作电压 | 连续工作时允许的直流/交流峰值电压 | 常为 50~75V |
| 最大过载电压 | 短时（如 5s）允许的过电压 | 常为工作电压的 2 倍 |
| 绝缘耐压 | 电阻体对外壳/基板的绝缘能力 | 数百 V 至 kV 级 |

最大工作电压往往先于功率限制成为瓶颈。例如一颗 0603/0.1W 的电阻，在 10kΩ 上施加 100V 时功耗已超标，但即使阻值很大使得功耗很小，100V 也可能超过其 50V 最大工作电压，仍然不允许。

### 5.4 浪涌与脉冲承受

浪涌（Surge）与脉冲（Pulse）是两类常见的瞬态应力。前者多来自雷击、感性负载切换、静电放电；后者多来自开关动作、电容充电。

影响浪涌承受能力的因素：

- 脉冲宽度与能量：主要看能量，而不是单纯的电压或电流幅值。
- 脉冲重复频率：重复脉冲会累积热效应。
- 电阻工艺：薄膜与厚膜的耐受机理不同，金属箔和绕线更耐冲击。
- 封装尺寸：封装越大，热容量越大，短脉冲承受能力越强。
- 阻值：同等电压下，阻值越小电流越大，会影响焦耳热分布。

提升浪涌承受能力的工程手段：

- 选择脉冲专用电阻或抗浪涌型产品。
- 使用较大封装，提高热容量。
- 串联分压/分流，把能量分配到多颗电阻。
- 在电阻前增加 TVS、压敏或 RC 吸收网络，把能量引导到保护器件。
- 核算最坏情况的浪涌能量，并与器件规格留足余量。

**经验**：浪涌电流的波形往往难以精确测量，建议按厂家曲线的 50% 甚至更低来使用。厚膜电阻在接近阈值反复冲击下阻值可能缓慢漂移而不立即失效，这才是最隐蔽的风险。

## 6. 噪声、稳定度与寄生效应

### 6.1 噪声特性

电阻噪声主要分为两类：热噪声（约翰逊噪声）与电流噪声（1/f 噪声）。

**热噪声**由载流子的热运动引起，与温度、阻值、带宽有关，与材料无关：

```text
V_n = √(4 k T R B)
```

热噪声是所有电阻的固有下限，无法通过选择材料消除，只能通过降低阻值、降低温度或缩小带宽来减小。

**电流噪声（1/f 噪声）**与材料和工艺密切相关，用噪声指数（μV/V）表征：

| 类型 | 噪声指数（典型） | 适用场合 |
| --- | --- | --- |
| 厚膜 | 较高（+0.5~+3 μV/V） | 数字、非关键场合 |
| 薄膜 | 低（-10~+10 dB） | 精密模拟前端 |
| 金属箔 | 极低 | 超低噪声测量、音频 |
| 绕线 | 极低 | 精密低频、音频 |

### 6.2 长期稳定度与老化

长期稳定度描述电阻在寿命周期内阻值的漂移程度，通常以负载寿命试验（如额定功率、额定温度下 1000 小时或 10000 小时）后的阻值变化百分比表示。

影响长期稳定度的因素：

- 工作温度：温度越高，漂移越快（近似遵循阿伦尼乌斯模型）。
- 负载功率：高负载加速膜层与基板的老化。
- 环境湿度：湿气侵入会影响膜层与端头。
- 材料与工艺：金属箔和精密薄膜的稳定度显著优于厚膜。

### 6.3 焊接与机械应力

机械应力是贴片电阻最隐蔽的失效来源。它通常不表现为立即失效，而是在温度循环、板弯或运输振动后出现间歇性开路或阻值漂移。

| 应力来源 | 机理 | 工程对策 |
| --- | --- | --- |
| 板弯/板翘 | 贴片电阻承受弯曲应力开裂 | 合理布局、避开高应力区、选择柔性端头 |
| 温度循环 | CTE 不匹配产生周期性应力 | 减少封装尺寸、优化焊料与焊盘 |
| 焊接热冲击 | 急热急冷使端头开裂 | 规范回流曲线、避免手工烙铁反复补焊 |
| 机械分板 | V-CUT/冲切应力传入元件 | 分板线远离元件、改用铣切 |
| 紧固件应力 | 螺钉拧紧使 PCB 局部变形 | 避开安装孔、使用垫圈缓冲 |

### 6.4 寄生电感与电容

理想电阻只有阻值，实际电阻还带有寄生电感和寄生电容。在低频电路中它们可以忽略，但在高速、高频或射频电路中会成为关键约束。

- 寄生电感：由端头、引线和绕线产生。频率升高时使阻抗上升，影响信号完整性。
- 寄生电容：由端头与基板、膜层之间的耦合产生。频率升高时使阻抗下降。
- 自谐振：寄生电感与电容在某一频率谐振，超过该频率阻抗特性反转。

减小寄生参数的选型与设计建议：

- 高频场合优先选用薄膜贴片或专门的射频电阻。
- 避免使用绕线电阻处理高频信号，除非是无感绕线型。
- 使用小封装，缩短电流路径。
- 必要时用多颗小阻值电阻并联分散电流路径。

### 6.5 匹配与跟踪

在需要阻值比例为关键指标的电路中（分压、增益、桥式），单一电阻的精度往往不是最重要，两颗电阻的匹配与跟踪才是。

- **匹配（Matching）**：两颗电阻阻值之比或之差的相对偏差。
- **跟踪（Tracking）**：两颗电阻在温度变化时保持比例的能力，由跟踪 TCR 表征。

集成网络电阻天然具有更好的匹配和跟踪。若使用分立电阻，应选择同型号、同批次、同封装的产品。

**经验**：对分压比或增益比，先确认需要的比值误差，再查网络电阻产品；若分立电阻无法满足跟踪性，应果断改用网络电阻。

## 7. 电阻类型与特性对比

### 7.1 常见电阻类型对比

| 类型 | 精度范围 | 温漂 (ppm/℃) | 典型功率 | 优势 | 局限 |
| --- | --- | --- | --- | --- | --- |
| 厚膜贴片 | ±0.5%~±5% | ±100~±250 | 1/16W~1W | 成本低、货期短、规格全 | 噪声大、温漂大、浪涌能力弱 |
| 薄膜贴片 | ±0.01%~±1% | ±5~±50 | 1/16W~0.5W | 精度高温漂小、噪声低 | 成本较高、功率小 |
| 金属膜（插件） | ±0.1%~±1% | ±15~±100 | 1/8W~2W | 性能均衡、通用性强 | 体积大、寄生电感略高 |
| 碳膜（插件） | ±2%~±10% | ±200~±1000 | 1/8W~2W | 极便宜 | 温漂差、噪声大，仅用于非关键场合 |
| 绕线 | ±0.01%~±1% | ±2~±50 | 1W~数百 W | 功率大、精度高、超低噪声 | 寄生电感大，高频不适用 |
| 合金/金属箔 | ±0.01%~±0.5% | ±0.2~±25 | 0.5W~5W | 超低温漂、低热电势、低电感 | 价格高、规格少 |
| 水泥/功率（插件） | ±5%~±10% | ±100~±350 | 2W~数十 W | 功率大、耐浪涌、便宜 | 精度差、体积大、有电感 |

**注意**：厚膜 ≠ 薄膜。采购和选型时最容易混淆的一对概念。厚膜是丝网印刷烧结，薄膜是真空溅射。同样 0603 封装、同样 10kΩ，二者的温漂可能相差 10 倍以上。BOM 里务必写清工艺类型，不要只写"贴片电阻"。

### 7.2 厚膜电阻

厚膜电阻（Thick Film）采用丝网印刷钌系氧化物浆料后高温烧结，膜层较厚。它是消费电子和一般数字电路的主力。

**主要特点**：

- 成本优势明显，单位价格在所有贴片类型中最低。
- 阻值范围宽广，从 0Ω（跳线）到数十 MΩ 均可提供。
- 温漂通常在 ±100~±250 ppm/℃，精密档可做到 ±50 ppm/℃。
- 噪声和电流非线性较明显，不适合高精度模拟前端。
- 脉冲承受能力较弱，易发生膜层局部烧蚀导致阻值永久偏移。

**适用场合**：数字信号的上拉、下拉、串联阻尼电阻；一般 LED 限流；对精度要求不高的分压、偏置网络；非关键位置的负载与泄放。

### 7.3 薄膜电阻

薄膜电阻（Thin Film）采用真空溅射在陶瓷基板上形成镍铬（NiCr）等合金薄膜，再经光刻或激光调阻形成图形。膜层致密均匀，温漂和噪声表现远优于厚膜。

**主要特点**：

- 温漂可低至 ±5~±25 ppm/℃，精密型甚至更优。
- 初始精度可达 ±0.01%，适合精密分压与基准网络。
- 电流噪声低，长期稳定性好。
- 功率密度较低，典型不超过 0.5W（贴片）。
- 价格高于同规格厚膜，规格数量较少。

**适用场合**：精密放大器、仪表放大器、ADC/DAC 参考网络；高精度分压比网络与增益设定电阻；对温漂敏感的温度补偿电路；需要成对匹配的差分、桥式电路。

### 7.4 合金电阻（金属箔/锰铜）

合金电阻使用锰铜、镍铬铝等合金材料，通过蚀刻或精密加工制成。它兼具超低温漂、低热电势和低寄生电感，是精密电流检测的首选。

**主要特点**：

- 温漂可低至 ±0.2 ppm/℃，接近理想的温度稳定性。
- 低热电势（EMF），避免温度梯度引起额外误差。
- 四端子（Kelvin）结构可消除引线与焊点的压降影响。
- 低寄生电感，适合高频电流检测。
- 成本显著高于普通电阻，规格以低阻值（mΩ 级）为主。

**适用场合**：电机驱动、BMS、电源的电流采样；大电流路径的精密检测（配合电流检测放大器）；高精度电流环、能效计量。

### 7.5 绕线与水泥电阻

绕线电阻（Wirewound）把合金丝绕制在陶瓷骨架上；水泥电阻（Cement）则是把绕线体封装在陶瓷/水泥外壳中。二者共同点是功率大、耐浪涌，共同局限是寄生电感大。

**主要特点**：

- 功率等级从 1W 到数百 W，散热能力突出。
- 耐浪涌和过载能力强，可承受短时大电流冲击。
- 精度和温漂可做得很好（精密绕线型）。
- 寄生电感明显，高频场合会引起相位失真和阻抗突变。
- 无感绕线（Ayrton-Perry 双线绕法）可缓解电感问题，但成本上升。

**适用场合**：电源的功率泄放、假负载、启动限流；变频器、电机的制动电阻；中低频大功率电路；需要高浪涌承受能力的保护电路。

### 7.6 特殊电阻类型

**热敏电阻（NTC / PTC）**：阻值随温度显著变化。NTC（负温度系数）常用于温度检测、浪涌抑制；PTC（正温度系数）常用于自恢复保护与恒温加热。注意其强非线性，不能作为普通电阻使用。

**压敏电阻（MOV）**：电压超过阈值后阻值急剧下降，用于吸收浪涌能量。选型关注压敏电压、通流容量、能量耐受和老化衰减，不能替代保险丝使用。

**熔断电阻（Fusible Resistor）**：兼具限流与过流保护功能，在电流超限时以开路方式切断电路。适合需要兼顾成本与保护的小功率场合。

**零欧姆电阻（跳线）**：实质是阻值接近 0 的跳线，用于 PCB 布局跨线、配置选择、电流测量点。选型关注额定电流和封装，而不是阻值。

## 8. 封装、尺寸与安装

### 8.1 常见封装尺寸

贴片电阻的封装以英制尺寸代码命名，数字代表长宽的英制尺寸（单位为 1/100 英寸）。

| 封装 | 尺寸(mm) | 典型功率(70℃) | 最大工作电压 | 备注 |
| --- | --- | --- | --- | --- |
| 0201 | 0.6×0.3 | 1/20W | 15~25V | 高密度便携设备 |
| 0402 | 1.0×0.5 | 1/16W | 25~50V | 主流小型化选择 |
| 0603 | 1.6×0.8 | 1/10W | 50~75V | 通用首选 |
| 0805 | 2.0×1.25 | 1/8W | 100~150V | 通用、易贴装 |
| 1206 | 3.2×1.6 | 1/4W | 150~200V | 功率与体积平衡 |
| 1210/2010 | 3.2×2.5 / 5.0×2.5 | 1/2~1W | 150~250V | 中大功率贴片 |
| 2512 | 6.4×3.2 | 1W | 200~300V | 大功率贴片、采样电阻 |

### 8.2 封装与功率、散热的关系

- 封装越大，表面积越大，散热路径越好，允许功率越高。
- 贴片电阻主要通过两端焊盘和 PCB 铜箔散热，铜箔面积对实际温升影响显著。
- 同等功耗下，加大焊盘和铜箔散热面积，可有效降低电阻温升。
- 多层板的内层铜箔可作为散热层，提高散热能力。
- 插件电阻主要通过引脚和空气散热，需注意周围元件的间距。

降低电阻温升的设计手段：

- 增加焊盘与铜箔面积，必要时在焊盘下方铺铜并打过孔。
- 避免把大功率电阻放在其他热敏元件旁边。
- 在空间允许时使用更大封装。
- 必要时主动散热或增加空气对流。
- 使用多颗电阻并联分摊功耗（注意并联后的阻值需重新核算）。

### 8.3 类型与封装的匹配

| 类型 | 常见封装 | 安装注意 |
| --- | --- | --- |
| 厚膜/薄膜贴片 | 0201~2512 | 焊盘对称、回流曲线规范 |
| 金属箔/合金贴片 | 1206~2818 | 四端子型需按开尔文接法布局 |
| 插件金属膜/碳膜 | 轴向/径向 | 引脚间距、弯曲半径、避免引脚应力 |
| 绕线/水泥 | 轴向/立式/带散热片 | 需预留散热空间，远离热敏元件 |
| 网络电阻 | SOP/DIP/贴片阵列 | 关注共端与独立端的连接方式 |

### 8.4 常见安装与布局问题

**焊盘设计**：焊盘宽度应略大于电阻端头宽度，长度保证足够的焊接强度。两侧焊盘应对称，避免焊接时产生立碑（Tombstoning）。大功率电阻的焊盘应加大并铺铜散热。

**立碑与偏移**：立碑主要因两侧焊盘受热不均、焊膏量不一致引起。改善措施：对称焊盘、均衡焊膏、优化回流曲线、避免一端连接大铜面。

**分板与组装应力**：V-CUT 分板时，靠近分板线的元件承受最大应力，应保持足够距离。推荐使用铣切或激光分板，减少机械应力。拼板方向应避免让电阻长轴垂直于分板方向。

**注意**：电阻长轴若与板弯方向垂直，承受的弯曲应力最大，最易开裂。布局时应尽量让电阻长轴平行于可能的弯曲方向，并远离板边、安装孔、连接器等应力集中区域。

## 9. 典型应用场景的选型要点

### 9.1 分压网络

分压是电阻最经典的用法，其选型核心是"比值精度"和"阻抗水平"。

| 关注点 | 选型要求 | 说明 |
| --- | --- | --- |
| 比值精度 | 优先匹配/网络电阻 | 比绝对精度更关键 |
| 温度跟踪 | 低跟踪 TCR | 同批次、同工艺、同封装 |
| 阻抗水平 | 兼顾功耗与负载效应 | 阻值过低耗电大，过高受漏电流影响 |
| 功率 | 按最高输入电压核算 | 上下臂分别计算 |
| 噪声 | 精密场合用薄膜 | 厚膜噪声会影响信噪比 |

分压选型的经验规则：

- 分压电阻的总阻值应使分压电流远大于后级输入偏置电流（通常 ≥100 倍）。
- 分压点若接 ADC，需考虑采样电容充电引起的动态误差，必要时并联小电容。
- 高压分压应采用多颗串联，并核算每颗的耐压与功耗。

### 9.2 LED 限流电阻

LED 限流电阻的选型核心是"在电源电压波动和 LED 压降波动下，仍保证电流在允许范围内"。

```text
R = (V_supply − V_f) / I_f
```

- 按最小 V_supply 和最大 V_f 计算，保证 LED 仍能获得足够电流。
- 按最大 V_supply 和最小 V_f 计算，保证电流不超过 LED 最大允许值。
- 功耗按最大压差和最大电流计算。
- 精度通常 ±5% 即可，普通厚膜足以胜任。

**注意**：多颗 LED 并联共用一个限流电阻会导致电流分配不均，容易烧毁压降最低的那颗。正确的做法是每颗 LED 各配一颗限流电阻，或用恒流驱动方案。

### 9.3 上拉/下拉电阻

上拉/下拉电阻的作用是给数字信号提供确定的默认电平。选型关注阻值范围与总线速率。

| 关注点 | 选型考虑 | 说明 |
| --- | --- | --- |
| 阻值下限 | 不能超过器件灌/拉电流能力 | 阻值过小会使驱动级过载 |
| 阻值上限 | 保证足够的上拉能力 | 阻值过大会使上升沿变慢、抗干扰差 |
| 总线速率 | I²C 等需按速率选阻值 | 速率越高，阻值应越小 |
| 功耗 | 低电平有效时功耗最大 | 需核算最大功耗 |
| 数量 | 多路并行时等效阻值下降 | 需汇总计算总负载 |

经验取值：一般数字信号 4.7kΩ~10kΩ；I²C（100kHz）4.7kΩ；（400kHz）2.2kΩ；（1MHz）1kΩ；低功耗场合可放宽到 100kΩ 量级。

### 9.4 采样电阻（电流检测）

采样电阻把电流转换为电压，是电源、电机、BMS 等系统的关键元件。其选型与普通电阻差异最大。

| 关注点 | 选型要求 | 说明 |
| --- | --- | --- |
| 阻值 | 尽量小以降低功耗，但不能太小 | 需保证检测信号高于放大器失调 |
| 温漂 | 超低温漂（≤25 ppm/℃） | 直接决定检测精度 |
| 热电势 | 低 EMF | 避免温度梯度引起误差 |
| 功率 | 按最大电流核算 | 注意持续与峰值之别 |
| 结构 | 建议四端子（开尔文） | 消除引线与焊点压降 |
| 电感 | 低寄生电感 | 高频开关场合需注意 |

**注意**：采样电阻的测量应从电阻的端头（而非焊盘外侧）引出，避免把焊料和走线的电阻计入测量结果。四端子电阻专门为此设计，其电压检测端子与电流路径分离，是精密采样首选。

### 9.5 上电浪涌抑制与泄放

**上电限流**：为限制电容充电时的浪涌电流，可在电源路径串联 NTC 热敏电阻或功率电阻。选型关注浪涌能量承受能力和长期功耗。

**母线泄放**：为满足安规要求（如断开电源后母线电压在规定时间内降到安全值），需要泄放电阻。

- 泄放电阻长期通电，功耗必须严格核算并按可靠性等级大幅降额。
- 高压场合需确认最大工作电压，必要时串联分摊。
- 泄放时间常数 τ = R × C，需满足安规要求的最长泄放时间。

### 9.6 高速信号与终端匹配

**终端匹配电阻**：用于消除传输线反射，常见形式包括串联终端、并联终端、戴维南终端等。选型关注：

- 阻值与传输线特征阻抗匹配（如同轴 50Ω、差分 100Ω）。
- 寄生电感和电容要小，避免影响匹配效果。
- 频率较高时应选用射频专用电阻或薄膜电阻。

**阻尼电阻**：串接在信号线上的小阻值电阻，用于抑制振铃和过冲。通常为几十欧姆以内，需靠近驱动端放置。

## 10. 可靠性与环境适应性

### 10.1 电阻的失效模式与机理

| 失效模式 | 机理 | 主要诱因 |
| --- | --- | --- |
| 阻值漂移 | 膜层老化、氧化、湿气侵入 | 高温、高负载、潮湿环境 |
| 开路 | 膜层烧蚀、端头开裂、机械断裂 | 过功率、浪涌、机械应力 |
| 短路 | 极少数情况下膜层熔化搭接 | 严重过载 |
| 噪声增大 | 膜层结构损伤 | 过载、老化 |
| 端头脱落 | 焊接不良或热应力 | 焊接工艺、温度循环 |

阻值漂移和开路是最常见的两类。阻值漂移通常是渐进过程，是长期可靠性设计的主要关注点；开路往往是突发过程，多由过应力或机械应力引起。

### 10.2 降额与寿命

降额是提升可靠性最直接有效的手段。电阻的失效率与工作温度、负载功率强相关，降低任何一项都能显著延长寿命。

- 温度每降低 10℃，寿命可显著延长（阿伦尼乌斯模型）。
- 负载功率降额可减少膜层老化和热应力。
- 高可靠性场合应同时降额温度和功率。
- 参考标准：GJB/Z 35、MIL-HDBK-338、各厂家降额准则。

### 10.3 环境因素

**温度**：高温加速老化，低温可能引起机械应力（CTE 不匹配）。温度循环导致的疲劳是贴片电阻开裂的主要原因之一。需按最高环境温度和最大温升核算。

**湿度**：湿气侵入会引起阻值漂移和绝缘下降。高湿环境下应选用防潮型产品或涂覆三防漆。

**硫化**：含硫环境中，硫会侵蚀厚膜电阻的端头（尤其是银电极），导致阻值升高或开路。硫化常见于工业、汽车、含硫橡胶密封的环境。抗硫化电阻（Anti-Sulfur）采用特殊端头结构，应优先选用。

**腐蚀与盐雾**：沿海、化工环境需关注盐雾腐蚀。涂层、封装材料和引脚镀层是关键。

**机械与振动**：振动和冲击可能引起引脚疲劳或元件开裂。大质量元件（如水泥电阻）需固定或选择带支架结构。

### 10.4 车规与高可靠性要求

| 要求 | 标准/内容 | 说明 |
| --- | --- | --- |
| 被动元件车规认证 | AEC-Q200 | 车规电阻的准入门槛 |
| 工作温度范围 | -55℃~+125/150/175℃ | 视安装位置而定 |
| 湿度偏压 | HTRB、HAST 等 | 验证湿气环境下的稳定性 |
| 温度循环 | TCT，循环次数要求高 | 验证机械与焊接可靠性 |
| 硫化要求 | 抗硫化测试 | 发动机舱、含硫环境必需 |
| 追溯性 | 批次可追溯 | 汽车行业强制要求 |

**说明**：通过 AEC-Q200 只说明元件满足最基本的车规门槛。实际选型还需结合具体安装位置的环境要求（温度、湿度、振动、硫化），以及整机厂更严苛的企业标准。选型时应索取完整的可靠性报告，而不只是认证证书。

### 10.5 提升可靠性的设计措施

- 严格降额：功率按等级降额，温度留足余量。
- 避免应力集中：合理布局，远离板边与安装孔。
- 选择匹配的环境等级：抗硫化、防潮、宽温产品。
- 冗余设计：关键位置可考虑串联/并联冗余。
- 工艺控制：规范回流曲线、避免反复手工焊接。
- 验证充分：温升实测、温度循环、长期老化试验。

## 11. 选型流程与决策方法

### 11.1 完整选型流程

| 步骤 | 工作内容 | 输出/记录 |
| --- | --- | --- |
| 1 | 明确电路功能与信号要求 | 功能定位、信号幅度、允许误差、工作频率 |
| 2 | 计算理论阻值 | 由电路方程反推阻值，确定 E 系列取值 |
| 3 | 确定精度与 TCR 等级 | 误差预算表，明确初始容差与温漂额度 |
| 4 | 计算功耗与温升 | 最坏情况功耗、降额后的额定功率要求 |
| 5 | 核算电压与浪涌 | 最大工作电压、浪涌能量与脉冲能力 |
| 6 | 选择电阻类型 | 厚膜/薄膜/合金/绕线等，明确理由 |
| 7 | 选择封装尺寸 | 兼顾功率、耐压、散热、布局与成本 |
| 8 | 确认可制造性与供应链 | 焊盘、共用料、二供、生命周期 |
| 9 | 样机验证 | 实测温升、精度、长期漂移 |

### 11.2 关键参数优先级判断

| 应用类型 | 第一优先级参数 | 次要关注 |
| --- | --- | --- |
| 精密模拟前端 | TCR、长期稳定度、噪声 | 容差、匹配 |
| 电流检测 | TCR、热电势、功率、四端子 | 阻值、电感 |
| 一般数字电路 | 阻值、容差、成本、交货 | 封装、功率 |
| 高速/射频 | 寄生电感电容、容差 | 功率、封装 |
| 电源功率路径 | 功率、耐压、浪涌承受 | 阻值、温漂 |
| 高压分压 | 最大工作电压、稳定性 | TCR、封装 |
| 汽车/工业 | 可靠性、认证、环境适应 | 全部参数均需核算 |

### 11.3 常见选型误区

| 误区 | 问题与纠正 |
| --- | --- |
| 只看阻值不看类型 | 厚膜与薄膜性能差异巨大，BOM 需明确工艺类型 |
| 用容差代替全部误差 | 忽略温漂、漂移、负载效应，误差会被低估数倍 |
| 按 25℃ 额定功率降额 | 忽略环境温度和自身温升，实际余量不足 |
| 忽略最大工作电压 | 功率满足但电压超限，导致沿面闪络 |
| 用分立电阻凑比值 | 不同批次跟踪性差，比值随温度漂移 |
| 采样电阻用普通厚膜 | 温漂与热电势过大，检测精度无法保证 |
| 小封装图省空间 | 功率、耐压、抗应力能力均下降，可靠性风险升高 |

## 12. 可制造性、成本与供应链

### 12.1 可制造性（DFM）

- 焊盘设计符合厂家推荐，避免过大或过小。
- 避免使用过于稀有或特殊规格的封装，增加贴装难度。
- 元件间距满足贴装机精度与焊接要求。
- 大功率元件的散热铜箔和过孔设计要到位。
- 拼板与分板方式需考虑应力影响。
- 自动化检测（AOI）友好的丝印与布局。

### 12.2 成本构成与优化

| 成本项 | 影响因素 | 优化方向 |
| --- | --- | --- |
| 元件单价 | 精度、TCR、封装、类型 | 在预算内选"刚好够用"的等级 |
| 贴装成本 | 元件数量、封装尺寸 | 合并可共用料，减少料号 |
| 库存成本 | 料号数量、货期 | 统一料号、选择通用规格 |
| 失效成本 | 可靠性问题引发的返修 | 前期充分降额与验证 |
| 供应链成本 | 供货稳定性、生命周期 | 避免独家料，关注 EOL 风险 |

**说明**：精度每提升一个量级，成本往往上升数倍。选型时应在误差预算内选择"刚好够用"的等级，把预算留给真正敏感的环节。若某个位置对精度要求极高，可考虑用软件校准或出厂分选替代高精度元件。

### 12.3 料号管理与二供

- 同阻值同封装的电阻尽量统一料号，减少种类。
- 关键位置应准备第二供应商，避免单一来源风险。
- 关注器件的生命周期状态（Active/NRND/EOL）。
- 二供产品需验证参数一致性，尤其是 TCR 和匹配性。
- 变更管理：任何器件替换都需重新评估关键参数。

**经验**：在 BOM 或设计说明中记录每次选型的理由（为什么选这个 TCR、为什么选这个封装），是团队协作和后续复盘的宝贵财富。尤其在项目交接和故障分析时，选型留痕能极大提升效率。

### 12.4 生命周期与技术趋势

- 小型化：0201、01005 封装在高密度产品中逐步普及。
- 高精度化：薄膜与金属箔在精密场合替代厚膜。
- 抗硫化与车规：工业和汽车需求推动特种产品增长。
- 低 TCR 与高稳定度：精密测量与计量需求持续提升。
- 集成化：网络电阻、匹配对替代分立组合。

- 比值网络是否评估了跟踪性？
- 布局是否存在机械应力集中？
- 关键位置是否准备了二供？
- 是否留存了选型理由与技术依据？

## 14. 常见问题（FAQ）

**Q1：厚膜和薄膜到底怎么选？**

看三点：精度要求、温漂要求、噪声要求。如果三项都宽松（如数字上拉、一般限流），选厚膜，成本最低。如果任一项严格（如精密分压、低噪声前端、电流检测），选薄膜或金属箔。判断的关键是做误差预算，而不是凭经验拍脑袋。

**Q2：精度选 ±1% 还是 ±0.1%？**

由误差预算决定。先算温漂、漂移等其他误差项，看还剩多少额度留给初始容差。若温漂误差已占大半，再高的初始精度也无意义。反之，若电路其他误差都很小，初始容差就成为决定项。

**Q3：怎么判断功率余量够不够？**

不要只看 25℃ 额定值。步骤是：算实际功耗 → 查降额曲线得到该温度下的允许功率 → 按可靠性等级留出余量（工业 50%、汽车 30~40%）→ 最好实测温升验证。

**Q4：为什么采样电阻要选低温漂的？**

采样电阻把电流转换为电压，其阻值直接决定检测比例。若阻值随温度漂移，检测结果就会随温度变化，形成系统性误差。此外，采样电阻往往工作在大电流下，自身温升明显，温漂影响被进一步放大。

**Q5：分压电阻为什么要成对选？**

分压比取决于两颗电阻的比值。即使单颗电阻的绝对 TCR 都不错，只要两者温漂不一致，比值就会随温度变化，输出随之漂移。因此要关注跟踪 TCR，优先使用同批次、同工艺、同封装的分立件，或直接使用网络电阻。

**Q6：电阻能用串联或并联替代一颗吗？**

在功率或耐压不足时，串联/并联是有效手段：串联分摊电压和功耗，并联分摊电流和功耗。但要注意：并联后等效阻值变化，需重新核算；并联电阻的温漂不一致会引入额外误差；并联还会增加元件数量和布局面积。

**Q7：什么是抗硫化电阻，什么时候需要？**

抗硫化电阻通过改进端头结构（如采用金/铂等抗硫材料或加防护层），抵抗含硫环境对端头的侵蚀。在工业、汽车（尤其发动机舱）、含硫橡胶密封、污染较重的户外环境中必须考虑。普通厚膜电阻在这些环境下可能出现阻值升高甚至开路。

**Q8：金属箔电阻为什么贵？**

金属箔电阻采用特殊合金材料和精密加工工艺，具有超低温漂（可低至 ±0.2 ppm/℃）、低热电势、低寄生电感和极高的长期稳定度。这些特性是普通工艺无法达到的，因此成本高。它主要用在计量、精密测量、高端仪器等对精度要求极高的场合。

**Q9：0201 封装能用吗？**

可以，但需权衡。0201 有利于高密度布局和降低寄生参数，但功率小、耐压低、抗机械应力弱、贴装和维修难度大。一般消费类产品在空间紧张时可用，但对可靠性要求高或功率较大的场合应谨慎，通常 0402/0603 是更稳妥的选择。

**Q10：怎么避免贴片电阻开裂？**

关键在布局与工艺：让电阻长轴平行于可能弯曲的方向；远离板边、安装孔等高应力区；采用铣切或激光分板；优化焊盘对称性；选择柔性端头产品；规范回流曲线，避免反复手工补焊。

**Q11：如何评估长期可靠性？**

主要有三条路径：一是选型阶段严格降额；二是选用有明确长期稳定度数据、经过负载寿命验证的产品；三是通过实际试验验证，如高温负荷试验、温度循环、湿度偏压、硫化试验等。对高可靠性场合，建议索取厂家的完整可靠性报告。

**Q12：为什么同一阻值不同封装价格差很多？**

封装尺寸影响材料用量、制造精度和工艺难度。小封装（如 0201）制造难度高、良率低，单价可能反而更高；大封装（如 2512）材料多，单价也高。此外，精度、TCR 等级对价格影响更大。采购时应综合参数与封装一起评估。

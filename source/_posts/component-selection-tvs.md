TVS（Transient Voltage Suppressor，瞬态电压抑制二极管）是一种二极管形式的过电压保护器件，通常并联在被保护线路与地之间，用于吸收浪涌、ESD、感性负载反电动势，把电压钳位在安全水平。

> 本文属于「[硬件产品器件选型](/collections/component-selection/)」合集。ESD 深度内容见[ESD篇](/posts/component-selection-esd/)，通用二极管对比见[二极管篇](/posts/component-selection-diode/)。

## 1. 工作原理

工作过程分为三个阶段：

| 阶段 | 状态 | 说明 |
| --- | --- | --- |
| 正常工作 | 高阻截止态 | 线路电压低于反向截止电压 VRWM，TVS 仅流过微安级漏电流，近似开路，对电路无影响 |
| 瞬态冲击 | 雪崩击穿导通 | 浪涌/ESD 尖峰使电压超过击穿电压 VBR，TVS 瞬间进入雪崩击穿区，阻抗急剧下降，将瞬态电流泄放至地，并把电压钳位在 VC 附近 |
| 浪涌过后 | 自动恢复 | 电压回落至 VRWM 以下后，TVS 恢复高阻态，不影响电路正常工作 |

**TVS 的核心优势**：

- **响应速度快**：皮秒（ps）级响应，远优于压敏电阻（MOV）和气体放电管（GDT）
- **钳位精度高**：钳位电压接近击穿电压，过冲小
- **无老化退化**：与 MOV 不同，TVS 在额定功率内可承受反复浪涌而不退化
- **寿命长、体积小、成本低**

**关键结论**：只要浪涌能量不超过其最大额定值，TVS 可以可靠、反复地工作；选型失误则保护失效，甚至烧毁后级芯片。

## 2. TVS 管的分类

### 2.1 按极性分

| 类型 | 特性 | 典型应用 |
| --- | --- | --- |
| 单向 TVS | 只钳位正极性浪涌（反向雪崩击穿），正向相当于普通二极管（约 0.7V 导通），可兼顾电源反接保护 | 直流电源轨（5V/12V/24V/48V）、单极性信号 |
| 双向 TVS | 正反两个方向对称钳位 | 交流输入、差分总线（RS-485、CAN）、可能承受双极性浪涌的信号线 |

经验法则：固定直流电位的线路用单向；信号可能正负摆动或交流线路用双向。注意双向 TVS 的结电容约为单向的 2 倍。

### 2.2 按应用特性分

| 类型 | 结电容 Cj | 峰值脉冲电流（8/20µs） | 典型应用 |
| --- | --- | --- | --- |
| 通用 TVS | 50~500pF | 5~50A | 电源轨、低速信号线 |
| 低电容 TVS / ESD 阵列 | <1pF（超低容可 <0.3pF） | 1~5A | USB 3.x、HDMI、以太网、RF 等高速接口 |
| 大功率 TVS | 500~5000pF | 100~500A | 电源输入口、电机驱动、光伏逆变、汽车 Load Dump |
| 汽车级 TVS | — | 20~100A | 符合 AEC-Q101 认证，车载 ECU、传感器端口 |

### 2.3 特殊类型

- **不对称双向 TVS**：如 RS-485 总线用的 +12V/−7V 特性器件，匹配总线共模电压范围。
- **阵列封装 TVS**：SOT-23、DFN、QFN 等多通道集成，保证差分对之间电容与钳位特性的一致性。

## 3. 关键参数详解

### 3.1 反向截止电压 VRWM

定义：TVS 可长期承受、不发生明显导通的最大连续反向工作电压。

选型要求：VRWM ≥ 线路最大正常工作电压（含电源容差、纹波峰值），通常取最大工作电压的 1.1 倍以上。

- 若选低了：正常工作时 TVS 进入雪崩区边缘，漏电流激增至毫安级，待机功耗超标甚至热失效。
- 若选高了：钳位特性变"软"，VC 升高，保护裕量减小。

常见标准值序列：5V、5.5V、6V、6.5V、7V、8V、9V、10V、12V、13V、15V、18V、24V、28V、33V、36V、40V 等。

- 交流场合：需将有效值换算成峰值比较，即 VRWM ≥ V(AC)×1.414。
- 汽车 12V 系统注意：稳态充电电压可达 14.5V，应按最坏工况而非标称值选取。

### 3.2 击穿电压 VBR

定义：TVS 开始明显导通（雪崩击穿）的电压，通常在测试电流 1mA 下定义，数据手册给出最小/最大范围。典型关系：VBR ≈ 1.1×VRWM（约高出 10%~15%）。注意 VBR 随温度漂移约 0.05%~0.1%/℃，10V 器件在 125℃ 时可能钳位在 11V。

### 3.3 钳位电压 VC——选型的生死线

定义：流过峰值脉冲电流 IPP 时，TVS 两端的最高电压。

选型要求：VC（在预估浪涌电流下）必须低于被保护器件的绝对最大额定值（Absolute Maximum Rating），并留 20% 以上裕量（即 VC ≤ 0.8×Vmax）。

**最常见失误**：只核对 VBR 而忽略 VC。VC 永远高于 VBR——击穿 6.4V 的 TVS 满电流时可能钳位到 9.2V，足以毁掉 5V 逻辑 IC。

VC 由器件的动态电阻 RDYN 决定（VC ≈ VBR + ISurge×RDYN），动态电阻越小钳位越好，专用 ESD 器件 RDYN 典型 0.1~1Ω。

### 3.4 峰值脉冲电流 IPP

定义：TVS 在指定测试波形（常见 8/20µs 浪涌波形或 10/1000µs 波形）下能承受的最大浪涌电流。

选型要求：IPP 额定值必须大于系统预期峰值浪涌电流，建议留 30%~50% 裕量。

估算：IPP(required) = (Vtransient − VC) / Rseries（含串联阻抗）。IPP 不足时，过大的浪涌能量会导致 TVS 热损坏或短路失效（常以短路方式失效，彻底丧失保护能力）。

### 3.5 峰值脉冲功率 PPP

定义：单次脉冲可吸收的最大功率，PPP = VC × IPP，典型按 10/1000µs 波形定义。常见等级：400W、600W、1500W、3000W、5000W。

按防护等级参考：

| 场景 | 推荐 PPP |
| --- | --- |
| 信号线 ESD 防护（IEC 61000-4-2） | 500W / 600W（板级 400~1500W 通常足够） |
| 电源线防护（IEC 61000-4-5 浪涌） | 1500W |
| 大功率电源/工业柜/雷击强浪涌 | 3000~5000W 及以上 |

温度降额：PPP 随温度升高而降低，高温环境必须按降额曲线核算。

### 3.6 结电容 Cj

影响：与线路阻抗构成低通滤波器，造成高频信号衰减、边沿变缓、眼图劣化。高速接口限值参考：

| 接口 | Cj 建议 |
| --- | --- |
| USB 2.0 | ≤ 5~10pF |
| USB 3.0 / USB4（5Gbps+） | ≤ 0.3~0.5pF |
| HDMI / DisplayPort | ≤ 0.5pF |
| 1000BASE-T 以太网 | 3~5pF |
| 10MHz 以上模拟信号 | ≤ 50pF |
| 10kHz 以下低速信号 | ≤ 1000pF 均可 |

差分对应使用通道间电容匹配的阵列器件。权衡：低电容器件通常浪涌能力较小（1~5A），切勿把低容 ESD 管用在大能量电源轨上。

### 3.7 漏电流 IR

定义：在 VRWM 下的反向漏电流。电池供电、低功耗、精密电路应选超低漏流器件（nA 级）。注意漏电流大约每升高 10~15℃ 翻一倍，25℃ 下 1µA 的器件在 125℃ 可能漏 20µA 以上。

### 3.8 响应时间

TVS 响应时间为 ps 级（<1ns），远快于任何瞬态上升速度，一般不构成选型瓶颈；对超高速 ESD（如 IEC 61000-4-2 首峰）可关注超低容 ESD 器件（<0.1ns）。

## 4. 选型流程（七步法）

①明确工况与威胁等级 → ②选 VRWM → ③定极性 → ④核对 VC 裕量 → ⑤定 IPP/PPP 等级 → ⑥查结电容/漏流 → ⑦定封装并实测验证

1. **明确被保护线路的基础工况与威胁等级**：精确测量最高持续工作电压 Vwork（稳态电压+纹波峰值+电源容差）；识别瞬态威胁类型与等级：

| 威胁类型 | 标准 | 典型等级 | 上升时间量级 | 峰值电流 |
| --- | --- | --- | --- | --- |
| 静电放电 ESD | IEC 61000-4-2 | ±4kV~±15kV（接触/空气） | 皮秒~纳秒级 | ~30A |
| 电快速瞬变脉冲群 EFT | IEC 61000-4-4 | ±1kV~±4kV | 纳秒级 | 数十 A |
| 浪涌 Surge | IEC 61000-4-5 | 1kV/2kV/4kV/8kV | 微秒级（8/20µs） | 可达 1kA |
| 抛负载 Load Dump（汽车） | ISO 7637-2 / ISO 16750-2 | ~100V 级 | 毫秒级 | 大能量 |

2. **选择反向截止电压 VRWM**：VRWM ≥ 1.1 × Vwork，确保正常工况下不导通。经验值：5V 系统选 6~6.5V；12V 系统选 15V；24V 系统选 26~28V；48V 系统选 54~58V。
3. **确定极性**：直流电源、单极性信号 → 单向；交流输入、差分总线 → 双向。
4. **核对钳位电压 VC 的裕量**：查阅被保护芯片数据手册的绝对最大额定值，确保满浪涌电流下 VC ≤ 0.8×Vmax。查 VC-IPP 曲线确认预估浪涌电流下的实际钳位值；若过高，换更低 VBR 型号或增加串联阻抗、采用多级防护。
5. **确定峰值脉冲功率 PPP 与电流 IPP 等级**：按必须通过的浪涌测试标准计算需求，并留 20%~50% 裕量。注意区分波形定义：同为"600W"，10/1000µs 与 8/20µs 下的实际能力差异很大。
6. **核对结电容 Cj 与漏电流 IR**：信号速率超过约 1Mbps 即需评估电容；高速接口选低容/超低容系列或 ESD 阵列。电池/低功耗场合选超低漏流器件。
7. **确定封装并实测验证**：按 PCB 空间、散热、功率等级选择封装。理论选型后必须进行实际浪涌测试（IEC 61000-4-2/-4-5 等）验证保护效果与 TVS 自身耐受能力，根据结果回调 PPP 或 VRWM。
## 5. 典型应用场景速查

### 5.1 电源端口

| 场景 | 推荐选型 | 要点 |
| --- | --- | --- |
| 3.3V/5V DC 输出轨 | SMAJ/SMBJ 系列，VRWM≥最大电压 | 单向；核对后级 IC 的 VC 裕量 |
| 12V/24V 工业电源、适配器 | SMBJ(600W)/SMCJ(1500W) | 注意 24V 系统纹波与浪涌等级 |
| AC 整流后母线、大功率 PSU | SMCJ、1.5KE、5KP(3000~5000W) | AC 输入按峰值选取；可与 MOV/GDT 组成多级防护 |
| PoE 供电端 | 专用 PoE TVS（VRWM≈57V） | 按 IEEE 802.3af/at/bt 等级选 |

### 5.2 通信接口

| 接口 | 推荐 | 要点 |
| --- | --- | --- |
| USB 2.0 | Cj≤5~10pF 的 ESD 阵列 | 线上防护以 ESD 为主 |
| USB 3.x/Type-C | Cj≤0.3~0.5pF 超低容阵列 | 超高速差分对必须用专用低容器件；VBUS 另配电源 TVS |
| HDMI/DP | 超低容 ESD 阵列（<0.5pF） | 差分对电容匹配 |
| 10/100M 以太网 | Cj≤3~5pF | 注意变压器隔离与 Bob Smith 端接防护 |
| 1000M 以太网/车载以太网 | 专用低容网络 TVS | 关注回损指标 |
| RS-485/CAN（差分总线） | 双向 TVS，VRWM 略高于总线共模电压（RS-485 可用 +12V/−7V 不对称型），600~1500W | 长线缆户外走线需兼顾浪涌，可加串联电阻（1~10Ω）与共模电感 |
| RS-232 | 双向，VRWM≈15V | — |

### 5.3 汽车电子

- 必须选用 AEC-Q101 认证器件，工作温度 −40℃~+125℃。
- 电源输入按 ISO 7637-2 / ISO 16750-2 的 Load Dump（抛负载）脉冲选大功率 TVS（如 SMCJ、5KP、DO-218AB 封装的 Load Dump 专用器件）。
- 12V 系统按充电最坏电压 14.5V 选 VRWM（一般选 15V 以上），冷启动可低至 6V 不影响选型。
- CAN/LIN 总线用双向 TVS，注意 VC 与收发器耐压匹配。

### 5.4 消费电子/智能家居

- USB 口、DC 插座：SMAJ/SMBJ + 数据线 ESD 阵列组合。
- 关注低剖面封装（DFN、X2-DFN）与 BOM 成本平衡。

## 6. 封装与功率等级选择

规律：封装越大 → 芯片面积越大 → 浪涌能力越强、结电容越大、成本越高。选型时先定功率等级再筛电压档。

| 封装 | 峰值脉冲功率（10/1000µs） | 特点 |
| --- | --- | --- |
| SOD-923 / DFN 超小型 | ~150W（波形不同有所差异） | 超低容 ESD 阵列，手机等紧凑设计 |
| SOD-323 / SOT-23 | 200~400W | 板级 ESD/小能量防护 |
| SMA / DO-214AC | 400W | 通用，适配器、USB 充电器 |
| SMB / DO-214AA | 600W | 工业 I/O、网络电源 |
| SMC / DO-214AB | 1500W | 机柜电源、工业控制 |
| 轴向 DO-15/DO-201（P6KE/1.5KE） | 600W / 1500W | 高功率、散热好，电源与户外设备 |
| P600（5KP） | 5000W | 电机柜、光伏、强雷击浪涌 |
| DO-218AB | 3600W | 汽车 Load Dump 专用 |

## 7. 与其他保护器件的对比

| 特性 | TVS 管 | 压敏电阻 MOV | 气体放电管 GDT | ESD 二极管（低容） |
| --- | --- | --- | --- | --- |
| 响应时间 | ps 级 | <25ns（较慢） | <100ns（最慢） | <0.1ns |
| 通流能力 | 中（A~数百 A） | 高（数百 A~kA） | 很高（数 kA） | 低（≤10A） |
| 钳位精度 | 高 | 中 | 低（点火电压高） | 高 |
| 老化退化 | 无 | 有（多次冲击退化） | 无 | 无 |
| 结电容 | 数十 pF~数 nF | — | <1pF | <1pF |
| 典型位置 | 后级精细防护 | 前级粗防护（AC 入口） | 前级（强雷击） | 高速数据线 |

多级防护典型架构：GDT（泄放大电流）→ 退耦电感/电阻 → TVS（精细钳位）。TVS 凭借超低动态电阻和快响应，负责对电压裕量敏感的后级做精确防护；前级用 MOV/GDT 分担大能量。

**注意**：TVS 不能代替保险丝——TVS 钳位电压，保险丝/PTC 切断持续过流，两者需配合使用，可参考[保险管篇](/posts/component-selection-fuse/)。

## 8. PCB 布局要点

1. **靠近连接器放置**：TVS 必须是信号进入连接器后的第一级器件。走线每增加 1mm 都引入寄生电感，快沿瞬态会在 TVS 导通前产生附加尖峰，实际钳位效果劣化。
2. **低感接地路径**：泄放电流回地路径必须短而宽（采用大面积覆铜/过孔阵列），细长地线电感会串入电压，等效抬高钳位电压。
3. **走线先过 TVS 再分叉**：避免被保护器件"绕过"TVS 取电。
4. **串联阻抗配合**：高能量场合在 TVS 前加 1~10Ω 串联电阻（或共模电感），分担能量并降低到达 IC 的钳位电压，常用于 RS-485/CAN/传感器线。
5. **散热焊盘**：大功率 TVS（SMB 以上）应按数据手册要求给焊盘足够覆铜散热。
6. **爬电距离**：AC 或高压场合注意焊盘间距满足安全规范。

## 9. 常见选型误区

| # | 误区 | 后果 | 正确做法 |
| --- | --- | --- | --- |
| 1 | 只核对 VBR，不核对 VC 与后级耐压 | 浪涌时后级 IC 仍被击穿 | 核对满浪涌电流下 VC ≤ 0.8×IC 绝对最大额定值 |
| 2 | PPP 选小（用板级 ESD 器件扛线缆浪涌） | TVS 几次冲击后短路失效，彻底失去保护 | 按必须通过的浪涌标准（波形+等级）选功率等级 |
| 3 | 高速数据线用了电源轨 TVS | 数百 pF 电容把信号"滤死"，眼图失效 | 高速线选 Cj<0.5pF 超低容 ESD 阵列 |
| 4 | VRWM 贴近标称电压 | 电源容差/纹波使 TVS 常态导通，发热失效 | VRWM ≥ 1.1×最大工作电压 |
| 5 | 差分总线用了单向 TVS | 反向浪涌无保护，装反方向甚至完全无防护 | RS-485/CAN/AC 必须双向 |
| 6 | TVS 远离连接器、地路径细长 | 寄生电感使实际钳位远超规格 | TVS 置于端口第一级，地路径短宽 |
| 7 | 忽略温度降额 | 高温下漏流增大、VBR/VC 漂移、PPP 下降 | 按高温降额曲线核算，留裕量 |
| 8 | 混淆波形定义（10/1000µs vs 8/20µs） | 实际通流能力与标称不符 | 核对 PPP/IPP 对应的测试波形 |
| 9 | 只做理论选型不实测 | 系统级抗扰不达标 | 必须进行 IEC 61000-4-2/-4-5 实测验证 |

## 10. 选型检查清单

选型完成后逐项打勾确认：

- [ ] 已确定被保护线路最大正常工作电压（含容差、纹波、启动异常）
- [ ] VRWM ≥ 1.1 × 最大工作电压（交流已换算峰值）
- [ ] 极性正确：DC→单向；AC/差分→双向
- [ ] 满浪涌电流下 VC ≤ 0.8 × 后级最敏感器件绝对最大额定值
- [ ] IPP/PPP 满足防护标准要求并留 20%~50% 裕量（已核对波形定义）
- [ ] Cj 满足信号完整性（高速接口已选低容/超低容器件，差分对已匹配）
- [ ] 漏电流 IR 满足低功耗/精度要求（已考虑高温倍增）
- [ ] 温度范围满足应用环境（汽车场合已确认 AEC-Q101）
- [ ] 封装满足 PCB 空间、散热与功率等级
- [ ] 布局：TVS 位于端口第一级，接地低感
- [ ] 已按 IEC 61000-4-2/-4-4/-4-5 完成系统级实测验证
- [ ] 考虑供货与成本（家族化选型、多平台复用）

**参数符号速查**：VRWM（反向截止/工作峰值电压）、VBR（击穿电压）、VC（钳位电压）、IPP（峰值脉冲电流）、PPP（峰值脉冲功率 = VC×IPP）、Cj（结电容）、IR（漏电流）、RDYN（动态电阻，决定 VC 斜率，越小越好）。

> 注：具体型号参数请以厂商最新数据手册为准；系统级防护设计应结合整机测试标准（IEC 61000 系列、ISO 7637-2 等）与实际浪涌测试结果闭环验证。
